# Guías de flujo de trabajo de aprobación de documentos {#table-of-contents}

Click2Approve es un sistema de aprobación de documentos. Envíe documentos a las personas que necesiten revisarlos, recopile decisiones y firmas electrónicas y realice un seguimiento del resultado. Estas guías explican cómo usar la aplicación en pasos simples.

Una **solicitud** contiene sus documentos, instrucciones y pasos del flujo de trabajo. Cada persona asignada a un paso recibe una **tarea**. Un **comprobante** registra el resultado cuando finaliza la solicitud.

Click2Approve también tiene una [edición de código abierto gratuita](open-source.md) para flujos de trabajo personales autohospedados. Vea la comparación de ediciones para conocer las funciones incluidas y las adiciones comerciales.
