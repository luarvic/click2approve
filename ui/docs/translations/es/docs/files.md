# Añadir archivos a solicitudes y tareas de aprobación {#files-and-attachments}

Puede adjuntar archivos a una solicitud de aprobación de documentos, a la decisión de un participante o a un mensaje de Chat. Cada lugar tiene un propósito diferente. Verifique dónde adjunta un archivo para que forme parte del registro que necesita.

| Quieres… | Adjunte el archivo aquí |
| --- | --- |
| Enviar un documento para que la gente lo revise | **Files to review** al crear la solicitud |
| Envíe un archivo con la respuesta a su tarea | **Your response** en la tarea |
| Comparte información adicional o haz una pregunta | **Chat** en la solicitud o tarea |

Cada archivo adjunto puede tener hasta **50 MiB** (52,428,800 bytes). Esto se aplica a los archivos adjuntos de solicitudes, decisiones y discusiones. También se aplican límites de token y almacenamiento del espacio de trabajo.

## Archivos de solicitud {#request-files}

Agregue los documentos que los participantes deben revisar al [crear una solicitud](create-a-request.md). Utilice nombres de archivos reconocibles y verifique los archivos seleccionados antes de enviarlos.

Abra un nombre de archivo para usar su vista previa disponible o acción de descarga. La compatibilidad con la vista previa depende del formato del archivo y del navegador. Si una vista previa no puede mostrar el documento, descárguelo y utilice una aplicación adecuada.

## Adjuntos de decisión {#decision-attachments}

Adjunte archivos de respuesta en el área de acción de la tarea cuando se solicite. Un paso marcado **Require an attachment** no se puede completar sin el archivo de respuestas requerido.

Los archivos adjuntos de decisión aparecen con la acción de la tarea registrada. Cargar el mismo archivo en Chat no cumple con el requisito de adjuntar una tarea.

## Adjuntos de discusión {#discussion-attachments}

Adjunte material de apoyo a un [mensaje de Chat](discussions.md) cuando necesite aclarar la solicitud. Considere la audiencia de la discusión antes de compartirla.

## Archivos revisados  {#revised-files}

Una revisión puede agregar, eliminar o reemplazar archivos de solicitud. Revise la lista de archivos actual y use **Show revision changes** para contexto. Los archivos reemplazados y eliminados que se muestran no son documentos de revisión actuales.

## Problemas de carga {#upload-problems}

Espera a que finalicen las cargas antes de enviarlas. Si se rechaza una carga, lea el error y verifique los [límites de uso del archivo y del espacio de trabajo](usage.md). Evite enviar repetidamente mientras una solicitud aún se está procesando. Consulte [Solución de problemas](troubleshooting.md) para conocer las acciones fallidas.

## Tokens y almacenamiento {#tokens-and-storage}

Subir, visualizar y descargar archivos consume tokens. El tamaño de los archivos también cuenta para el límite de almacenamiento independiente. Los archivos de tareas y conversaciones se cobran al espacio de trabajo del que procede el flujo; las demás cargas usan el espacio seleccionado. Solo se cobran las cargas completadas correctamente. Las transferencias simultáneas pueden dejar el saldo de tokens en negativo. Si se interrumpe una descarga, se cobran los bytes del documento ya transferidos. Consulte [Uso y tokens](usage.md).
