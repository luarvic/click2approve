# Hablemos {#lets-talk}

¿Tienes alguna pregunta sobre un flujo de trabajo, encontraste algo inesperado o tienes una idea para Click2Approve?

## Haz una pregunta {#ask-a-question}

Inicia una conversación en [GitHub Discusiones](https://github.com/luarvic/click2approve/discussions). Incluye lo que estás intentando hacer y dónde necesitas ayuda. Se requiere una cuenta GitHub para publicar.

## Reportar un error {#report-a-bug}

[Abrir un problema](https://github.com/luarvic/click2approve/issues) con los pasos para reproducir el problema, lo que esperaba y lo que sucedió. Deje las contraseñas, los documentos privados y otra información confidencial fuera de los informes públicos.

## Preguntas sobre cuentas privadas y privacidad {#private-account-and-privacy-questions}

Envíe un correo electrónico a [contact@click2approve.com](mailto:contact@click2approve.com) para solicitudes de cuentas, seguridad, legales o de privacidad. No envíe contraseñas ni documentos de identidad innecesarios.

## ¿Necesita un punto de partida? {#need-a-starting-point}

[Lea la guía de introducción](docs/index.md) para conocer los conceptos básicos de solicitudes y tareas.
