# Guide al flusso di lavoro di approvazione dei documenti {#table-of-contents}

Click2Approve è un sistema di approvazione dei documenti. Invia documenti alle persone che devono esaminarli, raccogliere decisioni e firme elettroniche e tenere traccia del risultato. Queste guide spiegano come utilizzare l'app in semplici passaggi.

Una **richiesta** contiene documenti, istruzioni e passaggi del flusso di lavoro. Ogni persona assegnata a un passaggio riceve un **compito**. Una **ricevuta** registra il risultato al termine della richiesta.

Click2Approve dispone anche di una [edizione open source](open-source.md) gratuita per flussi di lavoro personali ospitati autonomamente. Consulta il confronto tra le versioni per le funzionalità incluse e le aggiunte commerciali.
