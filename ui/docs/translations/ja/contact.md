# お問い合わせ {#lets-talk}

ワークフローについて質問がある場合、予想外のことを見つけた場合、または Click2Approve についてのアイデアがありますか?

## 質問する {#ask-a-question}

[GitHub Discussions](https://github.com/luarvic/click2approve/discussions)でご相談ください。目的と、どの部分でサポートが必要かをお知らせください。投稿するには GitHub アカウントが必要です。

## バグを報告する {#report-a-bug}

[問題を開く](https://github.com/luarvic/click2approve/issues) 問題を再現する手順、予想した内容、何が起こったかを記載してください。パスワード、プライベート文書、その他の機密情報は公開レポートから除外してください。

## プライベート アカウントとプライバシーに関する質問 {#private-account-and-privacy-questions}

アカウント、セキュリティ、法的、プライバシーに関するリクエストについては、[contact@click2approve.com](mailto:contact@click2approve.com) にメールしてください。パスワードや不必要な身分証明書を送信しないでください。

## 出発点が必要ですか? {#need-a-starting-point}

リクエストとタスクの基本については、[スタートガイドをお読みください](docs/index.md)。
