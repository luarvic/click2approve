# 登録とサインイン {#registration-and-sign-in}

承認のためにドキュメントを送信したり、タスクを完了するには、Click2Approve にサインインします。あなたのアカウントは、**Personal**、独自のリクエストや電子メールでアドレス指定されたタスク用のワークスペース、および従業員がアクセスできる任意の組織にアクセスできます。タスクのリンクをたどる場合は、タスクの送信先メール アドレスを使用します。

## を登録 {#register}

1. [アプリを開き](/app/)、登録オプションを選択します。
2. フォームの要件を満たすメールアドレスとパスワードを入力します。
3. パスワードを確認します。 [規約](../terms.md) と [プライバシー ポリシー](../privacy.md) を確認し、**I agree to the Terms and acknowledge the Privacy Policy** にチェックを入れて送信します。
4. 電子メールによる確認が必要な場合は、確認メッセージを開いてそのリンクをクリックします。
5. サインインして、[プロフィール](profile.md) を入力します。

**Sign up** は、同意ボックスにチェックを入れるまで無効のままです。

登録すると、Personal ワークスペースが作成されます。組織のメンバーシップは、[従業員](employees.md) を通じて個別に管理されます。

## にサインイン {#sign-in}

メールアドレスとパスワードを入力してください。オーセンティケータ MFA が有効になっている場合は、オーセンティケータ コードまたはリカバリ コードを使用して追加のチャレンジを完了します。サポートされている場合は、登録済みの [パスキー](security.md) を使用することもできます。

タスクまたはリクエストメールから到着したら、アクセス権のあるアカウントでサインインします。リンクはリソースの権限をバイパスできません。

## メールアドレス を確認してください {#confirm-your-email}

確認メッセージが見つからない場合は、スパムを確認し、再送信確認オプションを使用してください。使用するアカウントのアドレスを確認してください。リンクの有効期限が切れているか、受け入れられない場合は、結果ページで **Request a new verification email**を選択してください。検証が成功したら、**Sign in** を選択して続行します。

## 忘れたパスワードをリセットする {#reset-a-forgotten-password}

サインイン画面でパスワード リセット オプションを選択し、電子メールを入力し、リセット メッセージに従って新しいパスワードを設定します。電子メール送信結果ページとパスワード リセット結果ページには、それぞれ **Sign in**ボタンがあります。リセットが成功したら、**Sign in** を選択して続行します。パスワードのリセットと電子メールによる確認は別のフローです。

オーセンティケータまたはパスキーのアクセスの問題については、[MFA とパスキー](security.md) および [トラブルシューティング](troubleshooting.md) を参照してください。
