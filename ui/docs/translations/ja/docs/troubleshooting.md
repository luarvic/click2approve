# ドキュメント承認の問題のトラブルシューティング {#troubleshooting}

承認タスクが見つからない、リクエストを送信できない、または完了記録リンクを開けない場合は、まずアカウントと選択したワークスペースを確認してください。リクエストまたはタスクを開いて現在のステータスを確認します。次に、失敗したアクションのエラー メッセージを読みます。

## リクエストまたはタスク が見つかりません {#i-cannot-find-a-request-or-task}

メールアドレス指定されたタスクが **Personal** に表示されます。従業員とチームの割り当てが組織に表示されます。アカウントの電子メール、従業員のステータス、チームのメンバーシップ、および委任を確認します。タスクは、キャンセル、スキップ、完了、置き換え、または削除されている場合もあります。

電子メール リンクでは、組織にアクセス権が付与されません。 [ワークスペースとナビゲーション](workspaces.md) を参照してください。

**Page not found**と表示される場合は、ページが移動したか、ページにアクセスできない可能性があります。 [**Home**] を選択して戻り、アカウントとワークスペースを確認してください。

## メニュー項目またはアクションがありません {#a-menu-item-or-action-is-missing}

[機能と利用可能性](features.md) を確認してください。従業員、チーム、代表団、テンプレートには組織のワークスペースが必要です。役割、プラン、または請求ステータスによって、コントロールが非表示になったり無効になったりする場合があります。正しい組織を選択し、所有者または管理者にアクセスの確認を依頼してください。

## アップデート後にアプリがリロードされる {#the-app-reloads-after-an-update}

アプリは、新しいリリースを検出して現在のページを再度開くと、自動的にリロードされます。保存していないテキストは失われる可能性があります。

## 送信またはタスクの完了に失敗します {#submission-or-task-completion-fails}

強調表示されたフィールドを修正し、必要なコメント、署名、添付ファイルをすべて入力します。アップロードが完了するまで待ちます。メッセージに許容量について記載されている場合は、[使用法](usage.md) を確認してください。

API エラーの後に再試行する前にリソースを更新してください。別の参加者または代理人がすでに完了している可能性があります。リクエストまたはタスクをチェックして、元のアクションが成功したかどうかを確認してから、それを繰り返す前に判断してください。

## リクエスト を改訂できません {#i-cannot-revise-a-request}

再送信は、新しいリビジョンがなく、結果が成功していない対象となるリクエストに対してのみ使用できます。新しいリビジョンによりワークフローが再開されます。以前の決定は以前のリビジョンに残ります。 [リクエストの追跡と修正](track-requests.md) を参照してください。

## 確認リンクが機能しない {#a-verification-link-does-not-work}

リンクの有効期限が切れているか、取り消されているか、完了記録が削除されている可能性があります。 完了記録の所有者に有効なリンクを依頼してください。 [完了記録と確認](receipts.md).

## サインインできない、または電子メールを受信できない {#i-cannot-sign-in-or-receive-email}

電子メールの確認が必要かどうかを確認し、必要に応じて新しい確認メッセージまたはパスワード リセット メッセージを要求します。スパムとアカウント アドレスを検査します。 MFA の場合は、未使用のリカバリ コードを試してください。パスキーについては、登録済みの互換性のあるデバイスまたはパスワードによるサインインを試してください。

[登録とサインイン](sign-in.md)、[MFA とパスキー](security.md)、および [通知](notifications.md) を確認してください。

## ワークスペースは支払いのためにブロックされています。 {#the-workspace-is-blocked-for-payment}

**Plans** を開き、表示された期限までに支払い回復アクションに従います。組織の所有者または管理者は、組織の支払いを管理する必要があります。 [プランと請求](plans-and-billing.md) を参照してください。

## 削除はブロックされています {#deletion-is-blocked}

依存関係メッセージをお読みください。別のレコードが依然として従業員、チーム、またはワークフロー エンティティを参照している可能性があります。関連レコードを削除する前に、[保持と削除](retention.md) を確認してください。

## ヘルプを入手するか、バグを報告してください {#get-help-or-report-a-bug}

アプリの **Report a bug**または**Ask question**リンクを使用してください。再現手順、期待される結果、実際の結果、おおよその時間、関連するワークスペースの種類を含めます。 API エラーで**Details** が表示される場合は、診断情報を確認し、サポート チャネルに適切なもののみを含めてください。

パスワード、API トークン、リカバリ コード、確認リンク、および非公開ドキュメントを公開レポートに含めないでください。アカウント、電子メール、セキュリティ、または請求に関する問題については、サポートにお問い合わせください。
