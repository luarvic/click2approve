# プロフィールと保存された電子署名 {#profile-and-signature}

プロフィール メニューから **User profile** を開き、名前を更新したり、デフォルトのワークスペースを選択したり、将来の承認タスクのために署名を保存したりできます。これらの設定はアカウントに属し、アクセスできるワークスペース全体で共有されます。

## 個人情報 {#personal-details}

**Profile**で、必要に応じて名、姓、アバター、デフォルトのワークスペースを更新します。プロフィールフィールドを編集するかアバターを選択した後、**Save** を選択します。デフォルトのワークスペースは、どこから開始するかを制御します。リクエストやタスクはワークスペース間で移動されません。

アバター画像は最大 **4 MiB** (4,194,304 バイト) まで可能です。

組織の従業員の名前と役職は、[従業員](employees.md) で個別に管理されます。組織の帰属が間違っている場合は、所有者または管理者に従業員レコードを確認するよう依頼してください。

## 保存された署名 {#saved-signature}

1. **Signature** タブを開きます。
2. デフォルトの署名を描画または更新します。
3. **Save** を選択します。

保存された署名は、承認リクエストに署名するときに事前に入力されます。各決定の前にそれを確認し、署名フォームで要求された正式な名前と代表者の詳細を確認してください。プロファイルに署名を保存しても、タスクは署名または完了しません。

## その他のプロファイル タブ {#other-profile-tabs}

オーセンティケーター MFA には **Security**を使用し、デバイス認証情報には**Passkeys**を、デバイス認証情報には**API tokens**を使用します。 API 認証情報、および配信設定については**Notifications**。

[MFA とパスキー](security.md)、[API トークン](api-tokens.md) を参照してください。対応するコントロールの [通知](notifications.md)。
