# 文書承認ワークフロー ガイド {#table-of-contents}

Click2Approve は文書承認システムです。文書をレビューする必要がある人に文書を送信し、決定事項と電子署名を収集し、結果を追跡します。これらのガイドでは、アプリの使用方法を簡単な手順で説明します。

**リクエスト**には、ドキュメント、手順、ワークフロー ステップが含まれます。ステップに割り当てられた各人は **タスク**を受け取ります。 **完了記録**には、リクエストが終了したときの結果が記録されます。

Click2Approve には、自己ホスト型の個人ワークフロー用の無料の [オープンソース版](open-source.md) もあります。含まれる機能と商用追加機能については、エディションの比較を参照してください。
