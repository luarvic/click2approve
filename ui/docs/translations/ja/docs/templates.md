# ドキュメント承認ワークフロー テンプレートを再利用する {#workflow-templates}

同じ承認プロセスを通じてドキュメントを頻繁に送信する場合は、ワークフロー テンプレートを使用します。テンプレートには、組織内のリクエストのステップと参加者が保存されます。各リクエストを作成するときに現在のドキュメントを追加します。

たとえば、提案のレビュー ステップとその後に署名ステップを保存します。次の提案でこれらの手順を再利用し、送信する前にレビュー担当者、署名者、およびファイルを確認してください。

各テンプレートは、その作成者に属します。テンプレートはデフォルトではプライベートです。同じ組織の他のアクティブなメンバーがテンプレートを表示して使用できるようにするには、**Shared** を選択します。他のメンバーが所有者または管理者の場合を含め、作成者のみが編集または削除できます。

!!! info "組織のみ"
    ワークフロー テンプレートを作成して再利用する組織を選択します。テンプレートはその組織に属しており、Personal では使用できません。

## テンプレート を作成する {#create-a-template}

組織で **Templates** を開き、わかりやすい名前と再利用可能な手順を持つテンプレートを作成します。アクション、指示、担当者、完了ルール、表示設定、および追加の要件を設定して保存します。

他の組織メンバーが再利用する必要がある場合は、**Shared**を選択してください。テンプレートを非公開にするには、チェックを外したままにしておきます。テンプレート リストには**Shared**と**Owner** が表示されるため、利用可能なワークフローとその作成者を識別できます。

共有テンプレート名は組織内で一意である必要があります。プライベート テンプレート名は、その組織内の独自のプライベート テンプレート間で一意である必要があります。共有 **Budget**テンプレートとプライベート**Budget**テンプレートの両方を所有できます。テンプレートの名前を変更するか、**Shared** を変更する場合も、これらのルールを満たす必要があります。

組織内でテンプレートを使わずに新しいリクエストを作成する際、**Save template** は、タイトル、説明、ステップからプライベート テンプレートを作成します。同じテンプレート検証ルールが適用され、既存のテンプレートは上書きされません。タイトルがプライベート テンプレート名のいずれかと競合する場合は、保存する前に別のタイトルを選択してください。保存した内容を確認します。ワークフロー テンプレートには、完了したリクエストやその記録された決定ではなく、ステップ構成が保存されます。

## テンプレートからリクエストを開始します {#start-a-request-from-a-template}

1. 同じ組織内の **New request** を選択します。
2. **From template** を選択し、テンプレートまたは共有組織テンプレートの 1 つを選択して、続行します。
3. リクエストのタイトル、説明、現在のドキュメントを入力します。
4. **Submit** を選択する前に、すべての参加者と手順を確認してください。

テンプレートは開始時の構成を提供します。従業員とチームが新しいリクエストにまだ適切であることを確認してください。テンプレートが特定のトランザクション用のファイルを提供すると想定しないでください。

ピッカーは **Private templates**と**Shared templates** を個別にグループ化します。両方のグループに同じ名前のテンプレートが含まれている場合は、適切なグループから名前を選択します。

編集を開始する前に、エディタによってテンプレートが読み込まれます。その名前と説明は、最初のリクエスト テキストを提供します。送信する前に現在のリクエストに合わせて変更してください。

## テンプレート を維持します {#maintain-templates}

**Templates** を開いて、定期的な指示と参加者の選択を更新します。アクティブな組織メンバーは誰でも、独自のテンプレートを作成および管理できます。テンプレートを編集しても、すでに送信されたリクエストは変更されません。

他のメンバーが共有しているテンプレートは、読み取り専用ビューで開きます。再利用可能なステップを変更する必要がある場合は、テンプレートを更新するように作成者に依頼してください。 **Shared**をクリアすると、他のメンバーのテンプレートへのアクセスが削除されます。そこからすでに作成されたリクエストは、コピーされたワークフローを保持します。**Save template**は、カスタムの新しいリクエストでのみ使用できます。既存のテンプレートを変更するには、**Templates**を使用します。テンプレートから開始されたリクエストとリクエスト リビジョンには**Save template** は提供されません。

使用可能な削除アクションを使用して未使用のテンプレートを削除します。削除が参照によってブロックされている場合は、繰り返し再試行するのではなく、検証メッセージに従ってください。
