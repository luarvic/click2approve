# MFA とパスキー {#mfa-and-passkeys}

**多要素認証 (MFA)**または**パスキー** を使用して、Click2Approve アカウントを保護します。認証システム MFA を使用すると、パスワードの後に認証アプリからコードを入力します。パスキーを使用すると、ブラウザのプロンプトを使用して、サポートされているデバイスまたはセキュリティ キーを介してサインインできます。

これらの設定は、Personal と組織のワークスペース全体のアカウントに適用されます。

## 認証システムを有効にする MFA {#enable-authenticator-mfa}

1. **User profile → Security** を開きます。
2. **Use multi-factor authentication** を有効にします。
3. 認証アプリでセットアップ QR コードをスキャンするか、セットアップ キーを手動で入力します。
4. 認証システムからの確認コードを入力してセットアップを確認します。
5. リカバリ コードを安全な場所に保存し、保存したことを確認します。
6. **Done — sign in again** を選択し、パスワードと認証コードを使用してサインインします。

セットアップ後のパスワード サインインには、追加の MFA チャレンジが必要です。セットアップを開始するとセッションが変更されます。完了またはキャンセルするには、再度サインインする必要があります。

## リカバリ コード {#recovery-codes}

認証システムにアクセスできない場合は、保存したリカバリ コードを使用してください。

!!! warning "リカバリ コードを安全に保管する"
    各コードは秘密であり、使用できます。一度だけ。 **Generate new recovery codes** は前のセットを置き換えます。新しいコードを閉じる前に保存してください。

新しいリカバリ コードを生成したり、MFA をオフにしたりするには、終了後に再度サインインする必要があります。

MFA を無効にするには、[Security] タブを使用して、要求された検証を完了してください。別のサインイン方法をテストする前に、唯一動作しているサインイン方法を削除しないでください。

## パスキー を追加します。 {#add-a-passkey}

1. **User profile → Passkeys** を開き、新しいパスキー アクションを選択します。
2. 後でわかる名前を入力します。
3. 生体認証、PIN、またはセキュリティ キーを使用して、ブラウザまたはデバイスのプロンプトを完了します。
4. 認証情報がリストに表示されていることを確認します。

サポートされているデバイスとブラウザでは、パスキー サインイン オプションを使用してください。パスキーには互換性のあるデバイスとブラウザが必要です。アカウントを回復できるようにパスワードを保存しておいてください。

## パスキー を削除します {#remove-a-passkey}

パスキー リストで認証情報を選択し、削除アクションを使用します。まず、名前と最後に使用した詳細を確認してください。これを削除すると、その資格情報のアクセスが取り消されます。他の登録されたパスキーは削除されません。

削除後、アプリは互換性のあるパスワード マネージャーに通知し、削除されたパスキーの提供を停止できるようにします。お使いのブラウザまたはパスワード マネージャーがこのアップデートをサポートしていない可能性があります。パスキーがまだ表示される場合は、パスワード マネージャーから手動で削除してください。アカウントにサインインできなくなります。

認証システムを紛失した場合、またはデバイスが使用できない場合は、設定された代替方法またはリカバリ コードを試してください。利用できるものがない場合は、サポートにお問い合わせください。
