# リクエストとタスクのチャット でドキュメントについて話し合う {#discussions}

ドキュメントを承認または署名する前に、**Chat** を使用してドキュメントについて質問します。ディスカッション内でサポート ファイルを共有できます。チャットは、Personal と組織のワークスペースの両方で利用できます。

## リクエストについて質問する {#ask-about-a-request}

1. アクセス可能なリクエストまたはタスクを開きます。
2. **Chat** を選択します。
3. 既存のメッセージを読んでコンテキストを確認します。
4. メッセージを入力してください。 **Message**内のクリップを使用してサポート ファイルを添付し、**Send** を選択します。

メッセージが右側に表示されます。他の人のメッセージは左側に表示されます。リクエストに応じて、会話はワークフロー ステップごとにグループ化されます。タスクでは、Chat に現在のステップが表示されます。

ステップ見出しの横にある矢印を使用して、参加者をアルファベット順に表示します。リストを非表示にするには、もう一度使用します。参加者リストが非表示になっている場合でも、メッセージは表示されたままになります。

質問や説明にはチャットを使用してください。タスクのアクション コントロールを通じて実際の決定を記録し、それがワークフローの結果となるようにします。

## 参加者とアクセス {#audience-and-access}

ディスカッションへのアクセスは、リクエスト、タスク、および権限によって異なります。共有リンクまたは組織のメンバーシップでは、全員が会話にアクセスできるわけではありません。機密コンテンツを投稿する前にコンテキストを確認してください。

参加者は、組織内で許可されたアクセスを通じてのみ参加します。ディスカッション メッセージと通知には作成者の帰属が保持されます。

## を送信できない場合 {#when-you-cannot-send}

ワークフローに実行可能な保留中のタスクがなくなるか、完了すると、送信が終了することがあります。 メッセージ入力欄 が使用できない場合は、リソースを更新し、現在の状態とアクセス権を確認してください。新しいメッセージが許可されなくなっても、ディスカッションは引き続き読むことができます。

## 通知 {#notifications}

ディスカッションの通知は、[チャット通知設定](notifications.md) とそのメッセージの受信を許可されている視聴者によって異なります。チャットで送信されるファイルは、必須の [決定添付ファイル](files.md) とは別のものです。
