# ワークスペースとナビゲーション {#workspaces-and-navigation}

**ワークスペース**は、アクセスできるリクエスト、タスク、設定をグループ化します。誰もが、自分の電子メール アドレスに送信される自分のリクエストやタスク用のワークスペースである**Personal** から始めます。自分も組織に属している場合は、ワークスペース ピッカーを使用して、その組織の共有作業に切り替えます。 [ユーザー プロフィール](profile.md) で優先開始ワークスペースを設定します。

## Personal {#personal}

個人的に送信するリクエストやアカウントのメール アドレス宛てのタスクには、Personal を使用します。 Personal には従業員またはチームのディレクトリがありません。

組織があなたの電子メール アドレスにタスクを送信する場合があります。そのタスクは Personal で受信します。これによって従業員になったり、組織のワークスペースにアクセスできるようになったりするわけではありません。 Personal タスク リストには送信元の組織が表示されるため、送信者を区別できます。

## 組織 {#organizations}

組織の作業は、選択した組織内に留まります。従業員とチームのタスクは、その組織の Tasks ビューに表示されます。 Requests ビューには、リクエスタ ID、チーム関係、承認された委任を通じて利用できる作業が含まれます。

従業員と委任は同じ組織に属している必要があります。 1 つの組織のメンバーシップによって、別の組織のリクエストやタスクへのアクセスが許可されるわけではありません。

アクセスを委任されている場合、ワークスペース ピッカーには、代表された従業員の名前を含む組織エントリも表示されます。そのエントリを選択して、彼らに代わって作業します。独自のエントリを選択して作業に戻ります。 [委任](delegations.md) を参照してください。

ブランド名の右上隅の横にある小さなチップには、商用アプリでは **App**、オープンソース アプリでは **Free**、ドキュメント ポータルでは **Docs** と表示されます。

## Mainメニュー {#main-menu}

|エリア |目的 |
| --- | --- |
| Tasks |自分に割り当てられたアクション、またはワークフロー内の組織の役割を通じて利用できるアクションを確認します |
| Requests |アクセスできるリクエストに従ってください。新しいリクエストを使用して作業を送信します — New request |
| Receipts |いずれかのワークスペース タイプで発行された完了記録を表示、共有、削除します |
| Templates |組織ワークフローのステップを再利用する |
| Employees, Teams, Delegations |組織のメンバーシップと委任された作業を処理する |
| Plans, Usage, Retention |サブスクリプション、制限、データ設定を確認する |
| Organizations |ビジネス ワークスペースの作成と管理 |

アカウント設定と通知設定にはプロファイル メニューを使用します。アプリバーのベルをクリックすると、選択したワークスペースの通知が開きます。ナビゲーション ドロワーは、小さい画面のメニュー ボタンから開くことができます。カラーモードを切り替えると、同じサイト上のアプリとドキュメントの両方の外観が変わります。

小さな大文字のラベルは、ナビゲーション グループ、カード、セクション、ワークフロー ステップを識別します。ページのタイトルとコントロールは大文字と小文字を使用します。親ページに戻るには、ページ タイトルの上にあるブレッドクラム リンクを使用します。メイン メニューで **Docs**を選択し、現在のタブでユーザー ガイドを開きます。 Web サイトのドキュメント リンクとコンテキスト**Read documentation** リンクも現在のタブを使用します。オープンソース アプリでは、ドキュメントで [オープンソース版](open-source.md) ガイドと機能比較が開きます。

グリッドでは、緑色のタイトルと名前がリンクです。キーボードでホバーまたはフォーカスすると下線が表示されます。キーボード フォーカスには、アウトラインも表示されます。

フッターには、ホーム、アプリ、ドキュメント、連絡先、利用規約、およびプライバシーのリンクが含まれています。それぞれが現在のタブで開きます。

サイトやドキュメントのヘッダーで言語を選ぶと、同じページを別の言語で読めます。選択はこのブラウザーに保存されます。アプリから英語のサイトやドキュメントのリンクを開くと、保存した言語へ移動します。ただし、URLに言語が明示されている場合はそちらを優先します。検索結果もURLの言語に対応します。アプリは現在英語のため、ガイドでは画面上の項目名を英語のまま示し、選択した言語で意味を説明します。

メイン メニューでは、関連ページが **Work**、**Access**、**People**、**Subscription**、**Support**の下にグループ化されています。グループは、選択したワークスペースでその機能が利用可能な場合にのみ表示されます。**Support**の下にある**Replay user guide** を選択すると、アプリ バーとナビゲーションのガイド付き紹介が表示されます。 [はじめに](getting-started.md#take-a-quick-tour) を参照してください。

## 共有リンクを開く {#open-a-shared-link}

メールまたは共有リソースのリンクをたどるときに、目的のアカウントでサインインします。リンクによって追加の権限が付与されることはありません。リソースが使用できない場合は、ワークスペース、アカウント、従業員のアクセス権、およびレコードが削除されているかどうかを確認してください。 [トラブルシューティング](troubleshooting.md) を参照してください。
