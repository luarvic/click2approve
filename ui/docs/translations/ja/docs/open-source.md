# オープンソースのドキュメント承認システム {#open-source-document-approval-system}

Click2Approve は、MIT ライセンスを取得した無料のオープンソース ドキュメント承認システムで、独自のインフラストラクチャでホストできます。ドキュメントをアップロードし、電子メール アドレスでレビュー担当者を割り当て、複数ステップの承認ワークフローを通じてレビュー担当者の決定を追跡します。タスクに説明が必要な場合は、電子署名をリクエストしたり、コメントを要求したりできます。

オープンソース版は、個人または商用目的での個人アカウントおよび個人ドキュメントのワークフローをサポートしています。 Click2Approve ライセンス料はかかりません。インフラストラクチャとプロバイダーのコストはお客様が負担します。開始するには、[ソース コードとセルフホスティングの手順](https://github.com/luarvic/click2approve) を参照してください。

商用バージョンでは、組織のワークスペース、コラボレーション ツール、サブスクリプション ベースの使用と保持の制御が追加されます。このポータルの他のガイドでは商用サービスについて説明しています。この比較を使用して、どの機能がオープンソース エディションに適用されるかを確認してください。

## 例: 提案 を確認して承認する {#example-review-and-approve-a-proposal}

1. プロポーザルをアップロードし、それをレビューする必要がある人のための承認ステップを追加します。
2. ステップに割り当てられた全員が応答する必要があるか、または 1 人のレビュー担当者が完了できるかを選択します。ワークフロー ステップは順番に実行され、複数の担当者が各ステップ内で行動できます。
3. プロポーザルに電子署名も必要な場合は、署名ステップを追加します。
4. リクエストの進行状況を追跡し、**Requests**から記録された決定を追跡します。各参加者は、**Tasks** で自分に割り当てられた作業を見つけます。

ワークフロー コントロールについては、[リクエストの作成](create-a-request.md) および [ワークフロー ステップの構成](workflow-steps.md) を参照してください。共有可能な完了記録とファイル検証は商用機能です。エディションを選択する際は、以下の比較を参照してください。

## オープンソース アプリ を使用します {#use-the-open-source-app}

1. サインアップするか、アカウントでサインインします。
2. **New request** を選択し、ファイルをアップロードし、担当者の電子メール アドレスを使用してワークフロー ステップを構成します。共有ワークフロー コントロールについては、[リクエストの作成](create-a-request.md) および [ワークフロー ステップの構成](workflow-steps.md) を参照してください。
3. 送信した作業を追跡するには **Requests**を使用し、割り当てられたアクションを完了するには**Tasks** を使用します。コメントと署名については、[タスクを完了する](complete-a-task.md) を参照してください。応答の添付ファイルは商用バージョンで利用できます。

組織ナビゲーションと商用ツールはオープンソース アプリに隠されています。プロフィール、保存された署名、通知設定、MFA、およびパスキーは、プロフィール メニューから管理できます。
