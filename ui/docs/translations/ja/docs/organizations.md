# 組織の管理 {#manage-organizations}

**組織**は、ビジネスに代わって送信される文書承認のためのワークスペースです。独自のリクエスト、従業員、チーム、テンプレート、委任された作業を保持します。リクエストを作成したり、そのメンバーを管理したりする前に、ワークスペース ピッカーで選択します。

!!! info "組織ワークスペース"
    共有作業を管理する組織を作成または選択します。 Personal ワークスペースには、従業員、チーム、テンプレート、または委任がありません。

## 組織 を作成します {#create-an-organization}

1. **Organizations** を開いて、新しい組織を開始します。
2. 詳細を入力し、必要に応じてロゴを追加します。
3. 計画の選択を続けます。 **Back** を使用して、作成の下書きを保持しながら詳細を編集します。
4. **Choose Business Trial**または**Choose Business Pro**を選択し、カードの下にある**Subscribe** を使用して組織を作成します。
5. 有料プランの場合は、チェックアウトを完了してください。支払いが確認されるまで、ワークスペースへのアクセスは制限されたままになります。

ビジネス トライアルは、所有者ごとに 1 回利用できます。再度選択すると検証に失敗します。支払いと回収の動作については、[プランと請求](plans-and-billing.md) を参照してください。

## ワークスペース を設定します {#set-up-the-workspace}

ワークスペース ピッカーで組織を選択し、次の手順を実行します:

- [従業員](employees.md) を追加し、従業員を選択します
- 定期的な参加者グループ用に [チーム](teams.md) を作成します。
- 代わりに行動してくれる人が必要な従業員用に [委任](delegations.md) を構成します。
- 繰り返し用に [ワークフロー テンプレート](templates.md) を保存します。

従業員、チーム、および代表者は、この組織に属している必要があります。別の組織での作業は分離されたままです。

## 組織の詳細 を更新 {#update-organization-details}

**Organizations**から組織を開いて、ロールで許可されている詳細を編集します。ロゴ画像は最大**4 MiB** (4,194,304 バイト) まで可能です。参加者がリクエスト コンテキストや通知で組織を識別できるように、ビジネス名とロゴを認識できるようにしてください。

## 組織を削除する {#delete-an-organization}

**Owner**のみが**Delete organization** を通じて削除をスケジュールできます。確認事項をよくお読みください。スケジュールされた組織はワークスペースの選択から消え、アクセスできなくなります。バックグラウンド処理により、後でデータが削除されます。

!!! warning "削除前にレコードを保存"
    削除をスケジュールすると、組織へのアクセスがすぐに削除されます。確認する前に必要な記録を保存してください。クリーンアップの遅延は回復期間ではありません。 [保持と削除](retention.md) を参照してください。
