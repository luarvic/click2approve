# 문서 승인 워크플로 가이드 {#table-of-contents}

Click2Approve는 문서 승인 시스템입니다. 문서를 검토하고, 결정 사항과 전자 서명을 수집하고, 결과를 추적해야 하는 사람들에게 문서를 보냅니다. 이 가이드에서는 간단한 단계로 앱을 사용하는 방법을 설명합니다.

**요청**에는 문서, 지침 및 워크플로 단계가 포함됩니다. 단계에 할당된 각 사람은 **작업**을 받습니다. 요청이 완료되면 **완료 기록**에 결과가 기록됩니다.

Click2Approve에는 자체 호스팅 개인 워크플로를 위한 무료 [오픈 소스 버전](open-source.md)도 있습니다. 포함된 기능과 상용 추가 사항에 대한 버전 비교를 확인하세요.
