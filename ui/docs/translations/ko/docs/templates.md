# 문서 승인 워크플로 템플릿 재사용 {#workflow-templates}

동일한 승인 프로세스를 통해 문서를 자주 보낼 때 워크플로 템플릿을 사용하세요. 템플릿은 조직 내부의 요청 단계와 참가자를 저장합니다. 각 요청을 생성할 때 현재 문서를 추가합니다.

예를 들어 제안서 검토 단계와 서명 단계를 저장합니다. 다음 제안에 이러한 단계를 재사용한 다음 제출하기 전에 검토자, 서명자, 파일을 확인하세요.

각 템플릿은 템플릿을 만든 사람의 소유입니다. 템플릿은 기본적으로 비공개입니다. 동일한 조직의 다른 활성 구성원이 템플릿을 보고 사용할 수 있도록 하려면 **Shared**를 선택합니다. 다른 구성원이 소유자 또는 관리자인 경우를 포함하여 작성자만 편집하거나 삭제할 수 있습니다.

!!! info "조직만"
    워크플로 템플릿을 만들고 재사용하려면 조직을 선택하세요. 템플릿은 해당 조직에 속하며 Personal에서 사용할 수 없습니다.

## 템플릿 만들기 {#create-a-template}

조직에서 **Templates**를 열고 설명적인 이름과 재사용 가능한 단계가 포함된 템플릿을 만듭니다. 작업, 지침, 담당자, 완료 규칙, 가시성, 추가 요구 사항을 구성한 후 저장하세요.

다른 조직 구성원이 재사용해야 하는 경우 **Shared**를 선택하세요. 템플릿을 비공개로 유지하려면 선택하지 않은 상태로 두세요. 템플릿 목록에는 **Shared**및**Owner**가 표시되므로 사용 가능한 워크플로와 작성자를 식별할 수 있습니다.

공유 템플릿 이름은 조직 내에서 고유해야 합니다. 비공개 템플릿 이름은 해당 조직의 비공개 템플릿 중에서 고유해야 합니다. 공유 **Budget**템플릿과 비공개**Budget**템플릿을 모두 소유할 수 있습니다. 템플릿 이름을 바꾸거나**Shared**를 변경하는 경우에도 이러한 규칙을 충족해야 합니다.

조직에서 템플릿 없이 새 요청을 작성할 때 **Save template**는 제목, 설명 및 단계에서 비공개 템플릿을 생성합니다. 동일한 템플릿 유효성 검사 규칙을 적용하고 기존 템플릿을 덮어쓰지 않습니다. 제목이 비공개 템플릿 이름 중 하나와 충돌하는 경우 저장하기 전에 다른 제목을 선택하세요. 저장한 내용을 검토하세요. 워크플로 템플릿은 완료된 요청이나 기록된 결정이 아닌 단계 구성을 저장합니다.

## 템플릿 {#start-a-request-from-a-template}

1. 같은 조직에서 **New request**를 선택하세요.
2. **From template**를 선택하고 템플릿 중 하나 또는 공유 조직 템플릿을 선택한 후 계속하세요.
3. 요청의 제목, 설명, 현재 문서를 입력하세요.
4. **Submit**를 선택하기 전에 모든 참가자와 단계를 검토하세요.

템플릿은 시작 구성을 제공합니다. 직원과 팀이 여전히 새 요청에 적합한지 확인하세요. 템플릿이 특정 거래에 대한 파일을 제공한다고 가정하지 마세요.

선택기는 **Private templates**및**Shared templates**를 별도로 그룹화합니다. 둘 다 동일한 이름의 템플릿이 포함된 경우 적절한 그룹에서 이름을 선택하세요.

편집을 시작하기 전에 편집기가 템플릿을 로드합니다. 해당 이름과 설명은 초기 요청 텍스트를 제공합니다. 제출하기 전에 현재 요청에 맞게 변경하세요.

## 템플릿 유지 {#maintain-templates}

**Templates**를 열어 반복 지침과 참가자 선택을 업데이트하세요. 활동 중인 조직 구성원은 누구나 자신의 템플릿을 만들고 관리할 수 있습니다. 템플릿을 편집해도 이미 제출된 요청은 변경되지 않습니다.

다른 회원이 공유한 템플릿은 읽기 전용 보기로 열립니다. 재사용 가능한 단계를 변경해야 할 경우 작성자에게 템플릿을 업데이트하도록 요청하세요. **Shared**를 지우면 템플릿에 대한 다른 구성원의 액세스 권한이 제거됩니다. 이미 생성된 요청은 복사된 워크플로를 유지합니다.

**Save template**는 맞춤 새 요청에만 사용할 수 있습니다. 기존 템플릿을 변경하려면 **Templates**를 사용하세요. 템플릿에서 시작된 요청 및 요청 수정본은 **Save template**를 제공하지 않습니다.

사용 가능한 삭제 작업을 통해 사용하지 않는 템플릿을 제거하세요. 참조로 인해 삭제가 차단된 경우 반복해서 다시 시도하기보다는 확인 메시지를 따르세요.
