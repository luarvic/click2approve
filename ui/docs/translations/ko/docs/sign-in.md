# 등록 및 로그인 {#registration-and-sign-in}

Click2Approve에 로그인하여 승인을 위해 문서를 보내거나 작업을 완료하세요. 귀하의 계정은 **Personal**, 귀하의 요청과 이메일 주소 작업을 위한 작업 공간, 직원 액세스 권한이 있는 모든 조직에 액세스할 수 있습니다. 작업 링크를 따라갈 때 작업이 전송된 이메일 주소를 사용하세요.

## 등록 {#register}

1. [앱을 열고](/app/) 등록 옵션을 선택하세요.
2. 양식 요구 사항을 충족하는 이메일과 비밀번호를 입력하세요.
3. 비밀번호를 확인하세요. [약관](../terms.md) 및 [개인정보취급방침](../privacy.md)을 검토한 후 **I agree to the Terms and acknowledge the Privacy Policy**를 확인하고 제출하세요.
4. 이메일 확인이 필요한 경우 확인 메시지를 열고 링크를 따라가세요.
5. 로그인하고 [프로필](profile.md)을 작성하세요.

**Sign up**는 계약 상자를 선택할 때까지 비활성화된 상태로 유지됩니다.

등록하면 Personal 작업 공간이 생성됩니다. 조직 멤버십은 [직원](employees.md)을 통해 별도로 관리됩니다.

## 로그인 {#sign-in}

이메일과 비밀번호를 입력하세요. 인증자 MFA가 활성화된 경우 인증자 코드 또는 복구 코드를 사용하여 추가 인증을 완료하세요. 지원되는 경우 등록된 [패스키](security.md)를 사용할 수도 있습니다.

작업이나 요청에 관한 이메일의 링크를 열 때 액세스 권한이 있는 계정으로 로그인하세요. 링크는 리소스의 권한을 우회할 수 없습니다.

## 이메일 확인 {#confirm-your-email}

확인 메시지를 찾을 수 없는 경우 스팸을 확인하고 재전송 확인 옵션을 사용하세요. 사용하려는 계정의 주소를 확인하세요. 링크가 만료되었거나 수락할 수 없는 경우 결과 페이지에서 **Request a new verification email**를 선택하세요. 확인에 성공한 후 **Sign in**를 선택하여 계속 진행하세요.

## 잊어버린 비밀번호 재설정 {#reset-a-forgotten-password}

로그인 화면에서 비밀번호 재설정 옵션을 선택하고 이메일을 입력한 후 재설정 메시지에 따라 새 비밀번호를 설정하세요. 이메일 전송 및 비밀번호 재설정 결과 페이지에는 각각 **Sign in**버튼이 있습니다. 재설정이 성공한 후**Sign in**를 선택하여 계속 진행합니다. 비밀번호 재설정과 이메일 확인은 별도의 흐름입니다.

인증자 또는 비밀번호 키 액세스 문제는 [MFA 및 비밀번호](security.md) 및 [문제 해결](troubleshooting.md)을 참조하세요.
