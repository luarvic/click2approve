# 인증 앱 MFA 및 패스키 설정 {#mfa-and-passkeys}

**다단계 인증(MFA)**또는**패스키**로 Click2Approve 계정을 보호하세요. 인증기 MFA를 사용하면 비밀번호 뒤에 인증기 앱의 코드를 입력할 수 있습니다. 암호 키를 사용하면 브라우저 프롬프트를 사용하여 지원되는 기기 또는 보안 키를 통해 로그인할 수 있습니다.

이러한 설정은 Personal 및 조직 작업 공간 전체의 계정에 적용됩니다.

## 인증자 MFA {#enable-authenticator-mfa}

1. **User profile → Security**를 엽니다.
2. **Use multi-factor authentication**를 활성화합니다.
3. 인증 앱에서 설정 QR 코드를 스캔하거나 설정 키를 수동으로 입력하세요.
4. 설정을 확인하려면 인증기에서 받은 인증 코드를 입력하세요.
5. 복구 코드를 안전한 곳에 저장하고 저장했는지 확인하세요.
6. **Done — sign in again**를 선택한 다음 비밀번호와 인증 코드로 로그인하세요.

설정 후 비밀번호 로그인을 위해서는 추가 MFA 질문이 필요합니다. 설정을 시작하면 세션이 변경됩니다. 완료하거나 취소하려면 다시 로그인해야 합니다.

## 복구 코드 {#recovery-codes}

인증기에 액세스할 수 없으면 저장된 복구 코드를 사용하세요.

!!! warning "복구 코드를 안전하게 유지하세요"
    각 코드는 비밀입니다. 한 번만 사용할 수 있습니다. **Generate new recovery codes**는 이전 세트를 대체합니다. 새 코드를 삭제하기 전에 저장하세요.

새 복구 코드를 생성하거나 MFA를 끄려면 완료 후 다시 로그인해야 합니다.

MFA를 비활성화하려면 Security 탭을 사용하고 요청된 확인을 완료하세요. 다른 로그인 방법을 테스트하기 전에 작동하는 유일한 로그인 방법을 제거하지 마세요.

## 암호 키 추가 {#add-a-passkey}

1. **User profile → Passkeys**를 열고 새 암호 키 작업을 선택하세요.
2. 나중에 알아볼 수 있는 이름을 입력하세요.
3. 생체인식, PIN 또는 보안 키를 사용하여 브라우저 또는 기기 프롬프트를 완료하세요.
4. 목록에 자격 증명이 나타나는지 확인하세요.

지원되는 기기 및 브라우저에서 패스키 로그인 옵션을 사용하세요. 패스키를 사용하려면 호환되는 장치와 브라우저가 필요합니다. 계정 복구를 위해 비밀번호를 보관하세요.

## 암호 키 제거 {#remove-a-passkey}

암호 목록에서 자격 증명을 선택하고 제거 작업을 사용하세요. 이름과 최근 사용 내역을 먼저 확인하세요. 이를 제거하면 해당 자격 증명의 액세스 권한이 취소됩니다. 등록된 다른 비밀번호 키는 제거되지 않습니다.

제거 후 앱은 호환되는 비밀번호 관리자에게 알림을 보내 제거된 비밀번호 키 제공을 중단할 수 있도록 합니다. 귀하의 브라우저 또는 비밀번호 관리자가 이 업데이트를 지원하지 않을 수 있습니다. 암호 키가 계속 나타나면 암호 관리자에서 수동으로 제거하십시오. 더 이상 계정에 로그인할 수 없습니다.

인증기를 분실했거나 기기를 사용할 수 없는 경우 구성된 대체 방법이나 복구 코드를 사용해 보세요. 사용할 수 있는 것이 없으면 지원팀에 문의하여 도움을 받으세요.
