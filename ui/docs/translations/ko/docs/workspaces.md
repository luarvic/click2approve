# 작업 공간 및 탐색 {#workspaces-and-navigation}

**작업 공간**은 액세스할 수 있는 요청, 작업 및 설정을 그룹화합니다. 모든 사람은 자신의 이메일 주소로 전송된 자신의 요청과 작업을 위한 작업 공간인 **Personal**로 시작합니다. 귀하도 조직에 속해 있는 경우 작업공간 선택기를 사용하여 공유 작업으로 전환하세요. [사용자 프로필](profile.md)에서 기본 시작 작업 공간을 설정하세요.

## Personal {#personal}

개인적으로 보내는 요청과 계정의 이메일 주소로 전달되는 작업에 Personal를 사용하세요. Personal에는 직원 또는 팀 디렉터리가 없습니다.

조직에서 귀하의 이메일 주소로 작업을 보낼 수 있습니다. Personal에서 해당 작업을 받습니다. 이는 귀하를 직원으로 만들거나 조직의 작업 공간에 대한 액세스 권한을 부여하지 않습니다. Personal 작업 목록에는 보낸 사람을 구별할 수 있도록 원래 조직이 표시됩니다.

## 조직 {#organizations}

조직 작업은 선택한 조직 내에 유지됩니다. 직원 및 팀 작업이 해당 조직의 Tasks 보기에 나타납니다. Requests 보기에는 요청자 신원, 팀 관계, 승인된 위임을 통해 사용할 수 있는 작업이 포함됩니다.

직원과 대리인은 동일한 조직에 속해야 합니다. 한 조직의 멤버십은 다른 조직의 요청이나 작업에 대한 액세스 권한을 부여하지 않습니다.

액세스 권한을 위임하면 워크스페이스 선택기는 대표 직원의 이름이 포함된 조직 항목도 제공합니다. 대신 작업하려면 해당 항목을 선택하십시오. 작업으로 돌아가려면 자신의 항목을 선택하세요. [업무 위임](delegations.md)을 참조하세요.

브랜드 이름의 오른쪽 상단 모서리 옆에 있는 작은 칩은 상용 앱에서는 **App**, 오픈 소스 앱에서는 **Free**, 문서 포털에서는 **Docs**입니다.

## 메인 메뉴 {#main-menu}

| 면적 | 목적 |
| --- | --- |
| Tasks | 워크플로에서 귀하에게 할당되었거나 조직 역할을 통해 사용할 수 있는 작업을 검토하세요 |
| Requests | 귀하가 액세스할 수 있는 요청을 따르십시오. 새 요청을 사용하여 작업 보내기 — New request |
| Receipts | 워크스페이스 유형 중 하나에서 발행된 완료 기록 보기, 공유 및 삭제 |
| Templates | 조직 워크플로 단계 재사용 |
| Employees, Teams, Delegations | 조직 멤버십 및 업무 위임 작업 |
| Plans, Usage, Retention | 구독, 한도, 데이터 설정 검토 |
| Organizations | 비즈니스 작업 공간 생성 및 관리 |

계정 설정 및 알림 기본 설정에 프로필 메뉴를 사용하세요. 앱 바의 벨을 누르면 선택한 작업 공간에 대한 알림이 열립니다. 탐색 창은 작은 화면의 메뉴 버튼을 통해 열 수 있습니다. 색상 모드 스위치는 동일한 사이트에 있는 앱과 문서의 모양을 모두 변경합니다.

작은 대문자 라벨은 탐색 그룹, 카드, 섹션 및 워크플로 단계를 식별합니다. 페이지 제목과 컨트롤은 문장 케이스를 사용합니다. 상위 페이지로 돌아가려면 페이지 제목 위에 있는 탐색경로 링크를 사용하세요. 현재 탭에서 사용자 가이드를 열려면 메인 메뉴에서 **Docs**를 선택하세요. 웹사이트의 문서 링크와 상황별 **Read documentation** 링크도 현재 탭을 사용합니다. 오픈소스 앱에서 Docs는 [오픈소스 버전](open-source.md) 가이드 및 기능 비교를 엽니다.

그리드에서 녹색 제목과 이름은 링크입니다. 키보드로 마우스를 가져가거나 초점을 맞추면 밑줄이 표시됩니다. 키보드 포커스에는 윤곽선도 표시됩니다.

바닥글에는 홈, 앱, 문서, 연락처, 약관 및 개인정보 보호 링크가 포함되어 있습니다. 각각은 현재 탭에서 열립니다.

사이트나 사용 안내의 헤더에서 언어를 선택하면 같은 페이지를 다른 언어로 읽을 수 있습니다. 선택은 이 브라우저에 저장됩니다. 앱에서 영어 사이트나 사용 안내 링크를 열면 저장된 언어로 이동합니다. 단, URL에 언어 접두사가 명시되어 있으면 해당 언어가 우선합니다. 검색 결과도 URL의 언어로 표시됩니다. 앱은 현재 영어로 제공되므로 가이드에서는 실제 화면의 항목명을 그대로 쓰고 선택한 언어로 뜻을 설명합니다.

기본 메뉴는 **Work**, **Access**, **People**, **Subscription**및**Support**아래에 관련 페이지를 그룹화합니다. 그룹은 선택한 작업 영역에서 해당 기능을 사용할 수 있는 경우에만 나타납니다. 앱 바와 탐색에 대한 소개 안내를 보려면**Support**아래에서**Replay user guide**를 선택하세요. [시작하기](getting-started.md#take-a-quick-tour)를 참조하세요.

## 공유 링크 열기 {#open-a-shared-link}

이메일 또는 공유 리소스 링크를 따라갈 때 원하는 계정으로 로그인하세요. 링크는 추가 권한을 부여하지 않습니다. 리소스를 사용할 수 없는 경우 워크스페이스, 계정, 직원 액세스, 기록 삭제 여부를 확인하세요. [문제 해결](troubleshooting.md)을 참조하세요.
