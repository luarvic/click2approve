# 승인 작업과 요청 관리 위임 {#delegations}

한 직원이 승인 작업 및 요청을 수행하기 위해 다른 직원이 필요한 경우 **위임**을 사용하세요. 예를 들어, 누군가 자리를 비운 동안 동료가 업무를 처리할 수 있습니다. 두 직원 모두 동일한 조직에 속해야 합니다.

!!! info "조직만"
    위임 내용을 보려면 조직을 선택하세요. 소유자와 관리자는 이를 생성, 변경, 제거할 수 있습니다. 두 직원 모두 해당 조직에 속해야 합니다.

## 위임 만들기 {#create-a-delegation}

1. 조직을 선택하고 **Delegations**를 엽니다.
2. 소유자 또는 관리자로서 새로운 위임을 시작하세요.
3. **Employee** — 업무를 대신 처리해 줄 사람이 필요한 직원을 선택하세요.
4. **Delegate**에서 자신을 대신할 직원을 선택하세요.
5. 저장하고 관계의 방향을 확인하세요.

두 직원 모두 선택한 조직에 속해 있어야 합니다. 회원은 위임을 볼 수 있습니다. 소유자와 관리자가 이를 관리합니다. 위임은 다른 조직에 소유권을 이전하거나 멤버십을 부여하지 않습니다.

## 대리인으로 작업 {#work-as-a-delegate}

작업 공간 선택기에서 귀하가 대표하는 직원이 포함된 조직 항목을 선택하세요. 그러면 해당 직원의 작업 대기열이 선택됩니다. 자신의 항목을 선택하면 계속해서 자신의 작업이 표시됩니다. 위임은 대기열을 병합하지 않습니다.

작업 공간 페이지를 새로 고치면 액세스 권한을 위임받은 동안에만 해당 선택 사항이 복원됩니다. 로그아웃하면 선택 항목이 지워집니다.

승인된 작업이나 요청을 열고 해당 컨텍스트를 검토한 후 허용된 조치를 취하세요. 기록에는 실제 사용자와 직원이 보존되므로 해당 작업이 원래 담당자가 취한 작업과 구별될 수 있습니다.

위임 방향이 중요합니다. Alex를 Sam의 대리인으로 선택하면 Alex가 Sam을 대신할 수 있습니다. Sam이 Alex를 대신하여 행동하는 것을 자동으로 허용하지 않습니다.

## 위임 변경 또는 해제 {#change-or-remove-coverage}

소유자와 관리자는 적용 범위가 변경될 때 위임을 편집하거나 삭제할 수 있습니다. 저장된 관계를 검토하고 대리인에게 작업 목록을 새로 고치도록 요청하세요. 위임을 제거해도 위임이 유효한 동안 이미 기록된 결정은 지워지지 않습니다.
