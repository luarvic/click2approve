# 승인 워크플로 통합을 위한 API 토큰 {#api-tokens}

Click2Approve API를 사용하여 자체 도구를 연결하고 승인 워크플로를 자동화하세요. API 토큰을 사용하면 통합이 사용자 계정을 통해 API에 액세스할 수 있습니다. Personal에서 근무하든 조직에서 근무하든 프로필에서 관리하세요.

## 토큰 만들기 {#create-a-token}

1. **User profile → API tokens**를 엽니다.
2. **New API token**를 선택하세요.
3. 필요한 경우 인식 가능한 이름과 만료일을 입력하세요.
4. 대화 상자를 닫기 전에 토큰을 생성하고 해당 값을 복사하세요.
5. 의도한 통합을 위해 안전하게 저장하세요.

!!! warning "닫기 전에 토큰을 복사하세요."
    전체 값은 한 번만 표시됩니다. 안전하게 저장하고 메시지, 스크린샷, 소스 제어에 노출되지 않도록 하세요. 토큰을 분실한 경우 대체 토큰을 만들고 기존 토큰을 취소하세요.

## API 살펴보기 {#explore-the-api}

[API 참조(Swagger UI)]({{ api_reference_url }}){target="_blank" rel="noopener 열기 noreferrer"}를 사용하여 엔드포인트, 요청 필드 및 응답을 찾아보세요.

인증된 요청을 시도하려면 **Authorize**를 선택하고 `Bearer` 접두사 없이 API 토큰을 붙여넣은 후 확인하세요. Swagger가 인증 헤더를 추가합니다. 엔드포인트를 선택하고 **Try it out**를 선택한 후 필수 필드를 입력하고 **Execute**를 선택합니다. 이러한 요청은 귀하의 계정을 사용하며 실제 데이터를 생성, 변경 또는 삭제할 수 있습니다.

계정 보안 엔드포인트에는 대화형 로그인 세션이 필요하며 API 토큰과 함께 사용할 수 없습니다.

## 통합에서 토큰 사용 {#use-a-token-in-your-integration}

에서 토큰 보내기 각 API 요청이 포함된 `Authorization` 헤더:

```http
Authorization: Bearer YOUR_API_TOKEN
```

`YOUR_API_TOKEN`를 토큰 생성 시 복사한 값으로 바꾸세요. 토큰은 귀하의 계정 권한에 따라 작동합니다. 토큰 생성은 다른 사용자의 작업이나 다른 조직의 리소스에 대한 액세스 권한을 부여하지 않습니다. 승인은 여전히 적용됩니다.

## 토큰 취소 {#revoke-a-token}

목록에서 토큰을 선택하고 **Revoke**를 선택한 후 확인하세요. 이를 사용한 모든 통합을 대체 자격 증명으로 업데이트합니다. 노출된 것으로 의심되는 사용되지 않은 토큰과 자격 증명을 취소하세요.

API 토큰은 계정 설정입니다. 작업공간을 전환해도 별도의 토큰 세트가 생성되지 않습니다.
