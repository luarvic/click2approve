# 팀에 문서 승인 단계 할당 {#teams}

Teams는 한 조직 내의 직원을 그룹화하고 문서 승인 단계를 그룹에 할당할 수 있습니다. 예를 들어 제안서를 검토하는 사람들을 위한 팀을 만든 다음 검토 단계를 설정할 때 해당 팀을 선택합니다. 단계의 완료 규칙은 할당된 모든 사람 또는 한 사람이 성공적으로 응답해야 하는지 여부를 제어합니다.

!!! info "조직만"
    팀을 보려면 조직을 선택하세요. 소유자와 관리자는 팀 멤버십을 관리합니다.

## 팀 생성 또는 업데이트 {#create-or-update-a-team}

1. 조직을 선택하고 **Teams**를 엽니다.
2. 소유자 또는 관리자로서 새 팀을 시작하거나 팀을 열어 편집하세요.
3. 인식 가능한 **Name**를 입력하세요.
4. 해당 팀에 속한 조직의 **Employees**를 선택하세요.
5. 멤버십을 저장하고 검토하세요.

구성원은 팀 디렉터리를 볼 수 있습니다. 소유자와 관리자가 관리합니다. 다른 조직의 사람은 이 팀의 직원으로 추가할 수 없습니다.

## 팀에 작업 할당 {#assign-work-to-a-team}

[워크플로 단계](workflow-steps.md)를 구성할 때 담당자 유형으로 **Team**를 선택하고 팀을 선택하세요. 단계의 모든 담당자 또는 모든 담당자 규칙을 확인하여 의도한 완료 요구 사항과 일치하는지 확인하세요.

멤버십 변경 사항은 향후 작업 할당에 적용됩니다. 참가자에게 이미 할당된 작업은 팀을 떠난 후에도 계속 유지됩니다.

팀 관계는 사용자가 사용할 수 있는 조직 작업 및 요청에 영향을 미칩니다. 예상 작업이 누락된 경우 현재 작업 공간과 직원의 팀 멤버십을 모두 확인하세요.

## 팀 제거 {#remove-a-team}

팀이 더 이상 필요하지 않은 경우 사용 가능한 삭제 작업을 사용하세요. 다른 기록의 참조는 삭제를 방지할 수 있습니다. 할당을 변경하거나 활성 워크플로 또는 템플릿에서 사용되는 팀을 제거하기 전에 보고된 관계를 검토하세요.
