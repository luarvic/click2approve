# 프로필 및 저장된 전자 서명 {#profile-and-signature}

프로필 메뉴에서 **User profile**를 열어 이름을 업데이트하거나 기본 작업 공간을 선택하거나 향후 승인 작업을 위해 서명을 저장하세요. 이러한 설정은 귀하의 계정에 속하며 귀하가 액세스할 수 있는 작업 공간 전체에서 공유됩니다.

## 개인 정보 {#personal-details}

**Profile**에서 필요에 따라 이름, 성, 아바타 및 기본 작업 공간을 업데이트하세요. 프로필 필드를 수정하거나 아바타를 선택한 후 **Save**를 선택하세요. 기본 작업 공간은 시작하려는 위치를 제어합니다. 작업 공간 간에 요청이나 작업을 이동하지 않습니다.

아바타 이미지는 최대 **4MiB**(4,194,304바이트)까지 가능합니다.

조직 직원 이름과 직위는 [직원](employees.md)에서 별도로 관리됩니다. 조직 속성이 잘못된 경우 소유자나 관리자에게 직원 기록을 검토하도록 요청하세요.

## 저장된 서명 {#saved-signature}

1. **Signature** 탭을 엽니다.
2. 기본 서명을 그리거나 업데이트하세요.
3. **Save**를 선택하세요.

승인 요청에 서명하면 저장된 서명이 미리 채워집니다. 각 결정 전에 이를 검토하고 서명 양식에서 요구하는 법적 이름과 대표 세부 사항을 확인하십시오. 프로필에 서명을 저장해도 작업이 서명되거나 완료되지 않습니다.

## 기타 프로필 탭 {#other-profile-tabs}

인증자 MFA에는 **Security**를 사용하고, 장치 자격 증명에는 **Passkeys**를 사용하고, **API tokens**를 사용하세요. API 자격 증명 및 전송 기본 설정을 위한 **Notifications**.

[MFA 및 암호 키](security.md), [API 토큰](api-tokens.md) 및 해당 컨트롤에 대한 [알림](notifications.md).
