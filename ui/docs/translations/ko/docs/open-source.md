# 오픈 소스 문서 승인 시스템 {#open-source-document-approval-system}

Click2Approve는 자체 인프라에서 호스팅할 수 있는 무료 MIT 라이선스 오픈 소스 문서 승인 시스템입니다. 문서를 업로드하고, 이메일 주소로 검토자를 지정하고, 다단계 승인 워크플로를 통해 결정을 추적하세요. 작업에 설명이 필요한 경우 전자 서명을 요청하고 설명을 요구할 수 있습니다.

오픈 소스 버전은 개인 또는 상업적 용도로 개인 계정과 개인 문서 워크플로를 지원합니다. Click2Approve 라이센스 비용은 없습니다. 귀하는 인프라 및 공급자 비용을 부담합니다. 시작하려면 [소스 코드 및 자체 호스팅 지침](https://github.com/luarvic/click2approve)을 참조하세요.

상용 버전에는 조직 작업 공간, 공동 작업 도구, 구독 기반 사용 및 보존 제어 기능이 추가됩니다. 이 포털의 다른 가이드에서는 상용 서비스에 대해 설명합니다. 이 비교를 통해 오픈 소스 버전에 어떤 기능이 적용되는지 확인하세요.

## 예: 제안 검토 및 승인 {#example-review-and-approve-a-proposal}

1. 제안서를 업로드하고 이를 검토해야 하는 사람들을 위한 승인 단계를 추가하세요.
2. 단계에 할당된 모든 사람이 응답해야 하는지 아니면 한 명의 검토자가 완료할 수 있는지 선택합니다. 워크플로 단계는 순서대로 실행되며 여러 담당자가 각 단계 내에서 작업을 수행할 수 있습니다.
3. 제안서에 전자 서명도 필요한 경우 서명 단계를 추가하세요.
4. **Requests**에서 요청 진행 상황과 기록된 결정을 추적하세요. 각 참가자는 **Tasks**에서 자신에게 할당된 작업을 찾습니다.

워크플로 제어에 대해서는 [요청 만들기](create-a-request.md) 및 [워크플로 단계 구성](workflow-steps.md)을 참조하세요. 공유 가능한 완료 기록 및 파일 확인은 상용 기능입니다. 에디션을 선택할 때 아래 비교를 참조하세요.

## 오픈 소스 앱 사용 {#use-the-open-source-app}

1. 귀하의 계정으로 가입하거나 로그인하세요.
2. **New request**를 선택하고, 파일을 업로드하고, 담당자의 이메일 주소로 워크플로 단계를 구성하세요. 공유 워크플로 제어에 대해서는 [요청 생성](create-a-request.md) 및 [워크플로 단계 구성](workflow-steps.md)을 참조하세요.
3. **Requests**를 사용하여 보낸 작업을 추적하고 **Tasks**를 사용하여 할당된 작업을 완료하세요. 의견과 서명은 [작업 완료](complete-a-task.md)를 참조하세요. 응답 첨부 파일은 상용 버전에서 사용할 수 있습니다.

조직 탐색 및 상용 도구는 오픈 소스 앱에 숨겨져 있습니다. 프로필 메뉴를 통해 프로필, 저장된 서명, 알림 기본 설정, MFA 및 비밀번호를 관리할 수 있습니다.
