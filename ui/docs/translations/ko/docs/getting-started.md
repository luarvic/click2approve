# 문서 승인 시작하기 {#getting-started}

Click2Approve를 사용하여 검토, 승인 또는 전자 서명을 위해 문서를 보내세요. **요청**은 파일, 지침, 참가자를 포함하여 귀하가 보내는 작업입니다. **작업**은 해당 요청에서 한 참가자의 작업입니다. 워크플로 단계는 선택한 순서대로 실행됩니다.

예를 들어 고객의 이메일 주소로 제안서를 보내고 전자 서명을 요청합니다. 클라이언트는 로그인하여 제안을 검토하고 서명을 제출합니다. 요청이 완료되면 Click2Approve는 확인 링크를 통해 공유할 수 있는 결과 기록인 **완료 기록**을 생성합니다. [완료 기록 및 확인](receipts.md)을 참조하세요.

## 둘러보기 {#take-a-quick-tour}

로그인 후 처음으로 앱을 열면 간략한 사용자 가이드에서 프로필 설정, 알림, 작업 공간 선택기, 기본 메뉴 그룹을 강조합니다. 암호 설정 프롬프트가 나타나면 먼저 끝내거나 닫으세요.

가이드를 통해 이동하려면 **Next**및**Back**를 선택하고, 완료하려면 **Finish**를 선택하고, 닫으려면 **Skip**를 선택하세요. Escape를 사용하여 닫을 수도 있습니다.

짧은 화면에서는 Tab 키를 눌러 **User guide instructions**로 이동한 다음 Page Down 또는 화살표 키를 사용하여 설명을 스크롤하세요. 탐색 버튼은 계속 표시됩니다.

가이드에는 현재 작업 공간에서 사용할 수 있는 탐색이 표시됩니다. 사용 가능한 작업공간 선택기에 대해 설명합니다. Personal에서는 조직에 직원, 팀, 위임을 위한 **People** 그룹이 있다는 설명도 나와 있습니다.

완료 또는 건너뛰기는 이 브라우저의 계정에 대해 기억됩니다. 다른 브라우저를 사용하거나 저장된 사이트 데이터를 삭제하면 가이드가 다시 나타납니다. 언제든지 다시 방문하려면 기본 메뉴를 열고 **Support**에서 **Replay user guide**를 선택하세요.

## 첫 번째 요청 보내기 {#send-your-first-request}

1. 웹사이트에서 **앱 열기**를 선택하여 동일한 브라우저 탭에서 계속하거나 [앱을 직접 열기](/app/)한 다음 [로그인 또는 등록](sign-in.md)합니다.
2. 자신만의 요청을 위해 워크스페이스인 **Personal**를 사용하거나 워크스페이스 선택기에서 조직을 선택하여 대신 작업을 보내세요.
3. 메인 메뉴에서 **New request**를 선택하세요.
4. 제목과 설명을 입력하고, 파일을 추가하고, 단계와 담당자를 구성하세요.
5. 세부정보를 검토한 후 **Submit**를 선택하세요.
6. 결과를 확인하려면 **Requests**를 엽니다.

[요청 만들기](create-a-request.md)에서 제출의 각 부분을 설명합니다.

## 첫 번째 작업 를 완료하세요 {#complete-your-first-task}

요청이 전송된 이메일 주소로 로그인하세요. 해당 주소로 전송된 작업의 경우 작업 공간 선택기에서 **Personal**를 선택하세요. 직원이나 팀 배정의 경우 조직을 선택하세요. **Tasks**를 열고 작업을 선택하고 해당 지침을 읽고 현재 파일을 검토합니다. 필요한 의견, 서명 또는 첨부 파일을 제공한 후 결정을 제출하세요. [작업 완료](complete-a-task.md)를 참조하세요.

## Personal 및 비즈니스 업무 {#personal-and-business-work}

누구나 Personal 작업 공간으로 시작합니다. 조직은 직원, 팀, 위임 및 재사용 가능한 워크플로 템플릿을 추가합니다.

!!! info "조직 기능"
    직원, 팀, 위임 및 템플릿을 사용할 조직을 선택하세요. 토론, 완료 기록, 수정 및 계정 보안도 Personal에서 사용할 수 있습니다. 귀하의 역할과 계획에 따라 취할 수 있는 조치가 결정됩니다. [기능 및 가용성](features.md)을 참조하세요.
