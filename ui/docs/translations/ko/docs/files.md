# 문서 승인을 위한 파일 및 첨부 파일 {#files-and-attachments}

문서 승인 요청, 참가자의 결정 또는 채팅 메시지에 파일을 첨부할 수 있습니다. 각 장소마다 목적이 다릅니다. 필요한 기록의 일부가 되도록 파일을 어디에 첨부했는지 확인하세요.

| 당신은... | 여기에 파일을 첨부하세요 |
| --- | --- |
| 사람들이 검토할 수 있도록 문서 보내기 | **Files to review** 요청 생성 시 |
| 작업 응답이 포함된 파일 제출 | **Your response** 작업에 |
| 추가 정보를 공유하거나 질문하기 | **Chat** 요청 또는 작업 |

각 첨부 파일은 최대 **50MiB**(52,428,800바이트)까지 가능합니다. 이는 요청, 결정 및 토론 첨부 파일에 적용됩니다. Workspace 저장 공간 및 토큰 제한도 적용됩니다.

## 요청 파일 {#request-files}

[요청 생성](create-a-request.md) 시 참가자가 검토해야 하는 문서를 추가하세요. 인식 가능한 파일 이름을 사용하고 제출하기 전에 선택한 파일을 확인하세요.

사용 가능한 미리보기 또는 다운로드 작업을 사용하려면 파일 이름을 엽니다. 미리보기 지원은 파일 형식과 브라우저에 따라 다릅니다. 미리보기에서 문서를 표시할 수 없는 경우 문서를 다운로드하고 적합한 애플리케이션을 사용하세요.

## 결정 첨부 파일 {#decision-attachments}

요청 시 작업 작업 영역에 응답 파일을 첨부하세요. **Require an attachment**로 표시된 단계는 필수 응답 파일 없이 완료할 수 없습니다.

결정 첨부 파일은 기록된 작업 작업과 함께 표시됩니다. 동일한 파일을 채팅에 업로드하면 작업의 첨부 파일 요구 사항이 충족되지 않습니다.

## 토론 첨부 파일 {#discussion-attachments}

요청을 명확히 해야 할 경우 [채팅 메시지](discussions.md)에 지원 자료를 첨부하세요. 공유하기 전에 토론 대상을 고려하세요.

## 수정된 파일 {#revised-files}

수정은 요청 파일을 추가, 제거 또는 교체할 수 있습니다. 현재 파일 목록을 검토하고 **Show revision changes**를 사용하여 컨텍스트를 확인하세요. 교체 및 제거된 파일은 현재 검토 문서가 아닌 것으로 표시됩니다.

## 업로드 문제 {#upload-problems}

제출하기 전에 업로드가 완료될 때까지 기다리세요. 업로드가 거부된 경우 오류 내용을 읽고 해당 파일 및 작업공간의 [사용 제한](usage.md)을 확인하세요. 요청이 처리되는 동안 반복적으로 제출하지 마세요. 실패한 작업은 [문제 해결](troubleshooting.md)을 참조하세요.

## 토큰 및 저장소 {#tokens-and-storage}

파일 업로드, 미리 보기, 다운로드에는 토큰이 사용됩니다. 파일 크기는 별도의 저장 공간 한도에도 포함됩니다. 작업과 토론의 파일은 워크플로를 시작한 작업 공간에서 비용을 부담하며, 일반 업로드는 선택한 작업 공간을 사용합니다. 업로드는 성공한 경우에만 청구됩니다. 동시 전송으로 토큰 잔액이 음수가 될 수 있습니다. 다운로드가 중단되면 이미 전송된 문서 바이트 수만큼 청구됩니다. [사용량 및 토큰](usage.md)을 참조하세요.
