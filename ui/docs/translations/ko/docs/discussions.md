# 요청과 작업의 채팅에서 문서 논의하기 {#discussions}

문서를 승인하거나 서명하기 전에 **Chat**를 사용하여 문서에 대해 질문하세요. 토론에서 지원 파일을 공유할 수 있습니다. 채팅은 Personal 및 조직 작업 공간 모두에서 사용할 수 있습니다.

## 요청 {#ask-about-a-request}

1. 접근 가능한 요청이나 작업을 엽니다.
2. **Chat**를 선택하세요.
3. 기존 메시지를 읽어 맥락을 파악하세요.
4. 메시지를 입력하세요. **Message**안에 있는 클립을 사용하여 지원 파일을 첨부한 다음**Send**를 선택하세요.

메시지가 오른쪽에 표시됩니다. 다른 사람의 메시지가 왼쪽에 나타납니다. 요청 시 대화는 워크플로 단계별로 그룹화됩니다. 작업에서 Chat은 현재 단계를 표시합니다.

참가자를 알파벳순으로 표시하려면 단계 제목 옆에 있는 화살표를 사용하세요. 목록을 숨기려면 다시 사용하세요. 참가자 목록이 숨겨져도 메시지는 계속 표시됩니다.

질문과 설명을 위해 채팅을 사용하세요. 작업의 작업 제어를 통해 실제 결정을 기록하여 워크플로 결과가 되도록 하세요.

## 청중 및 액세스 {#audience-and-access}

토론 액세스는 요청, 작업 및 귀하의 권한에 따라 다릅니다. 공유 링크 또는 조직 멤버십이 모든 사람에게 대화에 대한 액세스 권한을 부여하는 것은 아닙니다. 민감한 자료를 게시하기 전에 맥락을 확인하세요.

대표자는 조직 내에서 부여된 액세스 권한을 통해서만 참여합니다. 토론 메시지와 알림에는 작성자의 속성이 유지됩니다.

## 를 보낼 수 없는 경우 {#when-you-cannot-send}

워크플로에 실행 가능한 보류 작업이 더 이상 없거나 완료되면 보내기가 종료될 수 있습니다. 작성기를 사용할 수 없는 경우 리소스를 새로 고치고 현재 상태와 액세스 권한을 확인하세요. 새 메시지가 더 이상 허용되지 않는 경우에도 토론을 계속 읽을 수 있습니다.

## 알림 {#notifications}

토론 알림은 [채팅 알림 기본 설정](notifications.md) 및 해당 메시지 수신이 허용된 청중에 따라 다릅니다. 채팅으로 전송된 파일은 필수 [결정 첨부 파일](files.md)과 별개입니다.
