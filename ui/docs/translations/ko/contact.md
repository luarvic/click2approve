# 문의하기 {#lets-talk}

워크플로에 대해 질문이 있거나 예상치 못한 것을 발견했거나 Click2Approve에 대한 아이디어가 있습니까?

## 질문 {#ask-a-question}

에서 대화를 시작하세요. [GitHub 토론](https://github.com/luarvic/click2approve/discussions). 수행하려는 작업과 도움이 필요한 부분을 포함하세요. 게시하려면 GitHub 계정이 필요합니다.

## 버그 신고 {#report-a-bug}

[문제 열기](https://github.com/luarvic/click2approve/issues) 문제를 재현하는 단계, 예상한 내용, 발생한 상황을 알려주세요. 비밀번호, 개인 문서 및 기타 민감한 정보는 공개 보고서에서 제외하세요.

## 개인 계정 및 개인 정보 보호 질문 {#private-account-and-privacy-questions}

계정, 보안, 법률 또는 개인 정보 보호 요청은 [contact@click2approve.com](mailto:contact@click2approve.com)로 이메일을 보내세요. 비밀번호나 불필요한 신분 증명서를 보내지 마세요.

## 시작점이 필요하신가요? {#need-a-starting-point}

요청 및 작업의 기본 사항은 [시작 가이드를 읽어보세요](docs/index.md).
