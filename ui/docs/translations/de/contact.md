# Lass uns reden {#lets-talk}

Haben Sie eine Frage zu einem Workflow, haben Sie etwas Unerwartetes gefunden oder eine Idee für Click2Approve?

## Stellen Sie eine Frage {#ask-a-question}

Starten Sie eine Unterhaltung in [GitHub Diskussionen](https://github.com/luarvic/click2approve/discussions). Geben Sie an, was Sie tun möchten und wo Sie Hilfe benötigen. Zum Posten ist ein GitHub-Konto erforderlich.

## Melden Sie einen Fehler {#report-a-bug}

[Öffnen Sie ein Problem](https://github.com/luarvic/click2approve/issues) mit den Schritten zum Reproduzieren des Problems, was Sie erwartet haben und was passiert ist. Lassen Sie Passwörter, private Dokumente und andere vertrauliche Informationen aus öffentlichen Berichten heraus.

## Fragen zu privaten Konten und zum Datenschutz {#private-account-and-privacy-questions}

E-Mail an [contact@click2approve.com](mailto:contact@click2approve.com) für Konto-, Sicherheits-, rechtliche oder Datenschutzanfragen. Senden Sie keine Passwörter oder unnötigen Ausweisdokumente.

## Benötigen Sie einen Ausgangspunkt? {#need-a-starting-point}

[Lesen Sie den Leitfaden „Erste Schritte“](docs/index.md) für die Grundlagen von Anfragen und Aufgaben.
