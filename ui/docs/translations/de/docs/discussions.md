# Besprechen Sie Dokumente im Anfrage- und Aufgaben-Chat {#discussions}

Verwenden Sie **Chat**, um Fragen zu einem Dokument zu stellen, bevor Sie es genehmigen oder unterzeichnen. Sie können unterstützende Dateien in der Diskussion teilen. Chat ist sowohl in Personal als auch in Organisationsarbeitsbereichen verfügbar.

## Fragen Sie nach einer Anfrage {#ask-about-a-request}

1. Öffnen Sie eine zugängliche Anfrage oder Aufgabe.
2. Wählen Sie **Chat**.
3. Lesen Sie die vorhandenen Nachrichten für den Kontext.
4. Geben Sie Ihre Nachricht ein. Verwenden Sie die Büroklammer in **Message**, um unterstützende Dateien anzuhängen, und wählen Sie dann **Send** aus.

Ihre Nachrichten werden auf der rechten Seite angezeigt. Die Nachrichten anderer Personen werden links angezeigt. Bei einer Anfrage werden Konversationen nach Workflowschritt gruppiert. Bei einer Aufgabe zeigt Chat den aktuellen Schritt an.

Verwenden Sie den Pfeil neben der Überschrift eines Schritts, um die Teilnehmer in alphabetischer Reihenfolge anzuzeigen. Benutzen Sie es erneut, um die Liste auszublenden. Nachrichten bleiben sichtbar, wenn die Teilnehmerliste ausgeblendet ist.

Verwenden Sie den Chat für Fragen und Erläuterungen. Zeichnen Sie die tatsächliche Entscheidung über die Aktionssteuerungen der Aufgabe auf, damit sie zu einem Workflow-Ergebnis wird.

## Zielgruppe und Zugriff {#audience-and-access}

Der Diskussionszugriff hängt von der Anfrage, der Aufgabe und Ihren Berechtigungen ab. Durch einen freigegebenen Link oder eine Organisationsmitgliedschaft erhält nicht jeder Zugriff auf die Konversation. Überprüfen Sie den Kontext, bevor Sie vertrauliches Material veröffentlichen.

Delegierte nehmen nur über den innerhalb ihrer Organisation gewährten Zugriff teil. Bei Diskussionsnachrichten und Benachrichtigungen bleibt die Quellenangabe des Autors erhalten.

## Wenn Sie nicht senden können {#when-you-cannot-send}

Der Versand wird möglicherweise beendet, wenn der Workflow keine umsetzbare ausstehende Aufgabe mehr hat oder abgeschlossen ist. Wenn das Nachrichtenfeld nicht verfügbar ist, aktualisieren Sie die Ressource und überprüfen Sie ihren aktuellen Status und Ihren Zugriff. Die Diskussion kann auch dann zum Lesen verfügbar bleiben, wenn neue Nachrichten nicht mehr zulässig sind.

## Benachrichtigungen {#notifications}

Diskussionsbenachrichtigungen hängen von Ihren [Chat-Benachrichtigungseinstellungen](notifications.md) und der Zielgruppe ab, die diese Nachricht empfangen darf. Eine im Chat gesendete Datei ist unabhängig von einem erforderlichen [Entscheidungsanhang](files.md).
