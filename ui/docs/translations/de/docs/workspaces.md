# Arbeitsbereiche und Navigation {#workspaces-and-navigation}

Ein **Arbeitsbereich** gruppiert die Anfragen, Aufgaben und Einstellungen, auf die Sie zugreifen können. Jeder beginnt mit **Personal**, dem Arbeitsbereich für seine eigenen Anfragen und Aufgaben, die an seine E-Mail-Adresse gesendet werden. Wenn Sie auch einer Organisation angehören, verwenden Sie die Arbeitsbereichsauswahl, um zu deren gemeinsamer Arbeit zu wechseln. Legen Sie einen bevorzugten Startarbeitsbereich in [Benutzerprofil fest](profile.md).

## Personal {#personal}

Verwenden Sie Personal für Anfragen, die Sie persönlich senden, und Aufgaben, die an die E-Mail-Adresse Ihres Kontos gerichtet sind. Personal hat kein Mitarbeiter- oder Teamverzeichnis.

Eine Organisation kann eine Aufgabe an Ihre E-Mail-Adresse senden. Sie erhalten diese Aufgabe in Personal; Dadurch werden Sie weder zum Mitarbeiter noch erhalten Sie Zugriff auf den Arbeitsbereich der Organisation. Personal-Aufgabenlisten zeigen die ursprüngliche Organisation an, damit Sie Absender unterscheiden können.

## Organisationen {#organizations}

Organisationsarbeit bleibt innerhalb der ausgewählten Organisation. Mitarbeiter- und Teamaufgaben werden in der Tasks-Ansicht dieser Organisation angezeigt. Die Requests-Ansicht umfasst Arbeiten, die über Ihre Anfordereridentität, Teambeziehungen und autorisierte Delegation verfügbar sind.

Mitarbeiter und Delegierte müssen derselben Organisation angehören. Die Mitgliedschaft in einer Organisation gewährt keinen Zugriff auf die Anfragen oder Aufgaben einer anderen Organisation.

Wenn Sie delegierten Zugriff haben, bietet die Arbeitsbereichsauswahl auch Organisationseinträge mit dem Namen des vertretenen Mitarbeiters an. Wählen Sie diesen Eintrag aus, um in ihrem Namen zu arbeiten. Wählen Sie Ihren eigenen Eintrag aus, um zu Ihrer Arbeit zurückzukehren. Siehe [Delegationen](delegations.md).

Der kleine Chip neben der oberen rechten Ecke des Markennamens lautet **App** in der kommerziellen App,**Free** in der Open-Source-App und **Docs** im Dokumentationsportal.

## Hauptmenü {#main-menu}

| Bereich | Zweck |
| --- | --- |
| Tasks | Überprüfen Sie Aktionen, die Ihnen zugewiesen wurden oder über Ihre Organisationsrolle im Workflow verfügbar sind |
| Requests | Befolgen Sie Anfragen, auf die Sie zugreifen können. Verwenden Sie „Neue Anfrage“, um Arbeit zu senden — New request |
| Receipts | An Sie ausgestellte Belege können Sie in beiden Arbeitsbereichstypen ansehen, teilen und löschen |
| Templates | Organisations-Workflow-Schritte wiederverwenden |
| Employees, Teams, Delegations | Arbeiten Sie mit Organisationsmitgliedschaft und delegierter Arbeit |
| Plans, Usage, Retention | Überprüfen Sie Abonnement, Limits und Dateneinstellungen |
| Organizations | Erstellen und verwalten Sie geschäftliche Arbeitsbereiche |

Verwenden Sie das Profilmenü für Ihre Kontoeinstellungen und Benachrichtigungseinstellungen. Die Glocke in der App-Leiste öffnet Benachrichtigungen für den ausgewählten Arbeitsbereich. Die Navigationsleiste kann auf kleineren Bildschirmen über die Menüschaltfläche geöffnet werden. Der Farbmoduswechsel ändert das Erscheinungsbild sowohl der App als auch von Docs auf derselben Website.

Kleine Beschriftungen in Großbuchstaben kennzeichnen Navigationsgruppen, Karten, Abschnitte und Workflow-Schritte. Seitentitel und Steuerelemente verwenden die Groß-/Kleinschreibung von Sätzen. Verwenden Sie die Breadcrumb-Links über einem Seitentitel, um zu den übergeordneten Seiten zurückzukehren. Wählen Sie im Hauptmenü **Docs**, um die Benutzerhandbücher auf der aktuellen Registerkarte zu öffnen. Die Docs-Links und kontextbezogenen **Read documentation**-Links der Website verwenden ebenfalls die aktuelle Registerkarte. In der Open-Source-App öffnet Docs den Leitfaden und den Funktionsvergleich zur [Open-Source-Edition](open-source.md).

In Rastern sind grüne Titel und Namen Links. Sie werden unterstrichen angezeigt, wenn Sie mit der Tastatur darüber fahren oder den Fokus darauf legen. Der Tastaturfokus hat auch einen sichtbaren Umriss.

Die Fußzeile enthält Links zu „Startseite“, „App“, „Dokumente“, „Kontakt“, „Nutzungsbedingungen“ und „Datenschutz“. Jedes wird im aktuellen Tab geöffnet.

Wählen Sie die Sprache in der Kopfzeile der Website oder Dokumentation, um dieselbe Seite in einer anderen Sprache zu lesen. Die Website merkt sich die Auswahl in diesem Browser. Englische Website- oder Dokumentationslinks aus der App leiten zur gespeicherten Sprache weiter; ein ausdrücklich angegebenes Sprachpräfix in der URL hat Vorrang. Die Dokumentationssuche liefert Seiten in der Sprache der URL. Die App bleibt vorerst englisch, daher behalten die Anleitungen ihre exakten Bedienelementnamen bei und erklären deren Bedeutung in der gewählten Sprache.

Das Hauptmenü gruppiert verwandte Seiten unter **Work**, **Access**, **People**, **Subscription** und **Support**. Gruppen werden nur angezeigt, wenn ihre Funktionen im ausgewählten Arbeitsbereich verfügbar sind. Wählen Sie **Replay user guide** unter **Support** für eine geführte Einführung in die App-Leiste und Navigation; siehe [Erste Schritte](getting-started.md#take-a-quick-tour).

## Einen freigegebenen Link öffnen {#open-a-shared-link}

Melden Sie sich mit dem vorgesehenen Konto an, wenn Sie einer E-Mail oder einem Link zu einer freigegebenen Ressource folgen. Ein Link gewährt keine zusätzlichen Berechtigungen. Wenn die Ressource nicht verfügbar ist, überprüfen Sie den Arbeitsbereich, das Konto, den Mitarbeiterzugriff und ob der Datensatz gelöscht wurde. Siehe [Fehlerbehebung](troubleshooting.md).
