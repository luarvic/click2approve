# Arbeitsablaufhandbücher für die Dokumentengenehmigung {#table-of-contents}

Click2Approve ist ein Dokumentengenehmigungssystem. Senden Sie Dokumente an die Personen, die sie überprüfen müssen, sammeln Sie Entscheidungen und elektronische Signaturen und verfolgen Sie das Ergebnis. Diese Anleitungen erklären in einfachen Schritten, wie Sie die App verwenden.

Eine **Anfrage** enthält Ihre Dokumente, Anweisungen und Workflow-Schritte. Jede einem Schritt zugewiesene Person erhält eine **Aufgabe**. Eine **Quittung** zeichnet das Ergebnis auf, wenn die Anfrage abgeschlossen ist.

Click2Approve verfügt außerdem über eine kostenlose [Open-Source-Edition](open-source.md) für selbst gehostete persönliche Workflows. Im Editionsvergleich finden Sie enthaltene Funktionen und kommerzielle Ergänzungen.
