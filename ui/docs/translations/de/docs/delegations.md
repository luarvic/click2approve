# Genehmigungsaufgaben und -anforderungen delegieren {#delegations}

Verwenden Sie eine **Delegierung**, wenn ein Mitarbeiter einen anderen Mitarbeiter benötigt, der auf seine Genehmigungsaufgaben und -anforderungen reagiert. Beispielsweise kann ein Kollege die Arbeit übernehmen, während jemand abwesend ist. Beide Mitarbeiter müssen derselben Organisation angehören.

!!! info "Nur Organisation"
    Wählen Sie eine Organisation aus, um Delegationen anzuzeigen. Eigentümer und Administratoren können sie erstellen, ändern und entfernen; Beide Mitarbeiter müssen dieser Organisation angehören.

## Erstellen Sie eine Delegation {#create-a-delegation}

1. Wählen Sie die Organisation aus und öffnen Sie **Delegations**.
2. Starten Sie als Eigentümer oder Administrator eine neue Delegation.
3. **Employee** — Wählen Sie die Person aus, deren Aufgaben vertreten werden sollen.
4. Wählen Sie in **Delegate** den Mitarbeiter aus, der für ihn handeln soll.
5. Speichern und überprüfen Sie die Richtung der Beziehung.

Beide Mitarbeiter müssen der ausgewählten Organisation angehören. Mitglieder können Delegationen einsehen; Eigentümer und Administratoren verwalten sie. Eine Delegation überträgt weder Eigentum noch gewährt sie eine Mitgliedschaft in einer anderen Organisation.

## Als Delegierter arbeiten {#work-as-a-delegate}

Wählen Sie in der Arbeitsbereichsauswahl den Organisationseintrag aus, der den von Ihnen vertretenen Mitarbeiter enthält. Dadurch wird die Arbeitswarteschlange dieses Mitarbeiters ausgewählt. Wenn Sie Ihren eigenen Eintrag auswählen, wird weiterhin Ihre eigene Arbeit angezeigt. Durch die Delegation werden die Warteschlangen nicht zusammengeführt.

Durch das Aktualisieren einer Arbeitsbereichsseite wird diese Auswahl nur wiederhergestellt, solange Sie noch über delegierten Zugriff verfügen. Durch das Abmelden wird die Auswahl gelöscht.

Öffnen Sie die autorisierten Aufgaben oder Anforderungen, überprüfen Sie ihren Kontext und führen Sie die zulässigen Aktionen aus. Der Datensatz bewahrt den tatsächlich handelnden Benutzer und Mitarbeiter, sodass die Aktion von einer Aktion des ursprünglichen Beauftragten unterschieden werden kann.

Die Delegationsrichtung ist wichtig: Wenn Sie Alex als Delegierten für Sam auswählen, kann Alex für Sam handeln. Es erlaubt Sam nicht automatisch, für Alex zu handeln.

## Vertretung ändern oder beenden {#change-or-remove-coverage}

Eigentümer und Administratoren können die Delegation bearbeiten oder löschen, wenn sich die Abdeckung ändert. Überprüfen Sie die gespeicherte Beziehung und bitten Sie den Stellvertreter, seine Arbeitsliste zu aktualisieren. Durch das Entfernen einer Delegation werden Entscheidungen, die während ihrer Gültigkeit bereits aufgezeichnet wurden, nicht gelöscht.
