# Profil und gespeicherte elektronische Signatur {#profile-and-signature}

Öffnen Sie **User profile** im Profilmenü, um Ihren Namen zu aktualisieren, einen Standardarbeitsbereich auszuwählen oder eine Signatur für zukünftige Genehmigungsaufgaben zu speichern. Diese Einstellungen gehören zu Ihrem Konto und werden in allen Arbeitsbereichen geteilt, auf die Sie zugreifen können.

## Persönliche Angaben {#personal-details}

Aktualisieren Sie auf **Profile** Ihren Vornamen, Nachnamen, Avatar und Standardarbeitsbereich nach Bedarf. Wählen Sie **Save**, nachdem Sie Profilfelder bearbeitet oder einen Avatar ausgewählt haben. Der Standardarbeitsbereich steuert, wo Sie beginnen möchten. Anfragen oder Aufgaben werden nicht zwischen Arbeitsbereichen verschoben.

Avatarbilder können bis zu **4 MiB** (4.194.304 Bytes) groß sein.

Namen und Positionen von Mitarbeitern der Organisation werden separat in [Mitarbeiter](employees.md) verwaltet. Wenn die Organisationszuordnung falsch ist, bitten Sie einen Eigentümer oder Administrator, den Mitarbeiterdatensatz zu überprüfen.

## Gespeicherte Signatur {#saved-signature}

1. Öffnen Sie die Registerkarte **Signature**.
2. Zeichnen oder aktualisieren Sie Ihre Standardsignatur.
3. Wählen Sie **Save**.

Die gespeicherte Signatur wird vorab ausgefüllt, wenn Sie eine Genehmigungsanfrage signieren. Überprüfen Sie es vor jeder Entscheidung und überprüfen Sie die im Unterzeichnungsformular geforderten rechtlichen Namens- und Vertretungsangaben. Durch das Speichern einer Signatur in Ihrem Profil wird keine Aufgabe signiert oder abgeschlossen.

## Andere Profilregisterkarten {#other-profile-tabs}

Verwenden Sie **Security** für den Authentifikator MFA,**Passkeys** für Geräteanmeldeinformationen,**API tokens** für API-Anmeldeinformationen und **Notifications** für Zustelleinstellungen.

Siehe [MFA und Passkeys](security.md), [API-Tokens](api-tokens.md) und [Benachrichtigungen](notifications.md) für die entsprechenden Kontrollen.
