# Vamos conversar {#lets-talk}

Tem alguma dúvida sobre um fluxo de trabalho, encontrou algo inesperado ou tem uma ideia para Click2Approve?

## Faça uma pergunta {#ask-a-question}

Iniciar uma conversa em [GitHub Discussões](https://github.com/luarvic/click2approve/discussions). Inclua o que você está tentando fazer e onde precisa de ajuda. É necessária uma conta GitHub para postar.

## Reportar um bug {#report-a-bug}

[Abrir um problema](https://github.com/luarvic/click2approve/issues) com as etapas para reproduzir o problema, o que você esperava e o que aconteceu. Deixe senhas, documentos privados e outras informações confidenciais fora dos relatórios públicos.

## Perguntas sobre contas privadas e privacidade {#private-account-and-privacy-questions}

Envie um e-mail para [contact@click2approve.com](mailto:contact@click2approve.com) para solicitações de conta, segurança, legais ou de privacidade. Não envie senhas ou documentos de identidade desnecessários.

## Precisa de um ponto de partida? {#need-a-starting-point}

[Leia o guia de primeiros passos](docs/index.md) para obter informações básicas sobre solicitações e tarefas.
