# Primeiros passos com aprovações de documentos {#getting-started}

Use Click2Approve para enviar documentos para revisão, aprovação ou assinatura eletrônica. Uma **solicitação** é o trabalho que você envia, incluindo seus arquivos, instruções e participantes. Uma **tarefa** é a ação de um participante nessa solicitação. As etapas do fluxo de trabalho são executadas na ordem que você escolher.

Por exemplo, envie uma proposta para o endereço de e-mail de um cliente e solicite uma assinatura eletrônica. O cliente faz login, analisa a proposta e envia uma assinatura. Quando a solicitação for concluída, Click2Approve cria um **registro de resultado**: um registro do resultado que você pode compartilhar por meio de um link de verificação. Consulte [Registros de resultado e verificação](receipts.md).

## Faça um tour rápido {#take-a-quick-tour}

Na primeira vez que você abrir o aplicativo após fazer login, um breve guia do usuário destacará suas configurações de perfil, notificações, seletor de espaço de trabalho e grupos do menu principal. Se um prompt de configuração de chave de acesso for exibido, conclua ou ignore-o primeiro.

Escolha **Next** e **Back** para percorrer o guia,**Finish** para concluí-lo ou **Skip** para fechá-lo. Você também pode fechá-lo com Escape.

Em telas curtas, vá até **User guide instructions** e use Page Down ou as teclas de seta para rolar a explicação. Os botões de navegação permanecem visíveis.

O guia mostra a navegação disponível em seu espaço de trabalho atual. Explica o seletor de espaço de trabalho quando houver um disponível. Em Personal, também explica que as organizações têm um grupo **People** para funcionários, equipes e delegações.

Concluir ou pular é lembrado para sua conta neste navegador. Outro navegador, ou a limpeza dos dados salvos do site, faz com que o guia apareça novamente. Para revisitá-lo a qualquer momento, abra o menu principal e escolha **Replay user guide** em **Support**.

## Envie sua primeira solicitação {#send-your-first-request}

1. Escolha **Abra o aplicativo** no site para continuar na mesma guia do navegador ou [abra o aplicativo diretamente](/app/) e [faça login ou registre-se](sign-in.md).
2. Use **Personal**, seu espaço de trabalho para suas próprias solicitações ou selecione uma organização no seletor de espaço de trabalho para enviar trabalho em seu nome.
3. Escolha **New request** no menu principal.
4. Insira um título e uma descrição, adicione arquivos e configure as etapas e os responsáveis.
5. Revise os detalhes e escolha **Submit**.
6. Abra **Requests** para acompanhar o resultado.

[Criar uma solicitação](create-a-request.md) explica cada parte do envio.

## Conclua sua primeira tarefa {#complete-your-first-task}

Faça login com o endereço de e-mail para o qual a solicitação foi enviada. Para tarefas enviadas para esse endereço, selecione **Personal** no seletor de espaço de trabalho; para atribuições de funcionário ou equipe, selecione a organização. Abra **Tasks**, selecione a tarefa, leia suas instruções e revise os arquivos atuais. Forneça qualquer comentário, assinatura ou anexo necessário e envie sua decisão. Consulte [Concluir uma tarefa](complete-a-task.md).

## Personal e trabalho comercial {#personal-and-business-work}

Todo mundo começa com um espaço de trabalho Personal. As organizações adicionam funcionários, equipes, delegações e modelos de fluxo de trabalho reutilizáveis.

!!! info "Recursos da organização"
    Selecione uma organização para usar seus funcionários, equipes, delegações e modelos. Discussões, registros de resultado, revisões e segurança de conta também estão disponíveis em Personal. Seu papel e plano determinam quais ações você pode tomar; consulte [Recursos e disponibilidade](features.md).
