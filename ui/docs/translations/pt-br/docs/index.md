# Guias de fluxo de trabalho de aprovação de documentos {#table-of-contents}

Click2Approve é um sistema de aprovação de documentos. Envie documentos para quem precisa revisá-los, colete decisões e assinaturas eletrônicas e acompanhe o resultado. Estes guias explicam como usar o aplicativo em etapas simples.

Uma **solicitação** contém seus documentos, instruções e etapas do fluxo de trabalho. Cada pessoa atribuída a uma etapa recebe uma **tarefa**. Um **registro de resultado** registra o resultado quando a solicitação é concluída.

Click2Approve também tem uma [edição de código aberto](open-source.md) gratuita para fluxos de trabalho pessoais auto-hospedados. Veja a comparação de edições para recursos incluídos e adições comerciais.
