# Perfil e assinatura eletrônica salva {#profile-and-signature}

Abra **User profile** no menu do perfil para atualizar seu nome, escolher um espaço de trabalho padrão ou salvar uma assinatura para futuras tarefas de aprovação. Essas configurações pertencem à sua conta e são compartilhadas entre os espaços de trabalho que você pode acessar.

## Dados pessoais {#personal-details}

Em **Profile**, atualize seu nome, sobrenome, avatar e espaço de trabalho padrão conforme necessário. Escolha **Save** após editar os campos do perfil ou selecionar um avatar. A área de trabalho padrão controla onde você prefere começar; ele não move solicitações ou tarefas entre espaços de trabalho.

As imagens de avatar podem ter até **4 MiB** (4.194.304 bytes).

Os nomes e cargos dos funcionários da organização são gerenciados separadamente em [Funcionários](employees.md). Se a atribuição da organização estiver incorreta, peça a um proprietário ou administrador para revisar o registro do funcionário.

## Assinatura salva {#saved-signature}

1. Abra a guia **Signature**.
2. Desenhe ou atualize sua assinatura padrão.
3. Escolha **Save**.

A assinatura salva é preenchida automaticamente quando você assina uma solicitação de aprovação. Revise-o antes de cada decisão e verifique a razão social e os dados de representação solicitados no formulário de assinatura. Salvar uma assinatura em seu perfil não assina nem conclui uma tarefa.

## Outras guias de perfil {#other-profile-tabs}

Use **Security** para autenticador MFA,**Passkeys** para credenciais de dispositivo,**API tokens** para Credenciais API e **Notifications** para preferências de entrega.

Consulte [MFA e chaves de acesso](security.md), [tokens API](api-tokens.md) e [Notificações](notifications.md) para os controles correspondentes.
