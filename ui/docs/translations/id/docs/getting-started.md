# Memulai persetujuan dokumen {#getting-started}

Gunakan Click2Approve untuk mengirim dokumen untuk ditinjau, disetujui, atau ditandatangani secara elektronik. **Permintaan** adalah pekerjaan yang Anda kirim, termasuk file, instruksi, dan pesertanya.**Tugas** adalah tindakan salah satu peserta dalam permintaan tersebut. Langkah-langkah alur kerja dijalankan sesuai urutan yang Anda pilih.

Misalnya, kirimkan proposal ke alamat email klien dan minta tanda tangan elektronik. Klien masuk, meninjau proposal, dan mengirimkan tanda tangan. Ketika permintaan sudah selesai, Click2Approve membuat **catatan hasil**: catatan hasil yang dapat Anda bagikan melalui tautan verifikasi. Lihat [Catatan hasil dan verifikasi](receipts.md).

## Ikuti tur singkat {#take-a-quick-tour}

Pertama kali Anda membuka aplikasi setelah masuk, panduan pengguna singkat menyoroti pengaturan profil, notifikasi, pemilih ruang kerja, dan grup menu utama Anda. Jika perintah penyiapan kunci sandi muncul, selesaikan atau tutup terlebih dahulu.

Pilih **Next** dan **Back** untuk menelusuri panduan,**Finish** untuk menyelesaikannya, atau **Skip** untuk menutupnya. Anda juga dapat menutupnya dengan Escape.

Pada layar pendek, Tab untuk **User guide instructions** dan gunakan Halaman Bawah atau tombol panah untuk menggulir penjelasan. Tombol navigasi tetap terlihat.

Panduan menunjukkan navigasi yang tersedia di ruang kerja Anda saat ini. Ini menjelaskan pemilih ruang kerja ketika tersedia. Di Personal juga dijelaskan bahwa organisasi memiliki grup **People** untuk karyawan, tim, dan delegasi.

Penyelesaian atau lompatan akan diingat untuk akun Anda di browser ini. Browser lain, atau menghapus data situs yang disimpan, membuat panduan ini muncul kembali. Untuk mengunjunginya kembali kapan saja, buka menu utama dan pilih **Replay user guide** di bawah **Support**.

## Kirim permintaan pertama Anda {#send-your-first-request}

1. Pilih **Buka aplikasi** di situs web untuk melanjutkan di tab browser yang sama, atau [buka aplikasi secara langsung](/app/), lalu [masuk atau mendaftar](sign-in.md).
2. Gunakan **Personal**, ruang kerja Anda untuk permintaan Anda sendiri, atau pilih organisasi di pemilih ruang kerja untuk mengirim pekerjaan atas namanya.
3. Pilih **New request** di menu utama.
4. Masukkan judul dan deskripsi, tambahkan file, dan konfigurasikan langkah-langkah dan penerima tugas.
5. Tinjau detailnya, lalu pilih **Submit**.
6. Buka **Requests** untuk mengikuti hasilnya.

[Buat permintaan](create-a-request.md) menjelaskan setiap bagian penyerahan.

## Selesaikan tugas pertama Anda {#complete-your-first-task}

Masuk dengan alamat email tujuan pengiriman permintaan. Untuk tugas yang dikirim ke alamat tersebut, pilih **Personal** di pemilih ruang kerja; untuk tugas karyawan atau tim, pilih organisasi. Buka **Tasks**, pilih tugas, baca instruksinya, dan tinjau file saat ini. Berikan komentar, tanda tangan, atau lampiran apa pun yang diperlukan, lalu kirimkan keputusan Anda. Lihat [Menyelesaikan tugas](complete-a-task.md).

## Personal dan pekerjaan bisnis {#personal-and-business-work}

Semua orang memulai dengan ruang kerja Personal. Organisasi menambahkan karyawan, tim, delegasi, dan templat alur kerja yang dapat digunakan kembali.

!!! info "Fitur organisasi"
    Pilih organisasi untuk menggunakan karyawan, tim, delegasi, dan templatnya. Pembahasan, penerimaan, revisi, dan keamanan akun juga tersedia di Personal. Peran dan rencana Anda menentukan tindakan apa yang dapat Anda ambil; lihat [Fitur dan ketersediaan](features.md).
