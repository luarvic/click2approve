# Panduan alur kerja persetujuan dokumen {#table-of-contents}

Click2Approve adalah sistem persetujuan dokumen. Kirim dokumen ke orang yang perlu meninjaunya, mengumpulkan keputusan dan tanda tangan elektronik, dan melacak hasilnya. Panduan ini menjelaskan cara menggunakan aplikasi dalam langkah-langkah sederhana.

**Permintaan** berisi dokumen, petunjuk, dan langkah alur kerja Anda. Setiap orang yang ditugaskan pada suatu langkah menerima **tugas**. **catatan hasil** mencatat hasilnya ketika permintaan selesai.

Click2Approve juga memiliki [edisi sumber terbuka](open-source.md) gratis untuk alur kerja pribadi yang dihosting sendiri. Lihat perbandingan edisi untuk mengetahui fitur yang disertakan dan tambahan komersial.
