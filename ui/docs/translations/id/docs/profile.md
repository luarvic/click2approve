# Profil dan tanda tangan elektronik tersimpan {#profile-and-signature}

Buka **User profile** dari menu profil untuk memperbarui nama Anda, memilih ruang kerja default, atau menyimpan tanda tangan untuk tugas persetujuan di masa mendatang. Setelan ini milik akun Anda dan dibagikan ke seluruh ruang kerja yang dapat Anda akses.

## Data pribadi {#personal-details}

Pada **Profile**, perbarui nama depan, nama belakang, avatar, dan ruang kerja default sesuai kebutuhan. Pilih **Save** setelah mengedit kolom profil atau memilih avatar. Ruang kerja default mengontrol tempat Anda ingin memulai; itu tidak memindahkan permintaan atau tugas antar ruang kerja.

Gambar avatar dapat berukuran hingga **4 MiB** (4,194,304 byte).

Nama dan posisi karyawan organisasi dikelola secara terpisah di [Karyawan](employees.md). Jika atribusi organisasi salah, minta Pemilik atau Admin untuk meninjau catatan karyawan.

## Tanda tangan tersimpan {#saved-signature}

1. Buka tab **Signature**.
2. Gambar atau perbarui tanda tangan default Anda.
3. Pilih **Save**.

Tanda tangan yang disimpan telah diisi sebelumnya saat Anda menandatangani permintaan persetujuan. Tinjaulah sebelum setiap keputusan dan periksa nama resmi dan rincian perwakilan yang diminta oleh formulir penandatanganan. Menyimpan tanda tangan di profil Anda tidak menandatangani atau menyelesaikan tugas.

## Tab profil lainnya {#other-profile-tabs}

Gunakan **Security** untuk pengautentikasi MFA,**Passkeys** untuk kredensial perangkat,**API tokens** untuk Kredensial API, dan **Notifications** untuk preferensi pengiriman.

Lihat [MFA dan kunci sandi](security.md), [token API](api-tokens.md), dan [Pemberitahuan](notifications.md) untuk kontrol yang sesuai.
