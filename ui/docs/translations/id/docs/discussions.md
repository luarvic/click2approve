# Diskusikan dokumen di obrolan permintaan dan tugas {#discussions}

Gunakan **Chat** untuk mengajukan pertanyaan tentang dokumen sebelum menyetujui atau menandatanganinya. Anda dapat membagikan file pendukung dalam diskusi. Obrolan tersedia di Personal dan ruang kerja organisasi.

## Tanyakan tentang permintaan {#ask-about-a-request}

1. Buka permintaan atau tugas yang dapat diakses.
2. Pilih **Chat**.
3. Baca pesan yang ada untuk mengetahui konteksnya.
4. Masukkan pesan Anda. Gunakan penjepit kertas di dalam **Message** untuk melampirkan file pendukung, lalu pilih **Send**.

Pesan Anda muncul di sebelah kanan; pesan orang lain muncul di sebelah kiri. Berdasarkan permintaan, percakapan dikelompokkan berdasarkan langkah alur kerja. Pada suatu tugas, Obrolan menampilkan langkah saat ini.

Gunakan panah di samping judul langkah untuk menampilkan pesertanya dalam urutan abjad. Gunakan lagi untuk menyembunyikan daftar. Pesan tetap terlihat saat daftar peserta disembunyikan.

Gunakan Obrolan untuk pertanyaan dan klarifikasi. Catat keputusan sebenarnya melalui kontrol tindakan tugas sehingga menjadi hasil alur kerja.

## Audiens dan akses {#audience-and-access}

Akses diskusi bergantung pada permintaan, tugas, dan izin Anda. Tautan bersama atau keanggotaan organisasi tidak memberi semua orang akses ke percakapan. Periksa konteksnya sebelum memposting materi sensitif.

Delegasi hanya berpartisipasi melalui akses yang diberikan dalam organisasi mereka. Pesan diskusi dan pemberitahuan mempertahankan atribusi penulis.

## Bila Anda tidak dapat mengirim {#when-you-cannot-send}

Pengiriman mungkin ditutup ketika alur kerja tidak lagi memiliki tugas tertunda yang dapat ditindaklanjuti atau telah selesai. Jika kolom pesan tidak tersedia, segarkan sumber daya dan periksa statusnya saat ini serta akses Anda. Diskusi dapat tetap tersedia untuk dibaca meskipun pesan baru tidak lagi diizinkan.

## Notifikasi {#notifications}

Notifikasi diskusi bergantung pada [Preferensi notifikasi chat](notifications.md) Anda dan audiens yang diizinkan untuk menerima pesan tersebut. File yang dikirim di Chat terpisah dari [lampiran keputusan](files.md) yang diperlukan.
