# Tambahkan berkas ke permintaan dan tugas persetujuan {#files-and-attachments}

Anda dapat melampirkan file ke permintaan persetujuan dokumen, keputusan peserta, atau pesan Obrolan. Setiap tempat mempunyai tujuan yang berbeda-beda. Periksa di mana Anda melampirkan file sehingga menjadi bagian dari catatan yang Anda perlukan.

| Anda ingin… | Lampirkan file di sini |
| --- | --- |
| Kirim dokumen untuk ditinjau orang | **Files to review** saat membuat permintaan |
| Kirimkan file dengan respons tugas Anda | **Your response** pada tugas |
| Bagikan informasi tambahan atau ajukan pertanyaan | **Chat** berdasarkan permintaan atau tugas |

Setiap lampiran dapat berukuran hingga **50 MiB** (52.428.800 byte). Hal ini berlaku untuk lampiran permintaan, keputusan, dan diskusi. Batas penyimpanan ruang kerja dan token juga berlaku.

## Permintaan file {#request-files}

Tambahkan dokumen yang harus ditinjau peserta saat [membuat permintaan](create-a-request.md). Gunakan nama file yang dapat dikenali dan periksa file yang dipilih sebelum mengirimkannya.

Buka nama file untuk menggunakan pratinjau atau tindakan pengunduhan yang tersedia. Dukungan pratinjau bergantung pada format file dan browser. Jika pratinjau tidak dapat menampilkan dokumen, unduh dan gunakan aplikasi yang sesuai.

## Lampiran keputusan {#decision-attachments}

Lampirkan file respons di area tindakan tugas saat diminta. Langkah yang ditandai **Require an attachment** tidak dapat diselesaikan tanpa file respons yang diperlukan.

Lampiran keputusan muncul bersama tindakan tugas yang direkam. Mengunggah file yang sama ke Obrolan tidak memenuhi persyaratan lampiran tugas.

## Lampiran diskusi {#discussion-attachments}

Lampirkan materi pendukung ke [Pesan Obrolan](discussions.md) saat Anda perlu mengklarifikasi permintaan. Pertimbangkan audiens diskusi sebelum membagikannya.

## File revisi {#revised-files}

Revisi dapat menambah, menghapus, atau mengganti file permintaan. Tinjau daftar file saat ini dan gunakan **Show revision changes** untuk konteksnya. File yang diganti dan dihapus ditampilkan bukan dokumen tinjauan terkini.

## Masalah pengunggahan {#upload-problems}

Tunggu hingga unggahan selesai sebelum dikirimkan. Jika unggahan ditolak, baca kesalahannya dan periksa [batas penggunaan file dan ruang kerja](usage.md). Hindari mengirimkan berulang kali saat permintaan masih diproses. Lihat [Pemecahan Masalah](troubleshooting.md) untuk tindakan yang gagal.

## Token dan penyimpanan {#tokens-and-storage}

Mengunggah, melihat pratinjau, dan mengunduh berkas menggunakan token. Ukuran berkas juga dihitung dalam batas penyimpanan yang terpisah. Berkas tugas dan diskusi dibebankan ke ruang kerja asal alur; unggahan lainnya menggunakan ruang kerja yang dipilih. Unggahan hanya ditagih setelah berhasil. Transfer bersamaan dapat membuat saldo token negatif. Jika unduhan terputus, biaya dihitung berdasarkan byte dokumen yang sudah ditransfer. Lihat [Penggunaan dan token](usage.md).
