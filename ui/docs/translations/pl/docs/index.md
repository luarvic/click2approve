# Przewodniki po procesie zatwierdzania dokumentów {#table-of-contents}

Click2Approve to system zatwierdzania dokumentów. Wysyłaj dokumenty do osób, które muszą je przejrzeć, zbieraj decyzje i podpisy elektroniczne oraz monitoruj wynik. W tych przewodnikach w prostych krokach wyjaśniono, jak korzystać z aplikacji.

**Żądanie** zawiera dokumenty, instrukcje i etapy przepływu pracy. Każda osoba przypisana do kroku otrzymuje **zadanie**. **Potwierdzenie** rejestruje wynik po zakończeniu żądania.

Click2Approve ma również bezpłatną [edycję open source](open-source.md) do samodzielnego hostowania osobistych przepływów pracy. Zobacz porównanie wersji pod kątem zawartych funkcji i dodatków komercyjnych.
