# Profil i zapisany podpis elektroniczny {#profile-and-signature}

Otwórz **User profile** z menu profilu, aby zaktualizować swoje imię i nazwisko, wybrać domyślny obszar roboczy lub zapisać podpis do przyszłych zadań zatwierdzania. Te ustawienia należą do Twojego konta i są współdzielone we wszystkich obszarach roboczych, do których masz dostęp.

## Dane osobowe {#personal-details}

W **Profile** zaktualizuj swoje imię, nazwisko, awatar i domyślny obszar roboczy zgodnie z potrzebami. Po edycji pól profilu lub wybraniu awatara wybierz **Save**. Domyślny obszar roboczy kontroluje miejsce, w którym wolisz zacząć; nie przenosi żądań ani zadań między obszarami roboczymi.

Obrazy awatarów mogą mieć maksymalnie **4 MiB** (4 194 304 bajty).

Nazwiska i stanowiska pracowników organizacji są zarządzane oddzielnie w [Pracownicy](employees.md). Jeśli oznaczenie organizacji jest nieprawidłowe, poproś właściciela lub administratora o sprawdzenie danych pracownika.

## Zapisany podpis {#saved-signature}

1. Otwórz zakładkę **Signature**.
2. Narysuj lub zaktualizuj swój domyślny podpis.
3. Wybierz **Save**.

Zapisany podpis jest wstępnie wypełniany podczas podpisywania prośby o zatwierdzenie. Przejrzyj go przed podjęciem każdej decyzji i sprawdź pełne imię i nazwisko oraz szczegóły reprezentacji wymagane w formularzu podpisu. Zapisanie podpisu w profilu nie powoduje podpisania ani zakończenia zadania.

## Inne zakładki profilu {#other-profile-tabs}

Użyj **Security** dla uwierzytelnienia MFA, **Passkeys** dla danych uwierzytelniających urządzenia, **API tokens** dla danych uwierzytelniających API i **Notifications** dla preferencji dostawy.

Zobacz [MFA i klucze dostępu](security.md), [API tokeny](api-tokens.md) i [Powiadomienia](notifications.md) dla odpowiednich elementów sterujących.
