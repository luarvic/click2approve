# Файлы и вложения для утверждения документов {#files-and-attachments}

Вы можете прикреплять файлы к запросу на утверждение документа, решению участника или сообщению чата. У каждого места своя цель. Проверьте, куда вы прикрепляете файл, чтобы он стал частью необходимой вам записи.

| Вы хотите… | Прикрепите файл сюда |
| --- | --- |
| Отправить документ на рассмотрение | **Files to review** при создании запроса |
| Отправьте файл с ответом на задачу | **Your response** на задании |
| Поделитесь дополнительной информацией или задайте вопрос | **Chat** по запросу или задаче |

Каждое вложение может иметь размер до **50 MiB** (52 428 800 байт). Это относится к вложениям запросов, решений и обсуждений. Также применяются ограничения на хранилище рабочей области и токены.

## Файлы запросов {#request-files}

Добавьте документы, которые участники должны просмотреть при [создании запроса](create-a-request.md). Используйте узнаваемые имена файлов и проверяйте выбранные файлы перед отправкой.

Откройте имя файла, чтобы использовать доступное для него действие предварительного просмотра или загрузки. Поддержка предварительного просмотра зависит от формата файла и браузера. Если при предварительном просмотре документ не может быть отображен, загрузите его и используйте подходящее приложение.

## Вложения решений {#decision-attachments}

Прикрепите файлы ответов в области действий задачи по запросу. Шаг, отмеченный **Require an attachment**, невозможно выполнить без необходимого файла ответов.

Вложения с решениями отображаются вместе с записанным действием задачи. Загрузка одного и того же файла в чат не удовлетворяет требованию вложения задачи.

## Вложения обсуждения {#discussion-attachments}

Прикрепите вспомогательный материал к [сообщению чата](discussions.md), когда вам нужно уточнить запрос. Прежде чем делиться информацией, обратите внимание на аудиторию обсуждения.

## Исправленные файлы {#revised-files}

В версии можно добавлять, удалять или заменять файлы запросов. Просмотрите текущий список файлов и используйте **Show revision changes** для контекста. Пометки заменённых и удалённых файлов помогают отличать изменения от текущих документов для проверки.

## Проблемы с загрузкой {#upload-problems}

Перед отправкой дождитесь завершения загрузки. Если загрузка отклонена, прочтите сообщение об ошибке и проверьте [ограничения использования файла и рабочей области](usage.md). Избегайте повторной отправки, пока запрос еще обрабатывается. См. раздел [Устранение неполадок](troubleshooting.md) для получения информации о неудачных действиях.

## Токены и хранилище {#tokens-and-storage}

Загрузка файлов на сервер, просмотр и скачивание расходуют токены. Размер файлов также учитывается в отдельном лимите хранилища. За файлы задач и обсуждений платит рабочее пространство, из которого запущен процесс; для остальных загрузок используется выбранное рабочее пространство. Токены за загрузку на сервер списываются только после её успешного завершения. Одновременная передача файлов может привести к отрицательному остатку токенов. При прерывании скачивания учитываются уже переданные байты документа. См. [Использование и токены](usage.md).
