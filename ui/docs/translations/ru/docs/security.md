# MFA и ключи доступа {#mfa-and-passkeys}

Защитите свою учетную запись Click2Approve с помощью **многофакторной аутентификации (MFA)** или **ключа доступа**. При использовании аутентификатора MFA вы вводите код из приложения аутентификатора после пароля. Ключ доступа позволяет вам войти в систему через поддерживаемое устройство или ключ безопасности, используя подсказку браузера.

Эти настройки применяются к вашей учетной записи в Personal и рабочих областях организации.

## Включить аутентификатор MFA {#enable-authenticator-mfa}

1. Откройте **User profile → Security**.
2. Включите **Use multi-factor authentication**.
3. Отсканируйте QR-код настройки в приложении для аутентификации или введите ключ настройки вручную.
4. Введите код подтверждения от аутентификатора для подтверждения настройки.
5. Сохраните коды восстановления в надежном месте и подтвердите, что вы их сохранили.
6. Выберите **Done — sign in again**, затем войдите в систему, используя свой пароль и код аутентификации.

После настройки для входа в систему с паролем потребуется дополнительный запрос MFA. При запуске настройки ваш сеанс меняется: для завершения или отмены требуется повторный вход в систему.

## Коды восстановления {#recovery-codes}

Используйте сохраненный код восстановления, если вы не можете получить доступ к аутентификатору.

!!! warning "Храните коды восстановления в безопасности"
    Каждый код секретный и может быть использован только один раз. **Generate new recovery codes** заменяет предыдущий набор; сохраните новые коды перед закрытием окна.

Для создания новых кодов восстановления или отключения MFA также потребуется повторный вход после завершения.

Чтобы отключить MFA, используйте вкладку Security и выполните запрошенную проверку. Не удаляйте единственный рабочий метод входа, прежде чем протестировать другой.

## Добавьте ключ доступа {#add-a-passkey}

1. Откройте **User profile → Passkeys** и выберите новое действие ключа доступа.
2. Введите имя, которое вы узнаете позже.
3. Заполните запрос браузера или устройства, используя свои биометрические данные, PIN-код или ключ безопасности.
4. Убедитесь, что учетные данные отображаются в списке.

Используйте вход с ключом доступа на поддерживаемом устройстве и в браузере. Ключи доступа требуют совместимого устройства и браузера. Сохраняйте свой пароль доступным для восстановления учетной записи.

## Удаление ключа доступа {#remove-a-passkey}

Выберите учетные данные в списке Ключи доступа и используйте действие удаления. Сначала проверьте его имя и последние использованные данные. Его удаление отменяет доступ к этим учетным данным; оно не удаляет другие зарегистрированные ключи доступа.

После удаления приложение уведомляет совместимые менеджеры паролей, чтобы они больше не предлагали удаленный ключ доступа. Ваш браузер или менеджер паролей могут не поддерживать это обновление. Если ключ доступа все еще отображается, удалите его вручную из менеджера паролей; он больше не сможет войти в вашу учетную запись.

В случае утери аутентификатора или недоступного устройства попробуйте настроенный альтернативный метод или код восстановления. Если ничего недоступно, обратитесь за помощью в службу поддержки.
