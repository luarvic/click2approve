# Управление организациями {#manage-organizations}

**Организация** — это рабочая область для утверждения документов, отправляемых от имени компании. В ней хранятся собственные запросы, сотрудников, команды, шаблоны и делегированную работу. Выберите её в переключателе рабочих пространств, прежде чем создавать запрос или управлять сотрудниками.

!!! info "Рабочая область организации"
    Создайте или выберите организацию для управления совместной работой. В вашем рабочем пространстве Personal нет сотрудников, команд, шаблонов или делегирований.

## Создайте организацию {#create-an-organization}

1. Откройте **Organizations** и создайте новую организацию.
2. Введите данные организации и при необходимости добавьте логотип.
3. Перейдите к выбору тарифа. Используйте **Back**, чтобы редактировать детали, сохраняя черновик создания.
4. Выберите **Choose Business Trial** или **Choose Business Pro**, затем используйте **Subscribe** под карточками, чтобы создать организацию.
5. Для платного плана завершите оформление заказа. Доступ к рабочей области остается ограниченным до тех пор, пока платеж не будет подтвержден.

Бизнес-пробная версия доступна один раз для каждого владельца. Повторный выбор не проходит проверку. См. [Планы и выставление счетов](plans-and-billing.md) для получения информации о платежах и возмещении.

## Настройте рабочее пространство {#set-up-the-workspace}

Выберите организацию в средстве выбора рабочего пространства, затем:

- Добавьте [сотрудников](employees.md) и выберите их роли.
- Создайте [команды](teams.md) для повторяющихся групп участников.
- Настройте [делегирование](delegations.md) для сотрудников, которым нужно, чтобы кто-то действовал от их имени.
- Сохраните [шаблоны согласования](templates.md) для повторяющихся процессов.

Сотрудники, команды и делегаты должны принадлежать к этой организации. Работа в другой организации остается отдельной.

## Обновить сведения об организации {#update-organization-details}

Откройте организацию из **Organizations**, чтобы изменить сведения, разрешенные вашей ролью. Изображения логотипов могут иметь размер до **4 MiB** (4 194 304 байта). Сохраняйте название компании и логотип узнаваемыми, чтобы участники могли идентифицировать организацию в контексте запроса и уведомлениях.

## Удаление организации {#delete-an-organization}

Только **Owner** может запланировать удаление через **Delete organization**. Внимательно прочитайте подтверждение. Запланированные организации исчезают из выбора рабочего пространства и становятся недоступными; фоновая обработка удаляет их данные позже.

!!! warning "Сохранять записи перед удалением"
    При планировании удаления немедленно удаляется доступ к организации. Сохраните все необходимые записи перед подтверждением; задержка очистки не является окном восстановления. См. [Хранение и удаление](retention.md).
