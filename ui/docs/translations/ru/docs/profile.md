# Профиль и сохраненная электронная подпись {#profile-and-signature}

Откройте **User profile** в меню профиля, чтобы обновить свое имя, выбрать рабочее пространство по умолчанию или сохранить подпись для будущих задач утверждения. Эти настройки принадлежат вашей учетной записи и доступны всем рабочим областям, к которым у вас есть доступ.

## Личные данные {#personal-details}

В **Profile** обновите свое имя, фамилию, аватар и рабочую область по умолчанию по мере необходимости. Выберите **Save** после редактирования полей профиля или выбора аватара. Рабочая область по умолчанию определяет, с чего вы предпочитаете начать; оно не перемещает запросы или задачи между рабочими пространствами.

Изображения аватара могут иметь размер до **4 MiB** (4 194 304 байт).

Имена и должности сотрудников организации управляются отдельно в [Сотрудники](employees.md). Если атрибуция организации неверна, попросите владельца или администратора просмотреть запись сотрудника.

## Сохраненная подпись {#saved-signature}

1. Откройте вкладку **Signature**.
2. Нарисуйте или обновите подпись по умолчанию.
3. Выберите **Save**.

Сохраненная подпись заполняется автоматически при подписании запроса на утверждение. Проверяйте подпись перед каждым решением и сверяйте полное имя и сведения о представительстве, запрошенные в форме подписи. Сохранение подписи в вашем профиле не означает подписание или выполнение задачи.

## Другие вкладки профиля {#other-profile-tabs}

Используйте **Security** для аутентификатора MFA, **Passkeys** для учетных данных устройства, **API tokens** для учетных данных API и **Notifications** для настроек доставки.

См. [MFA и ключи доступа](security.md), [API токены](api-tokens.md) и [Уведомления](notifications.md) для соответствующих элементов управления.
