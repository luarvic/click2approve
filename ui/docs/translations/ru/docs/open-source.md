# Система утверждения документов с открытым исходным кодом {#open-source-document-approval-system}

Click2Approve — это бесплатная система утверждения документов с открытым исходным кодом, имеющая лицензию MIT, которую вы можете разместить в своей собственной инфраструктуре. Загружайте документы, назначайте рецензентов по адресу электронной почты и отслеживайте их решения с помощью многоэтапного рабочего процесса утверждения. Вы можете запрашивать электронные подписи и комментарии, когда задача требует объяснения.

Редакция с открытым исходным кодом поддерживает отдельные учетные записи и рабочие процессы с личными документами для личного или коммерческого использования. Плата за лицензию Click2Approve не взимается; вы покрываете расходы на инфраструктуру и провайдера. Чтобы начать работу, ознакомьтесь с [исходным кодом и инструкциями по самостоятельному размещению](https://github.com/luarvic/click2approve).

Коммерческая версия добавляет рабочие области организации, инструменты для совместной работы, а также элементы управления использованием и хранением на основе подписки. Другие руководства на этом портале описывают коммерческую услугу; используйте это сравнение, чтобы проверить, какие функции применимы к версии с открытым исходным кодом.

## Пример: просмотрите и утвердите предложение {#example-review-and-approve-a-proposal}

1. Загрузите предложение и добавьте этап утверждения для людей, которым необходимо его просмотреть.
2. Выберите, должны ли отвечать все, кому назначен этот шаг, или его может выполнить один рецензент. Шаги рабочего процесса выполняются по порядку, и на каждом этапе могут действовать несколько исполнителей.
3. Добавьте этап подписания, если для предложения также требуется электронная подпись.
4. Отслеживайте ход выполнения запроса и записывайте решения от **Requests**. Каждый участник находит назначенную ему работу в **Tasks**.

См. разделы [Создать запрос](create-a-request.md) и [Настройка шагов рабочего процесса](workflow-steps.md) для элементов управления рабочим процессом. Общие записи о результате и проверка файлов являются коммерческими функциями; при выборе редакции смотрите сравнение ниже.

## Используйте приложение с открытым исходным кодом {#use-the-open-source-app}

1. Зарегистрируйтесь или войдите под своей учетной записью.
2. Выберите **New request**, загрузите файлы и настройте этапы рабочего процесса с адресами электронной почты ответственных лиц. См. разделы [Создание запроса](create-a-request.md) и [Настройка шагов рабочего процесса](workflow-steps.md) для общих элементов управления рабочим процессом.
3. Используйте **Requests** для отслеживания отправленной вами работы и **Tasks** для выполнения назначенных вам действий. См. [Выполнить задачу](complete-a-task.md) для комментариев и подписей; вложения с ответами доступны в коммерческой версии.

Навигация по организации и коммерческие инструменты скрыты в приложении с открытым исходным кодом. Вы можете управлять своим профилем, сохраненной подписью, настройками уведомлений, MFA и ключами доступа через меню профиля.
