# Руководства по рабочему процессу утверждения документов {#table-of-contents}

Click2Approve — это система утверждения документов. Отправляйте документы людям, которым необходимо их просмотреть. Собирайте решения и электронные подписи, а также отслеживать результат. В этих руководствах объясняется, как легко использовать приложение.

**Запрос** содержит ваши документы, инструкции и этапы рабочего процесса. Каждый человек, назначенный на шаг, получает **задачу**. **Запись о результате** записывает результат после завершения запроса.

Click2Approve также имеет бесплатную [версию с открытым исходным кодом](open-source.md) для самостоятельных личных рабочих процессов. См. сравнение версий, чтобы узнать о включенных функциях и коммерческих дополнениях.
