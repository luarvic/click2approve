# Повторно используйте шаблоны рабочих процессов утверждения документов {#workflow-templates}

Используйте шаблоны рабочих процессов, когда вы часто отправляете документы через один и тот же процесс утверждения. Шаблон сохраняет шаги запроса и участников внутри организации. Вы добавляете текущие документы при создании каждого запроса.

Например, сохраните этап проверки предложения, за которым следует этап подписания. Повторите эти шаги для следующего предложения, а затем проверьте рецензентов, подписывающего лица и файлы перед отправкой.

Каждый шаблон принадлежит тому, кто его создает. По умолчанию шаблоны являются частными. Выберите **Shared**, чтобы разрешить другим активным участникам той же организации просматривать и использовать шаблон. Только его создатель может редактировать или удалять его, в том числе, если другой участник является владельцем или администратором.

!!! info "Только организация"
    Выберите организацию для создания и повторного использования шаблонов рабочих процессов. Шаблоны принадлежат этой организации и недоступны в Personal.

## Создайте шаблон {#create-a-template}

Откройте **Templates** в организации и создайте шаблон с описательным именем и шагами, которые можно использовать повторно. Настройте действия, инструкции, исполнителей, правила завершения, видимость и дополнительные требования, а затем сохраните.

Выберите **Shared**, если другие участники организации должны повторно использовать его. Оставьте этот флажок снятым, чтобы сохранить конфиденциальность шаблона. В списке шаблонов отображаются **Shared** и **Owner**, чтобы вы могли идентифицировать доступные рабочие процессы и их создателей.

Имена общих шаблонов должны быть уникальными в пределах организации. Имена частных шаблонов должны быть уникальными среди ваших личных шаблонов в этой организации. Вы можете владеть как общим шаблоном **Budget**, так и частным шаблоном **Budget**. Переименование шаблона или изменение **Shared** также должно соответствовать этим правилам.

При создании нового запроса в организации без использования шаблона **Save template** создает частный шаблон на основе его названия, описания и шагов. Он применяет те же правила проверки шаблона и не перезаписывает существующий шаблон. Если заголовок конфликтует с одним из имен ваших личных шаблонов, перед сохранением выберите другой заголовок. Проверьте, что вы сохраняете: шаблон рабочего процесса хранит конфигурацию шага, а не завершенный запрос или записанные решения.

## Запустите запрос из шаблона {#start-a-request-from-a-template}

1. Выберите **New request** в той же организации.
2. Выберите **From template**, выберите один из своих шаблонов или общий шаблон организации и продолжайте.
3. Введите название запроса, описание и текущие документы.
4. Прежде чем выбрать **Submit**, просмотрите каждого участника и шаг.

Шаблоны предоставляют начальную конфигурацию. Убедитесь, что сотрудники и команды по-прежнему соответствуют новому запросу. Не предполагайте, что шаблон предоставляет файлы для конкретной транзакции.

В списке выбора шаблоны разделены на группы **Private templates** и **Shared templates**. Выберите имя из соответствующей группы, если обе группы содержат шаблон с одинаковым именем.

Редактор загружает шаблон перед началом редактирования. Его имя и описание предоставляют исходный текст запроса; измените их для текущего запроса перед отправкой.

## Сохранение шаблонов {#maintain-templates}

Откройте **Templates**, чтобы обновить повторяющиеся инструкции и выбор участников. Любой активный участник организации может создавать свои собственные шаблоны и управлять ими. Редактирование шаблона не приводит к изменению уже отправленных запросов.

Шаблоны, которыми поделились другие участники, открываются в режиме только для чтения. Попросите создателя обновить шаблон, когда потребуется изменить его повторно используемые шаги. Очистка **Shared** удаляет доступ других участников к шаблону; уже созданные из него запросы сохраняют скопированный рабочий процесс. **Save template** доступен только для новых пользовательских запросов. Чтобы изменить существующий шаблон, используйте **Templates**. Запросы, начатые из шаблона, и версии запросов не предлагают **Save template**.

Удалите неиспользуемые шаблоны с помощью доступного действия удаления. Если удаление заблокировано ссылкой, следуйте сообщению проверки, а не повторяйте попытку повторно.
