# Токены API для интеграции согласования документов {#api-tokens}

Используйте Click2Approve API для подключения собственных инструментов и автоматизации рабочих процессов утверждения. Токены API позволяют интеграциям получать доступ к API через вашу учетную запись пользователя. Управляйте ими в своем профиле, независимо от того, работаете ли вы в Personal или в организации.

## Создайте токен {#create-a-token}

1. Откройте **User profile → API tokens**.
2. Выберите **New API token**.
3. При необходимости введите узнаваемое имя и срок действия.
4. Создайте токен и скопируйте его значение перед закрытием диалогового окна.
5. Сохраните его в надежном месте для предполагаемой интеграции.

!!! warning "Скопируйте токен перед закрытием"
    Полное значение отображается только один раз. Храните его в надежном месте и не допускайте попадания в сообщения, снимки экрана и систему контроля версий. Если вы потеряете его, создайте замену и отзовите старый токен.

## Изучите API {#explore-the-api}

Откройте [справочник API (Swagger UI)]({{ api_reference_url }}){target="_blank" rel="noopener noreferrer"} для просмотра конечных точек, полей запросов и ответов.

Чтобы попробовать аутентифицированный запрос, выберите **Authorize**, вставьте свой токен API без префикса `Bearer` и подтвердите. Swagger добавит для вас заголовок авторизации. Выберите конечную точку, выберите **Try it out**, заполните необходимые поля и выберите **Execute**. Эти запросы используют вашу учетную запись и могут создавать, изменять или удалять реальные данные.

Конечные точки безопасности учетной записи требуют интерактивного сеанса входа и не могут использоваться с токенами API.

## Используйте токен в своей интеграции {#use-a-token-in-your-integration}

Передавайте токен в заголовке `Authorization` для каждого запроса API:

```http
Authorization: Bearer YOUR_API_TOKEN
```

Замените `YOUR_API_TOKEN` значением, которое вы скопировали при создании токена. Токены действуют в соответствии с разрешениями вашей учетной записи. Создание токена не предоставляет доступ к работе другого пользователя или ресурсам другой организации; авторизация по-прежнему применяется.

## Отозвать токен {#revoke-a-token}

Выберите токен в списке, выберите **Revoke** и подтвердите. Обновите любую интеграцию, которая использовала его, заменяя учетные данные. Отзовите неиспользуемые токены и учетные данные, которые, как вы подозреваете, были раскрыты.

Токены API — это настройки учетной записи. Переключение рабочих пространств не создает отдельный набор токенов.
