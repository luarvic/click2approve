# Функции утверждения документов и доступ к рабочему пространству {#features-and-availability}

Click2Approve сочетает в себе проверку документов, этапы утверждения, электронные подписи и отслеживание запросов. Используйте **Personal**, свое рабочее пространство для собственных запросов и задач, адресованных по электронной почте, для индивидуальной работы. Используйте рабочее пространство организации для общих бизнес-процессов. Ваше рабочее пространство, роль и план определяют, какие действия вы можете предпринять.

Вы также можете подключить свои собственные инструменты через Click2Approve API. См. [API токены](api-tokens.md) для создания учетных данных и аутентификации запросов на интеграцию.

!!! info "Только для организации"
    Сотрудники, команды, делегирование и шаблоны рабочих процессов принадлежат организациям. Выберите организацию в средстве выбора рабочей области, чтобы использовать их. Другие функции, описанные в этом руководстве, также доступны в Personal.

## Как работает утверждение документов {#how-document-approval-works}

1. [Создать запрос](create-a-request.md) с документами и инструкциями.
2. [Настройте шаги рабочего процесса](workflow-steps.md), чтобы выбрать, кто будет действовать и в каком порядке. Несколько человек могут просматривать на одном этапе.
3. Участники открывают **Tasks**, чтобы [записать свои решения](complete-a-task.md). Для шага может потребоваться комментарий, электронная подпись или файл ответов.
4. Откройте **Requests**, чтобы [проверить ход выполнения](track-requests.md). Когда запрос завершается, [записи о результате](receipts.md) сохраняют его результат и записанные действия.

Например, два участника проверяют предложение на первом этапе, а клиент подписывает его на следующем. Если нужна нарисованная подпись, включите **Require an electronic signature** на этапе подписания.

## Разрешения организации {#organization-permissions}

Участники могут просматривать каталоги сотрудников, команд и делегирований. Владельцы и администраторы управляют сотрудниками, командами, делегированием, оплатой и сроками хранения. По умолчанию шаблоны являются частными; их создатели могут делиться ими с другими членами организации для просмотра и использования. Только создатель может редактировать или удалять шаблон. Доступ к записям о результате ограничен пользователем, которому выдана каждая запись о результате. Только владелец может запланировать удаление организации.

Доступ к запросу или задаче зависит от участия, взаимоотношений в команде и делегирования. Членство в организации само по себе не раскрывает все рабочие процессы и не предоставляет доступ к записям другой организации.

См. [Сотрудники и роли](employees.md) для получения информации о роли и [Использование и ограничения](usage.md) для ознакомления с ограничениями плана. Откройте **Plans**, чтобы узнать о доступных возможностях тарифа и доступных вариантах плана.
