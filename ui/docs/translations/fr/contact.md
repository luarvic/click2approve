# Parlons-en {#lets-talk}

Vous avez une question sur un flux de travail, avez trouvé quelque chose d'inattendu ou avez une idée pour Click2Approve ?

## Poser une question {#ask-a-question}

Démarrer une conversation dans [GitHub Discussions](https://github.com/luarvic/click2approve/discussions). Incluez ce que vous essayez de faire et les domaines dans lesquels vous avez besoin d'aide. Un compte GitHub est requis pour publier.

## Signaler un bug {#report-a-bug}

[Ouvrir un problème](https://github.com/luarvic/click2approve/issues) avec les étapes pour reproduire le problème, ce à quoi vous vous attendiez et ce qui s'est passé. Laissez les mots de passe, les documents privés et autres informations sensibles hors des rapports publics.

## Questions sur les comptes privés et la confidentialité {#private-account-and-privacy-questions}

E-mail [contact@click2approve.com](mailto:contact@click2approve.com) pour les demandes de compte, de sécurité, juridiques ou de confidentialité. N'envoyez pas de mots de passe ou de pièces d'identité inutiles.

## Besoin d'un point de départ ? {#need-a-starting-point}

[Lire le guide de démarrage](docs/index.md) pour connaître les bases des requêtes et des tâches.
