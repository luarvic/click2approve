# Premiers pas avec les approbations de documents {#getting-started}

Utilisez Click2Approve pour envoyer des documents pour révision, approbation ou signature électronique. Une **demande** correspond au travail que vous envoyez, y compris ses fichiers, ses instructions et ses participants. Une **tâche** est l'action d'un participant dans cette demande. Les étapes du workflow s'exécutent dans l'ordre que vous choisissez.

Par exemple, envoyez une proposition à l'adresse e-mail d'un client et demandez une signature électronique. Le client se connecte, examine la proposition et soumet une signature. Une fois la demande terminée, Click2Approve crée un **reçu** : un enregistrement du résultat que vous pouvez partager via un lien de vérification. Voir [Reçus et vérification](receipts.md).

## Faites un tour rapide {#take-a-quick-tour}

La première fois que vous ouvrez l'application après vous être connecté, un court guide de l'utilisateur met en évidence vos paramètres de profil, vos notifications, votre sélecteur d'espace de travail et vos groupes de menu principal. Si une invite de configuration de clé d'accès apparaît, terminez-la ou ignorez-la d'abord.

Choisissez **Next** et **Back** pour vous déplacer dans le guide,**Finish** pour le terminer ou **Skip** pour le fermer. Vous pouvez également le fermer avec Échap.

Sur les écrans courts, appuyez sur Tab pour **User guide instructions** et utilisez Page suivante ou les touches fléchées pour faire défiler l'explication. Les boutons de navigation restent visibles.

Le guide affiche la navigation disponible dans votre espace de travail actuel. Il explique le sélecteur d'espace de travail lorsqu'il est disponible. Dans Personal, il est également expliqué que les organisations disposent d'un groupe **People** pour les employés, les équipes et les délégations.

La fin ou le saut sont mémorisés pour votre compte dans ce navigateur. Un autre navigateur, ou la suppression des données enregistrées du site, fait réapparaître le guide. Pour y revenir à tout moment, ouvrez le menu principal et choisissez **Replay user guide** sous **Support**.

## Envoyez votre première demande {#send-your-first-request}

1. Choisissez **Ouvrir l'application** sur le site Web pour continuer dans le même onglet du navigateur, ou [ouvrir l'application directement](/app/), puis [vous connecter ou vous inscrire](sign-in.md).
2. Utilisez **Personal**, votre espace de travail pour vos propres demandes, ou sélectionnez une organisation dans le sélecteur d'espace de travail pour envoyer du travail en son nom.
3. Choisissez **New request** dans le menu principal.
4. Saisissez un titre et une description, ajoutez des fichiers et configurez les étapes et les responsables.
5. Vérifiez les détails, puis choisissez **Submit**.
6. Ouvrez **Requests** pour suivre le résultat.

[Créer une demande](create-a-request.md) explique chaque partie de la soumission.

## Terminez votre première tâche {#complete-your-first-task}

Connectez-vous avec l'adresse e-mail à laquelle la demande a été envoyée. Pour les tâches envoyées à cette adresse, sélectionnez **Personal** dans le sélecteur d'espace de travail ; pour les affectations d'employés ou d'équipes, sélectionnez l'organisation. Ouvrez **Tasks**, sélectionnez la tâche, lisez ses instructions et examinez les fichiers actuels. Fournissez tout commentaire, signature ou pièce jointe requis, puis soumettez votre décision. Voir [Terminer une tâche](complete-a-task.md).

## Personal et travail commercial {#personal-and-business-work}

Tout le monde commence avec un espace de travail Personal. Les organisations ajoutent des employés, des équipes, des délégations et des modèles de flux de travail réutilisables.

!!! info "Fonctionnalités d'organisation"
    Sélectionnez une organisation pour utiliser ses employés, ses équipes, ses délégations et ses modèles. Les discussions, les reçus, les révisions et la sécurité des comptes sont également disponibles dans Personal. Votre rôle et votre plan déterminent les actions que vous pouvez entreprendre ; voir [Caractéristiques et disponibilité](features.md).
