# Profil et signature électronique enregistrée {#profile-and-signature}

Ouvrez **User profile** dans le menu du profil pour mettre à jour votre nom, choisir un espace de travail par défaut ou enregistrer une signature pour de futures tâches d'approbation. Ces paramètres appartiennent à votre compte et sont partagés dans les espaces de travail auxquels vous pouvez accéder.

## Informations personnelles {#personal-details}

Sur **Profile**, mettez à jour votre prénom, votre nom, votre avatar et votre espace de travail par défaut si nécessaire. Choisissez **Save** après avoir modifié les champs de profil ou sélectionné un avatar. L'espace de travail par défaut contrôle par où vous préférez commencer ; il ne déplace pas les demandes ou les tâches entre les espaces de travail.

Les images d'avatar peuvent atteindre **4 Mio** (4 194 304 octets).

Les noms et postes des employés de l'organisation sont gérés séparément dans [Employés](employees.md). Si l'attribution à l'organisation est incorrecte, demandez à un propriétaire ou à un administrateur d'examiner le dossier de l'employé.

## Signature enregistrée {#saved-signature}

1. Ouvrez l'onglet **Signature**.
2. Dessinez ou mettez à jour votre signature par défaut.
3. Choisissez **Save**.

La signature enregistrée est préremplie lorsque vous signez une demande d'approbation. Examinez-le avant chaque décision et vérifiez le nom légal et les détails de représentation demandés par le formulaire de signature. L'enregistrement d'une signature dans votre profil ne signe ni ne termine une tâche.

## Autres onglets de profil {#other-profile-tabs}

Utilisez **Security** pour l'authentificateur MFA,**Passkeys** pour les informations d'identification de l'appareil,**API tokens** pour Informations d'identification API et **Notifications** pour les préférences de livraison.

Voir [MFA et clés d'accès](security.md), [Jetons API](api-tokens.md) et [Notifications](notifications.md) pour les champs correspondants.
