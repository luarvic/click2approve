# Espaces de travail et navigation {#workspaces-and-navigation}

Un **espace de travail** regroupe les demandes, tâches et paramètres auxquels vous avez accès. Chaque compte commence dans **Personal**, pour ses propres demandes et les tâches adressées à son e-mail. Si vous appartenez à une organisation, utilisez le sélecteur d’espace pour accéder au travail partagé. Choisissez votre espace de démarrage dans le [profil utilisateur](profile.md).

## Personal {#personal}

Utilisez Personal pour les demandes envoyées en votre nom et les tâches adressées à l’e-mail du compte. Cet espace ne possède pas d’annuaire d’employés ni d’équipes.

Une organisation peut vous envoyer une tâche par e-mail. Elle arrive dans Personal sans vous rendre employé ni vous donner accès à son espace. Les listes indiquent l’organisation d’origine pour distinguer les expéditeurs.

## Organisations {#organizations}

Le travail reste dans l’organisation sélectionnée. Les tâches des employés et équipes figurent dans sa vue Tasks. Sa vue Requests comprend les demandes accessibles selon votre identité de demandeur, vos équipes et les délégations autorisées.

Employés et délégués doivent appartenir à la même organisation. Une adhésion ne donne aucun accès aux demandes ou tâches d’une autre organisation.

Avec une délégation, le sélecteur propose aussi l’organisation accompagnée du nom de l’employé représenté. Sélectionnez cette entrée pour agir en son nom, puis la vôtre pour revenir à votre travail. Voir les [délégations](delegations.md).

Le petit badge en haut à droite du nom de marque indique **App** dans l’application commerciale,**Free** dans l’édition open source et **Docs** dans la documentation.

## Menu principal {#main-menu}

| Rubrique | Utilité |
| --- | --- |
| Tasks | Traiter les actions qui vous sont attribuées ou accessibles par votre rôle dans le processus |
| Requests | Suivre les demandes accessibles ; utiliser New request pour en envoyer une |
| Receipts | Consulter, partager et supprimer les reçus qui vous sont délivrés dans les deux types d’espace |
| Templates | Réutiliser les étapes des processus de l’organisation |
| Employees, Teams, Delegations | Gérer les membres, les équipes et le travail délégué |
| Plans, Usage, Retention | Consulter l’abonnement, les limites et les paramètres des données |
| Organizations | Créer et gérer les espaces d’entreprise |

Le menu du profil donne accès aux paramètres du compte et aux préférences de notification. La cloche ouvre les notifications de l’espace sélectionné. Sur petit écran, le bouton de menu ouvre le volet de navigation. Le commutateur de thème modifie ensemble l’application et Docs sur le même site.

Les petites étiquettes en majuscules identifient groupes, cartes, sections et étapes. Les titres et commandes utilisent la casse de phrase. Le fil d’Ariane au-dessus du titre permet de revenir aux pages parentes. **Docs** ouvre les guides dans le même onglet, comme les liens du site et **Read documentation**. Dans l’application open source, Docs ouvre le guide de l’[édition open source](open-source.md) et le comparatif des fonctionnalités.

Les titres et noms verts des tableaux sont des liens. Ils sont soulignés au survol et au focus clavier ; le focus possède aussi un contour visible.

Le pied de page contient Home, App, Docs, Contact, Terms et Privacy. Tous s’ouvrent dans le même onglet.

Utilisez le sélecteur de langue dans l’en-tête du site ou de la documentation pour lire la même page dans une autre langue. Le site mémorise votre choix dans ce navigateur. Les liens anglais vers le site ou la documentation ouverts depuis l’application redirigent vers la langue enregistrée ; un préfixe de langue explicite dans l’URL reste prioritaire. La recherche renvoie les pages dans la langue de l’URL. L’application reste en anglais : les guides conservent les noms exacts de ses commandes et en expliquent le sens dans la langue choisie.

Le menu regroupe les pages sous **Work**, **Access**, **People**, **Subscription** et **Support**. Un groupe apparaît seulement si ses fonctions sont disponibles dans l’espace sélectionné. Choisissez **Replay user guide** dans **Support** pour découvrir la barre d’application et la navigation ; voir [Premiers pas](getting-started.md#take-a-quick-tour).

## Ouvrir un lien partagé {#open-a-shared-link}

Connectez-vous au compte prévu lorsque vous suivez un lien reçu par e-mail ou partagé. Le lien n’accorde aucune permission supplémentaire. Si la ressource est indisponible, vérifiez l’espace, le compte, l’accès de l’employé et une éventuelle suppression. Voir le [dépannage](troubleshooting.md).
