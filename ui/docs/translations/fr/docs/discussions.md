# Discuter des documents dans le chat des demandes et des tâches {#discussions}

Utilisez **Chat** pour poser des questions sur un document avant de l'approuver ou de le signer. Vous pouvez partager des fichiers de support dans la discussion. Le chat est disponible dans les espaces de travail Personal et de l'organisation.

## Renseignez-vous sur une demande {#ask-about-a-request}

1. Ouvrez une requête ou une tâche accessible.
2. Sélectionnez **Chat**.
3. Lisez les messages existants pour le contexte.
4. Entrez votre message. Utilisez le trombone à l'intérieur de **Message** pour joindre les fichiers justificatifs, puis choisissez **Send**.

Vos messages apparaissent à droite ; les messages des autres personnes apparaissent sur la gauche. Sur demande, les conversations sont regroupées par étape du workflow. Sur une tâche, Chat affiche l'étape en cours.

Utilisez la flèche à côté de l'en-tête d'une étape pour afficher ses participants par ordre alphabétique. Utilisez-le à nouveau pour masquer la liste. Les messages restent visibles lorsque la liste des participants est masquée.

Utilisez Chat pour les questions et les éclaircissements. Enregistrez la décision réelle via les contrôles d'action de la tâche afin qu'elle devienne un résultat du flux de travail.

## Audience et accès {#audience-and-access}

L'accès aux discussions dépend de la demande, de la tâche et de vos autorisations. Un lien partagé ou une adhésion à une organisation ne donne pas à tout le monde accès à la conversation. Vérifiez le contexte avant de publier du matériel sensible.

Les délégués participent uniquement via l'accès accordé au sein de leur organisation. Les messages de discussion et les notifications conservent l'attribution de l'auteur.

## Lorsque vous ne pouvez pas envoyer {#when-you-cannot-send}

L'envoi peut être interrompu lorsque le flux de travail n'a plus de tâche en attente exploitable ou est terminé. Si le champ de message n'est pas disponible, actualisez la ressource et vérifiez son état actuel ainsi que votre accès. La discussion peut rester disponible en lecture même lorsque les nouveaux messages ne sont plus autorisés.

## Notifications {#notifications}

Les notifications de discussion dépendent de vos [Préférences de notification de discussion](notifications.md) et de l'audience autorisée à recevoir ce message. Un fichier envoyé dans Chat est distinct d'une [pièce jointe de décision requise](files.md).
