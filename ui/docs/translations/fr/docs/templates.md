# Réutiliser les modèles de workflow d'approbation de documents {#workflow-templates}

Utilisez des modèles de workflow lorsque vous envoyez souvent des documents via le même processus d'approbation. Un modèle enregistre les étapes de la demande et les participants au sein d'une organisation. Vous ajoutez les documents actuels lorsque vous créez chaque demande.

Par exemple, enregistrez une étape de révision de proposition suivie d'une étape de signature. Réutilisez ces étapes pour la prochaine proposition, puis vérifiez les réviseurs, les signataires et les fichiers avant de les soumettre.

Chaque modèle appartient à la personne qui l'a créé. Les modèles sont privés par défaut. Sélectionnez **Shared** pour permettre aux autres membres actifs de la même organisation d'afficher et d'utiliser un modèle. Seul son créateur peut le modifier ou le supprimer, y compris lorsqu'un autre membre est propriétaire ou administrateur.

!!! info "Organisation uniquement"
    Sélectionnez une organisation pour créer et réutiliser des modèles de workflow. Les modèles appartiennent à cette organisation et ne sont pas disponibles dans Personal.

## Créez un modèle {#create-a-template}

Ouvrez **Templates** dans l'organisation et créez un modèle avec un nom descriptif et des étapes réutilisables. Configurez les actions, les instructions, les responsables, les règles d'achèvement, la visibilité et les exigences supplémentaires, puis enregistrez.

Sélectionnez **Shared** si d'autres membres de l'organisation doivent le réutiliser. Laissez-la décochée pour garder le modèle privé. La liste des modèles affiche **Shared** et **Owner** afin que vous puissiez identifier les workflows disponibles et leurs créateurs.

Les noms de modèles partagés doivent être uniques au sein de l'organisation. Les noms de modèles privés doivent être uniques parmi vos propres modèles privés dans cette organisation. Vous pouvez posséder à la fois un modèle **Budget** partagé et un modèle **Budget** privé. Renommer un modèle ou modifier **Shared** doit également respecter ces règles.

Lors de la création d’une nouvelle demande dans une organisation, sans modèle, **Save template** crée un modèle privé à partir de son titre, de sa description et de ses étapes. Il applique les mêmes règles de validation de modèle et n'écrase pas un modèle existant. Si le titre est en conflit avec l'un de vos noms de modèles privés, choisissez un titre différent avant d'enregistrer. Vérifiez ce que vous enregistrez : un modèle de workflow stocke la configuration des étapes plutôt qu'une demande terminée ou ses décisions enregistrées.

## Démarrez une demande à partir d'un modèle {#start-a-request-from-a-template}

1. Choisissez **New request** dans la même organisation.
2. Sélectionnez **From template**, choisissez l'un de vos modèles ou un modèle d'organisation partagé, et continuez.
3. Saisissez le titre, la description et les documents actuels de la demande.
4. Passez en revue chaque participant et chaque étape avant de choisir **Submit**.

Les modèles fournissent une configuration de départ. Vérifiez que les collaborateurs et les équipes sont toujours adaptés à la nouvelle demande. Ne présumez pas qu’un modèle fournit les fichiers pour une transaction particulière.

Le sélecteur regroupe **Private templates** et **Shared templates** séparément. Choisissez le nom dans le groupe approprié lorsque les deux contiennent un modèle portant le même nom.

L'éditeur charge le modèle avant de commencer l'édition. Son nom et sa description fournissent le texte de la demande initiale ; modifiez-les pour la demande en cours avant de la soumettre.

## Gérer les modèles {#maintain-templates}

Ouvrez **Templates** pour mettre à jour vos instructions récurrentes et vos choix de participants. Tout membre actif de l'organisation peut créer et gérer ses propres modèles. La modification d'un modèle ne modifie pas les demandes déjà soumises.

Les modèles partagés par d'autres membres s'ouvrent en lecture seule. Demandez au créateur de mettre à jour le modèle lorsque ses étapes réutilisables doivent être modifiées. La suppression de **Shared** supprime l'accès des autres membres au modèle ; les demandes déjà créées à partir de celui-ci conservent leur workflow copié.**Save template** est disponible uniquement pour les nouvelles demandes personnalisées. Pour modifier un modèle existant, utilisez **Templates**. Les demandes démarrées à partir d'un modèle et les révisions de demandes n'offrent pas **Save template**.

Supprimez les modèles inutilisés avec l’action de suppression disponible. Si la suppression est bloquée par une référence, suivez le message de validation plutôt que de réessayer à plusieurs reprises.
