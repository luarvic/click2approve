# Guides de flux de travail d'approbation de documents {#table-of-contents}

Click2Approve est un système d'approbation de documents. Envoyez des documents aux personnes qui doivent les examiner, collectez les décisions et les signatures électroniques et suivez le résultat. Ces guides expliquent comment utiliser l'application en étapes simples.

Une **demande** contient vos documents, instructions et étapes de flux de travail. Chaque personne affectée à une étape reçoit une **tâche**. Un **reçu** enregistre le résultat une fois la demande terminée.

Click2Approve dispose également d'une [édition open source gratuite](open-source.md) pour les flux de travail personnels auto-hébergés. Consultez la comparaison des éditions pour connaître les fonctionnalités incluses et les ajouts commerciaux.
