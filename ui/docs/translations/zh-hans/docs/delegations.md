# 委派审批任务和请求 {#delegations}

当一名员工需要另一名员工执行其审批任务和请求时，使用**委派**。例如，同事可以在某人不在时代劳。两名员工必须属于同一组织。

!!! info“仅限组织”
    选择一个组织以查看委派。所有者和管理员可以创建、更改和删除它们；两名员工都必须属于该组织。

## 创建委托 {#create-a-delegation}

1. 选择组织并打开**Delegations**。
2. 作为所有者或管理员，启动新的委派。
3. **Employee** — 选择需要由他人代办工作的员工。
4. 在 **Delegate** 中，选择将代表他们行事的员工。
5. 保存并检查关系方向。

两名员工必须属于所选组织。会员可以查看工作委托；所有者和管理员管理它们。委派不会转让所有权或授予不同组织中的成员资格。

## 作为委派 {#work-as-a-delegate}

在工作区选择器中，选择包含您代表的员工的组织条目。这将选择该员工的工作队列。选择自己的作品继续展示自己的作品；委派不会合并队列。

刷新工作区页面只会在您仍具有委派访问权限时恢复该选择。注销会清除选择。

打开授权的任务或请求，查看其上下文，然后执行允许的操作。该记录保留了实际执行的用户和员工，从而可以将操作与原始受派人执行的操作区分开来。

委托方向很重要：选择 Alex 作为 Sam 的委托人允许 Alex 代表 Sam 行事。它不会自动允许 Sam 代表 Alex。

## 更改或取消委托 {#change-or-remove-coverage}

当覆盖范围发生变化时，所有者和管理员可以编辑或删除委托。查看保存的关系并要求代理人刷新他们的工作列表。删除授权并不会删除在其生效期间已记录的决定。
