# 文档审批功能和工作区访问 {#features-and-availability}

Click2Approve 结合了文档审核、审批步骤、电子签名和请求跟踪。使用**Personal**，您的工作空间可满足您自己的请求和电子邮件地址任务以及个人工作。使用组织工作区来共享业务工作流程。您的工作空间、角色和计划决定了您可以采取哪些操作。

您还可以通过 Click2Approve API 连接您自己的工具。请参阅 [API 令牌](api-tokens.md) 以创建凭据并验证集成请求。

!!! info“仅限组织”
    员工、团队、工作委托和工作流模板属于组织。在工作区选择器中选择一个组织来使用它们。 Personal 中也提供了本指南中的其他功能。

## 文档审批的工作原理 {#how-document-approval-works}

1. [创建请求](create-a-request.md) 并附上文档和说明。
2. [配置工作流程步骤](workflow-steps.md) 选择谁执行操作以及执行顺序。多人可以同时审阅。
3. 参与者打开**Tasks**来[记录他们的决定](complete-a-task.md)。步骤可能需要注释、电子签名或响应文件。
4. 打开**Requests**来[检查进度](track-requests.md)。请求完成后，[结果记录](receipts.md) 会保留其结果和记录的操作。

例如，先由两位审核人在第一步检查提案，再由客户在后续步骤签署。若需要手绘签名，请在该步骤启用 **Require an electronic signature**。

## 组织权限 {#organization-permissions}

成员可以查看员工、团队和委派目录。所有者和管理员管理员工、团队、授权、计费和保留。模板默认是私有的；它们的创建者可以共享它们以供其他组织成员查看和使用。只有创建者可以编辑或删除模板。结果记录访问权限仅限于每张结果记录所发给的用户。只有所有者才能安排组织删除。

对请求或任务的访问取决于参与、团队关系和委派。仅凭组织成员资格并不会公开每个工作流程或授予对其他组织记录的访问权限。

请参阅[员工和角色](employees.md) 了解角色参考，并参阅[使用和限制](usage.md) 了解计划限制。打开 **Plans** 了解您当前的津贴和可用的计划选择。
