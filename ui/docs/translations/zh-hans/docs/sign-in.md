# 注册与登录 {#registration-and-sign-in}

登录 Click2Approve 后可发送审批申请或完成任务。账户可访问 **Personal**，即个人申请和邮箱任务的工作区，以及您拥有员工访问权限的组织。打开任务链接时，请使用接收该任务的邮箱。

## 注册 {#register}

1. [打开应用](/app/)，选择注册。
2. 输入邮箱及符合表单要求的密码。
3. 确认密码，阅读[条款](../terms.md)和[隐私政策](../privacy.md)，勾选 **I agree to the Terms and acknowledge the Privacy Policy** 后提交。
4. 如需验证邮箱，打开验证邮件并点击链接。
5. 登录并完善[个人资料](profile.md)。

未勾选协议前，**Sign up** 不可用。

注册会创建 Personal 工作区。组织成员资格通过[员工](employees.md)另行管理。

## 登录 {#sign-in}

输入邮箱和密码。若启用验证器 MFA，还须输入验证器代码或恢复码。设备支持时，也可使用已注册的[通行密钥](security.md)。

从任务或申请邮件进入时，请登录有权访问的账户。链接不能绕过资源权限。

## 验证邮箱 {#confirm-your-email}

找不到邮件时，检查垃圾邮件并使用重新发送功能。请验证准备使用的账户邮箱。链接过期或无效时，在结果页选择 **Request a new verification email**。验证成功后选择 **Sign in** 继续。

## 重设忘记的密码 {#reset-a-forgotten-password}

在登录页选择重设密码，输入邮箱，按邮件指引设置新密码。邮件已发送及密码重设结果页均提供 **Sign in**。重设成功后选择 **Sign in** 继续。重设密码与验证邮箱是两项独立操作。

验证器或通行密钥问题，请参阅 [MFA 与通行密钥](security.md)及[故障排查](troubleshooting.md)。
