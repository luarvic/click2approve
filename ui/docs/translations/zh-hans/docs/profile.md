# 个人资料与保存的电子签名 {#profile-and-signature}

从个人菜单打开 **User profile**，更新姓名、选择默认工作区或保存签名。设置属于账户，在您可访问的各工作区共用。

## 个人信息 {#personal-details}

在 **Profile**更新名字、姓氏、头像和默认工作区。编辑字段或选好头像后，选择**Save**。默认工作区决定您希望从哪里开始，不会在工作区之间移动申请或任务。

头像图片最大 **4 MiB**（4,194,304 字节）。

组织员工的姓名和职位在[员工](employees.md)中单独管理。组织身份信息不正确时，请让 Owner 或 Admin 检查员工记录。

## 保存签名 {#saved-signature}

1. 打开 **Signature** 标签页。
2. 绘制或更新默认签名。
3. 选择 **Save**。

签署审批申请时会预填已保存的签名。每次决定前都应检查签名，以及表单要求的法定姓名和代表身份信息。保存签名不会签署或完成任务。

## 其他资料标签页 {#other-profile-tabs}

**Security**用于验证器 MFA，**Passkeys**用于设备凭据，**API tokens**用于 API 凭据，**Notifications** 用于送达偏好。

相关操作见 [MFA 与通行密钥](security.md)、[API 令牌](api-tokens.md)和[通知](notifications.md)。
