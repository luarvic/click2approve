# 文档审批工作流程指南 {#table-of-contents}

Click2Approve 是一个文档审批系统。将文档发送给需要审阅的人员、收集决策和电子签名并跟踪结果。这些指南解释了如何通过简单的步骤使用该应用程序。

**请求**包含您的文档、说明和工作流程步骤。分配到某个步骤的每个人都会收到一个**任务**。 **结果记录**记录请求完成时的结果。

Click2Approve 还有一个免费的[开源版本](open-source.md)，用于自托管个人工作流程。查看包含的功能和商业附加功能的版本比较。
