# 审批结果记录与文档文件验证 {#receipts-and-verification}

**结果记录**是 Click2Approve 在申请结束时生成的记录，保存申请详情、结果和参与者的操作，包括已提供的签名。您可据此查看谁采取了什么行动，以及记录的结果。

通过验证链接分享后，持有链接的人可查看记录，并检查自己的文档副本是否与记录中的文件一致。

!!! info "谁能管理结果记录？"
    只有记录签发给的用户，才能在工作区打开、删除该记录或管理其验证链接。Personal 和组织均如此；Owner 或 Admin 身份不授予查看他人结果记录的权限。

申请完成、取消或被新修订替代时，申请人及每位实际收到任务的受派人都会获得记录。每人对每个工作区、每个申请修订只获得一份，即使承担多个任务或同时是申请人。任务不必完成也能获得记录；记录中的状态会区分被分配与已执行。未产生任务的步骤不会向受派人签发记录。

## 打开结果记录 {#open-a-receipt}

在发送申请或完成任务的工作区打开 **Receipts**，选择对应记录。**Receipt**卡片标题显示短编号，与申请及任务卡片一致；卡片还显示完整 ID 和日期，随后是**Request**和**Task** 部分，包含详情、结果、参与者、操作及已有签名。

工作区记录及共享验证页面的 **Request**、**Task** 标题均带短编号。可用时，完整申请及任务 ID 仍保留在详情中。

日期使用本地时间，不显示秒。空字段和首次修订编号会隐藏。

打印时，Request 和 Task 部分可以跨页。标题尽量与首行保持在一起；能在一页容纳的详情行和签名不会拆开。

结果记录保存已结束工作的上下文。参与者可见范围可能限制其中包含的步骤。它独立于实时申请。

## 创建验证链接 {#create-a-verification-link}

1. 打开您有权管理的记录。
2. 选择 **Share**。
3. 选择 **New link**，设置 **Expires**，再创建链接。
4. 在列表中选择新链接打开验证地址，复制后分享给预期接收人。

记录卡片中的二维码打开同一验证链接。点击卡片上方的 Click2Approve 标识或名称可返回主页。

!!! warning "持有链接的人都能查看记录"
    有效验证链接无需工作区成员资格即可打开记录。分享前请检查，其中可能包含姓名、决定及签名。

## 验证文件 {#verify-a-file}

在工作区记录或有效验证链接中选择 **Verify file**，再选择自己的文档副本。浏览器计算 **SHA-256 hash**，即由文件内容决定的哈希值。Click2Approve 将其与记录中的哈希比较，判断是否匹配申请文件或参与者回复附件。文件仅在浏览器中读取，不会上传所选副本。

例如，收到已批准的提案及结果链接后，打开链接并用 **Verify file** 检查提案。内容修改过的文件即使名称相同，也不会匹配原哈希。

结果显示在 **Verify file**上方。**File verified**指明匹配的附件及其申请或任务；**File does not match** 表示没有相同哈希的记录文件。请确认选择的版本后重试。

验证依赖记录保存的文件元数据和哈希，因此原附件移除后仍可进行。保存结果记录不会保留原附件。

匹配只确认文件内容与某个已记录文件一致，不评判文档主张，也不独立验证签署者身份。

## 停止分享 {#stop-sharing}

在 **Share**中选中链接，选择**Remove** 并确认。过期或撤销的链接不再提供记录访问。创建新链接不会延长旧链接的有效期。

验证链接不可用时，请向记录所有者索取新链接。公开验证链接只授权查看对应记录，不授予访问组织申请、任务或目录的权限。

## 结果记录的保留期限 {#receipt-retention}

后台按记录所属工作区的[保留策略](retention.md)，从记录创建之日起计算并删除记录及验证链接：

| 方案 | 结果记录保留期限 |
| --- | --- |
| Personal Free | 五年 |
| Business Trial | 一个月 |
| 付费方案 | 配置的 **Requests and receipts**期限，包括**Never delete** |

个人受派人的记录遵循其 Personal 工作区策略，与发起组织的方案无关。更换方案也会改变尚未删除的现有记录策略。删除原申请不会删除结果记录，但工作区移除或付款相关清理可能提前移除它们。

验证链接不是记录的独立备份。撤销链接只停止分享，不删除记录。

## 删除自己的结果记录 {#delete-your-receipt}

在自己的记录上选择 **Delete**，再在 **Delete receipt** 确认。这会永久移除该记录及全部验证链接，不会删除原申请或其他参与者的记录。Owner 和 Admin 也只能删除签发给自己的记录。

若只想停止分享并保留记录，请撤销验证链接。
