# 在请求和任务的聊天中讨论文档 {#discussions}

在批准或签署文档之前，使用 **Chat** 询问有关文档的问题。您可以在讨论中共享支持文件。 Personal 和组织工作区均提供聊天功能。

## 询问请求 {#ask-about-a-request}

1. 打开可访问的请求或任务。
2. 选择 **Chat**。
3. 阅读现有消息以了解上下文。
4. 输入您的信息。使用 **Message**内的回形针附加支持文件，然后选择**Send**。

您的消息显示在右侧；其他人的消息显示在左侧。根据请求，对话按工作流程步骤进行分组。对于任务，聊天会显示当前步骤。

使用步骤标题旁边的箭头按字母顺序显示其参与者。再次使用它来隐藏列表。当参与者列表隐藏时，消息仍然可见。

使用聊天来提问和澄清。通过任务的操作控件记录实际决策，使其成为工作流程结果。

## 受众和访问权限 {#audience-and-access}

讨论访问权限取决于请求、任务和您的权限。共享链接或组织成员身份并不能让每个人都访问对话。在发布敏感材料之前检查上下文。

代表只能通过其组织内授予的访问权限参与。讨论消息和通知保留作者的归属。

## 当您无法发送 {#when-you-cannot-send}

当工作流程不再具有可操作的待处理任务或已完成时，发送可能会关闭。如果 消息输入框 不可用，请刷新资源并检查其当前状态和您的访问权限。即使不再允许新消息，讨论仍然可供阅读。

## 通知 {#notifications}

讨论通知取决于您的[聊天通知首选项](notifications.md) 以及允许接收该消息的受众。在聊天中发送的文件与所需的[决策附件](files.md) 是分开的。
