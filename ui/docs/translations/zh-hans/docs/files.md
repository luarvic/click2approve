# 用于文档审批的文件和附件 {#files-and-attachments}

您可以将文件附加到文档审批请求、参与者的决定或聊天消息。每个地方都有不同的目的。检查附加文件的位置，使其成为您所需记录的一部分。

|你想要... |在此处附加文件 |
| --- | --- |
|发送文档供人们审阅 | **Files to review** 创建请求时 |
|提交包含您的任务响应的文件 | **Your response** 任务 |
|分享额外信息或提出问题 | **Chat** 关于请求或任务 |

每个附件最多可达 **50 MiB**（52,428,800 字节)。这适用于请求、决定和讨论附件。工作区存储和令牌限制也适用。

## 请求文件 {#request-files}

添加参与者在[创建请求](create-a-request.md) 时必须查看的文档。使用可识别的文件名并在提交之前检查所选文件。

打开文件名以使用其可用的预览或下载操作。预览支持取决于文件格式和浏览器。如果预览无法显示文档，请下载并使用合适的应用程序。

## 决策附件 {#decision-attachments}

根据要求在任务操作区域中附加响应文件。如果没有所需的响应文件，则无法完成标记为 **Require an attachment** 的步骤。

决策附件与记录的任务操作一起显示。将同一文件上传到聊天不满足任务的附件要求。

## 讨论附件 {#discussion-attachments}

当您需要澄清请求时，将支持材料附加到[聊天消息](discussions.md)。分享之前请考虑讨论受众。

## 修订文件 {#revised-files}

修订可以添加、删除或替换请求文件。查看当前文件列表并使用 **Show revision changes** 作为上下文。替换和删除的文件显示没有当前审核文档。

## 上传问题 {#upload-problems}

等待上传完成后再提交。如果上传被拒绝，请阅读错误并检查文件和工作区的[使用限制](usage.md)。避免在请求仍在处理时重复提交。请参阅[问题排查](troubleshooting.md) 了解失败的操作。

## 令牌和存储 {#tokens-and-storage}

上传、预览和下载文件会消耗用量点数，文件大小还计入单独的存储限额。任务和讨论中的文件由发起工作流的工作区承担费用，其他上传使用当前选定的工作区。上传仅在成功后计费，失败不扣点。并发传输可能使点数余额变为负数；下载中断时，按已传输的文档字节数计费。请参阅[用量与点数](usage.md)。
