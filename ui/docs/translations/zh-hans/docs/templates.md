# 重复使用文档审批工作流模板 {#workflow-templates}

频繁按相同流程审批文档时，可以使用模板。模板保存组织中的步骤和参与者，创建每份新申请时再添加当前文档。

例如，保存提案审核步骤及后续签名步骤；处理下一份提案时复用，并在提交前核对审核人、签署者和文件。

模板归创建者所有，默认私有。勾选 **Shared** 可让同一组织的其他有效成员查看和使用。只有创建者能修改或删除，即使其他成员拥有 Owner 或 Admin 角色也不例外。

!!! info "仅适用于组织"
    选择组织后才能创建和使用模板。模板属于该组织，Personal 中不可用。

## 创建模板 {#create-a-template}

在组织中打开 **Templates**，填写清晰名称及可复用步骤，配置操作、说明、受派人、完成规则、可见范围和额外要求，再保存。

需要他人复用时启用 **Shared**；否则保持私有。列表显示 **Shared**和**Owner**，便于识别共享状态及创建者。

共享模板名在组织内必须唯一；私有模板名在您于该组织拥有的私有模板中必须唯一。因此可以同时拥有名为 **Budget**的共享模板和私有模板。重命名或切换**Shared** 同样须符合规则。

准备不使用模板的新组织申请时，**Save template** 从其标题、说明和步骤创建私有模板，使用相同验证规则，不覆盖现有模板。若标题与您的私有模板冲突，请先改名。检查保存内容：模板保存步骤配置，不是完成的申请或决定记录。

## 从模板创建申请 {#start-a-request-from-a-template}

1. 在同一组织选择 **New request**。
2. 选择 **From template**，选自己的模板或组织共享模板后继续。
3. 填写本次申请的标题、说明及当前文档。
4. 选择 **Submit** 前检查每位参与者及步骤。

模板只是起始配置。请确认员工和团队仍适合本次申请，不要假定模板包含这笔业务所需的文件。

选择器把 **Private templates**与**Shared templates** 分组。两组同名时，请从正确分组选取。

编辑器先加载模板再允许编辑。模板名称和说明成为申请初始文本，提交前请按当前申请调整。

## 维护模板 {#maintain-templates}

打开 **Templates** 更新重复使用的说明及人员。任何有效组织成员都可创建、管理自己的模板。修改模板不会改变已提交申请。

他人共享的模板以只读方式打开，需要变更时请联系创建者。关闭 **Shared**会移除其他人对模板的访问，但既有申请仍保留已复制的流程。**Save template**只用于未从模板创建的新申请。修改已有模板请使用**Templates**。从模板创建的申请及申请修订均不提供 **Save template**。

不再使用的模板可删除。如被引用阻止，请按验证提示处理，不要反复重试。
