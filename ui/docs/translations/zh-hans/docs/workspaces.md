# 工作区与导航 {#workspaces-and-navigation}

**工作区**集中显示您可访问的申请、任务及设置。每个账户都从 **Personal** 开始，用于个人申请及发到自己邮箱的任务。加入组织后，可用工作区选择器切换到组织协作。默认工作区可在[用户资料](profile.md)设置。

## Personal {#personal}

Personal 用于以自己名义发送的申请，以及分配到账户邮箱的任务，不含员工或团队目录。

组织可以向您的邮箱发送任务；任务会进入 Personal，但不会让您成为员工或获得组织工作区访问权。Personal 任务列表显示来源组织，便于识别发送方。

## 组织 {#organizations}

组织工作保留在选定组织内。员工及团队任务显示在该组织的 Tasks；Requests 显示您通过申请人身份、团队关系及授权委托可访问的工作。

员工和代理人必须属于同一组织。加入某组织不授予访问其他组织申请或任务的权限。

具有委托权限时，选择器还显示带被代表员工姓名的组织选项。选择它可代其工作，选回自己的条目即可返回。见[委托](delegations.md)。

品牌名称右上角的小标签在商业应用中为 **App**，开源应用中为 **Free**，文档门户中为 **Docs**。

## 主菜单 {#main-menu}

| 区域 | 用途 |
| --- | --- |
| Tasks | 处理分配给自己或根据组织工作流角色可执行的操作 |
| Requests | 跟踪可访问的申请；用 New request 发起工作 |
| Receipts | 在两种工作区查看、分享及删除签发给自己的结果记录 |
| Templates | 复用组织工作流步骤 |
| Employees, Teams, Delegations | 管理组织成员、团队及委托工作 |
| Plans, Usage, Retention | 查看订阅、限额及数据设置 |
| Organizations | 创建、管理企业工作区 |

个人菜单提供账户设置及通知偏好。应用栏铃铛打开当前工作区通知。小屏幕可用菜单按钮展开导航。外观开关会同步改变同一网站上应用与 Docs 的主题。

小号大写标签区分导航组、卡片、章节及步骤；页面标题和控件采用句首大写样式。标题上方的面包屑可返回父页面。主菜单 **Docs**在当前标签页打开指南，网站 Docs 和上下文**Read documentation** 链接也如此。开源应用的 Docs 打开[开源版本](open-source.md)指南及功能对比。

表格中的绿色标题和姓名是链接，悬停或键盘聚焦时显示下划线；键盘焦点另有可见轮廓。

页脚包含 Home、App、Docs、Contact、Terms 和 Privacy 链接，均在当前标签页打开。

在网站或文档的页眉中选择语言，即可阅读同一页面的其他语言版本。网站会在此浏览器中记住您的选择。从应用打开网站或文档的英文链接时，页面会跳转到已保存的语言；如果 URL 已明确指定语言前缀，则以该前缀为准。文档搜索也会返回 URL 对应语言的页面。应用目前使用英语，因此指南保留界面中的英文名称，并用所选语言解释其含义。

主菜单按 **Work**、**Access**、**People**、**Subscription**和**Support**分组，只显示当前工作区可用功能的组。在**Support**下选择**Replay user guide**，可重新查看应用栏和导航导览；见[入门](getting-started.md#take-a-quick-tour)。

## 打开共享链接 {#open-a-shared-link}

打开邮件或共享资源链接时，请登录预期账户。链接不会授予额外权限。无法访问时，请检查工作区、账户、员工权限及记录是否已删除。见[故障排查](troubleshooting.md)。
