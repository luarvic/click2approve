# 将文档审批步骤分配给团队 {#teams}

团队把同一组织的员工组成一组，便于向整组人员分配审批步骤。例如，建立提案审核团队，在配置审核步骤时选择该团队。步骤的完成规则决定需要全体成功响应，还是任意一人即可。

!!! info "仅适用于组织"
    先选择组织查看团队。Owner 和 Admin 管理团队成员。

## 创建或更新团队 {#create-or-update-a-team}

1. 选择组织，打开 **Teams**。
2. 由 Owner 或 Admin 创建团队，或打开现有团队编辑。
3. 输入清晰的 **Name**。
4. 选择属于该团队的本组织 **Employees**。
5. 保存并检查成员列表。

成员可以查看团队目录，Owner 和 Admin 负责管理。其他组织的人员不能作为此团队的员工加入。

## 分配工作给团队 {#assign-work-to-a-team}

配置[工作流步骤](workflow-steps.md)时，受派类型选择 **Team**，再选择团队。检查要求全体响应还是任意一人响应，确保符合完成要求。

成员变化仅影响今后的任务分配。已经分配的任务在参与者离开团队后仍由其负责。

团队关系影响用户可访问的组织任务与申请。找不到预期工作时，同时检查当前工作区和员工的团队成员资格。

## 移除团队 {#remove-a-team}

不再需要时可删除团队。其他记录的引用可能阻止删除。修改分配或删除正在被工作流、模板使用的团队前，请检查提示的关联关系。
