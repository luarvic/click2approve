# 文档审批入门 {#getting-started}

使用 Click2Approve 发送文档以供审阅、审批或电子签名。 **请求**是您发送的工作，包括其文件、说明和参与者。 **任务**是该请求中的一个参与者的操作。工作流程步骤按照您选择的顺序运行。

例如，将提案发送到客户的电子邮件地址并要求电子签名。客户登录、查看提案并提交签名。完成请求后，Click2Approve 会创建一个**结果记录**：您可以通过验证链接共享的结果记录。请参阅[结果记录和验证](receipts.md)。

## 快速浏览 {#take-a-quick-tour}

登录后首次打开应用程序时，简短的用户指南会突出显示您的个人资料设置、通知、工作区选择器和主菜单组。如果出现密钥设置提示，请先完成或关闭它。

选择 **Next**和**Back**浏览指南，选择**Finish**完成指南，或选择**Skip** 关闭指南。您也可以使用 Escape 关闭它。

在短屏幕上，按 Tab 键切换至 **User guide instructions**，然后使用 Page Down 或箭头键滚动说明。导航按钮保持可见。

该指南显示当前工作区中可用的导航。它解释了工作区选择器（当工作区选择器可用时)。在 Personal 中，它还说明组织有一个用于员工、团队和工作委托的 **People** 组。

系统会在此浏览器中记住您的帐户的完成或跳过操作。使用另一个浏览器或清除保存的站点数据会使指南再次出现。要随时重新访问，请打开主菜单并选择 **Support**下的**Replay user guide**。

## 发送您的第一个请求 {#send-your-first-request}

1. 在网站上选择“**打开应用**”以在同一浏览器选项卡中继续，或[直接打开应用程序](/app/)，然后[登录或注册](sign-in.md)。
2. 使用**Personal**（您的工作区)来满足您自己的请求，或在工作区选择器中选择一个组织以代表其发送工作。
3. 在主菜单中选择**New request**。
4. 输入标题和说明，添加文件，然后配置步骤和受派人。
5. 查看详细信息，然后选择 **Submit**。
6. 打开 **Requests** 以查看结果。

[创建请求](create-a-request.md) 解释提交的每个部分。

## 完成第一个任务 {#complete-your-first-task}

使用请求发送到的电子邮件地址登录。对于发送到该地址的任务，请在工作区选择器中选择 **Personal**；对于员工或团队分配，选择组织。打开 **Tasks**，选择任务，阅读其说明，然后查看当前文件。提供任何所需的评论、签名或附件，然后提交您的决定。请参阅[完成任务](complete-a-task.md)。

## Personal 和业务工作 {#personal-and-business-work}

每个人都从 Personal 工作空间开始。组织添加员工、团队、委派和可重复使用的工作流模板。

!!! info“组织功能”
    选择一个组织以使用其员工、团队、委派和模板。讨论、结果记录、修订和帐户安全也可在 Personal 中找到。您的角色和计划决定了您可以采取哪些行动；请参阅[功能和可用性](features.md)。
