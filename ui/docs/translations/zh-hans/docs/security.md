# MFA 与通行密钥 {#mfa-and-passkeys}

使用**多因素身份验证（MFA）**或**通行密钥**保护 Click2Approve 账户。验证器 MFA 要求在密码后输入验证器应用的代码。通行密钥通过受支持的设备或安全密钥，按浏览器提示完成登录。

设置适用于账户在 Personal 和各组织工作区中的使用。

## 启用验证器 MFA {#enable-authenticator-mfa}

1. 打开 **User profile → Security**。
2. 启用 **Use multi-factor authentication**。
3. 用验证器扫描二维码，或手动输入设置密钥。
4. 输入验证器代码确认设置。
5. 安全保存恢复码，并确认已保存。
6. 选择 **Done — sign in again**，用密码和验证器代码重新登录。

设置后，密码登录需要额外的 MFA 验证。开始设置会改变会话；无论完成还是取消，都需要重新登录。

## 恢复码 {#recovery-codes}

无法访问验证器时，使用保存的恢复码。

!!! warning "妥善保管恢复码"
    每个恢复码都是秘密信息，只能使用一次。**Generate new recovery codes** 会替换旧码；关闭前请先保存新码。

生成新恢复码或关闭 MFA 后，也需要重新登录。

在 Security 中关闭 MFA，并完成要求的验证。测试其他方式前，不要移除唯一可用的登录方式。

## 添加通行密钥 {#add-a-passkey}

1. 打开 **User profile → Passkeys**，选择新增通行密钥。
2. 输入容易识别的名称。
3. 按浏览器或设备提示，使用生物识别、PIN 或安全密钥。
4. 确认凭据已出现在列表中。

在兼容设备和浏览器上使用通行密钥登录。两者均须支持通行密钥。请保留密码以便恢复账户。

## 移除通行密钥 {#remove-a-passkey}

在 Passkeys 列表选中凭据并移除，操作前检查名称及最近使用情况。移除只撤销该凭据，不会删除其他通行密钥。

应用会通知兼容的密码管理器停止提供已移除的密钥。浏览器或密码管理器可能不支持此更新；若仍显示，请手动删除。该密钥已经无法登录账户。

验证器丢失或设备不可用时，请尝试已设置的替代方式或恢复码。都不可用时，请联系支持。
