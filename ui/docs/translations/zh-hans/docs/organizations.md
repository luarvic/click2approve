# 管理组织 {#manage-organizations}

**组织** 是代表企业发送的文档审批的工作区。它拥有自己的请求、员工、团队、模板和委派的工作。在创建请求或管理其人员之前，请在工作区选择器中选择它。

!!! info“组织工作区”
    创建或选择一个组织来管理共享工作。您的 Personal 工作区没有员工、团队、模板或委派。

## 创建组织 {#create-an-organization}

1. 打开**Organizations**并开始一个新组织。
2. 输入其详细信息并根据需要添加徽标。
3. 继续进行计划选择。使用 **Back** 编辑详细信息，同时保留创建草稿。
4. 选择 **Choose Business Trial**或**Choose Business Pro**，然后使用卡片下方的 **Subscribe** 创建组织。
5. 对于付费计划，请完成结账。在验证付款之前，工作区访问仍然受到限制。

每位所有者只能使用一次业务试用版。再次选择它会导致验证失败。有关付款和恢复行为，请参阅[计划和计费](plans-and-billing.md)。

## 设置工作区 {#set-up-the-workspace}

在工作区选择器中选择组织，然后：

- 添加[员工](employees.md) 并选择他们的员工
- 为定期参与者组创建[团队](teams.md)。
- 为需要有人代表他们行事的员工配置[委派](delegations.md)。
- 保存[工作流程模板](templates.md)以供重复流程。

员工、团队和代表必须属于该组织。在另一个组织中的工作保持独立。

## 更新组织详细信息 {#update-organization-details}

从 **Organizations**打开组织以编辑您的角色允许的详细信息。徽标图像最大可达**4 MiB**（4,194,304 字节)。保持企业名称和徽标易于识别，以便参与者可以在请求上下文和通知中识别组织。

## 删除组织 {#delete-an-organization}

只有 **Owner**可以通过**Delete organization** 安排删除。仔细阅读确认信息。预定的组织从工作空间选择中消失并且变得无法访问；后台处理稍后会删除其数据。

!!! warning“删除前保留记录”
    计划删除会立即删除对组织的访问权限。确认前保存您需要的任何记录；清理延迟不是恢复窗口。请参阅[保留和删除](retention.md)。
