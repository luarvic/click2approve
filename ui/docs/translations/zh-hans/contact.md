# 让我们来谈谈 {#lets-talk}

对工作流程有疑问、发现意外情况，或者对 Click2Approve 有想法吗？

## 提出问题 {#ask-a-question}

在 [GitHub Discussions](https://github.com/luarvic/click2approve/discussions) 发起讨论，说明您想完成什么，以及哪里需要帮助。需要 GitHub 帐户才能发帖。

## 报告错误 {#report-a-bug}

[打开问题](https://github.com/luarvic/click2approve/issues)，其中包含重现问题的步骤、您的预期以及发生的情况。不要公开报告中的密码、私人文档和其他敏感信息。

## 私人帐户和隐私问题 {#private-account-and-privacy-questions}

通过电子邮件 [contact@click2approve.com](mailto:contact@click2approve.com) 提出帐户、安全、法律或隐私请求。不要发送密码或不必要的身份证明文件。

## 需要起点吗？ {#need-a-starting-point}

[阅读入门指南](docs/index.md) 了解请求和任务的基础知识。
