# تواصل معنا {#lets-talk}

هل لديك سؤال حول سير العمل، أو وجدت شيئًا غير متوقع، أو لديك فكرة عن Click2Approve؟

## اطرح سؤالاً {#ask-a-question}

ابدأ محادثة في [مناقشات GitHub](https://github.com/luarvic/click2approve/discussions). قم بتضمين ما تحاول القيام به والمكان الذي تحتاج فيه إلى المساعدة. يلزم وجود حساب GitHub للنشر.

## الإبلاغ عن خطأ {#report-a-bug}

[افتح مشكلة](https://github.com/luarvic/click2approve/issues) مع خطوات إعادة إنتاج المشكلة، وما توقعته، وما حدث. اترك كلمات المرور والمستندات الخاصة والمعلومات الحساسة الأخرى خارج التقارير العامة.

## أسئلة حول الحساب الخاص والخصوصية {#private-account-and-privacy-questions}

أرسل بريدًا إلكترونيًا إلى [contact@click2approve.com](mailto:contact@click2approve.com) لطلبات الحساب أو الأمان أو الطلبات القانونية أو طلبات الخصوصية. لا ترسل كلمات مرور أو مستندات هوية غير ضرورية.

## هل تحتاج إلى نقطة بداية؟ {#need-a-starting-point}

[اقرأ دليل البدء](docs/index.md) للتعرف على أساسيات الطلبات والمهام.
