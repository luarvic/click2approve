# رموز API لتكامل سير الموافقات {#api-tokens}

استخدم Click2Approve API لتوصيل أدواتك الخاصة وأتمتة سير عمل الموافقة. تتيح الرموز المميزة API لعمليات التكامل الوصول إلى API من خلال حساب المستخدم الخاص بك. قم بإدارتها في ملفك الشخصي، سواء كنت تعمل في Personal أو في مؤسسة.

## إنشاء رمز مميز {#create-a-token}

1. افتح **User profile → API tokens**.
2. اختر **New API token**.
3. أدخل اسمًا يمكن التعرف عليه وانتهاء الصلاحية إذا لزم الأمر.
4. أنشئ الرمز المميز وانسخ قيمته قبل إغلاق مربع الحوار.
5. قم بتخزينه بشكل آمن للتكامل المقصود.

!!! warning "انسخ الرمز المميز قبل الإغلاق"
    يتم عرض القيمة الكاملة مرة واحدة فقط. قم بتخزينه بشكل آمن وإبقائه بعيدًا عن الرسائل ولقطات الشاشة والتحكم في المصدر. إذا فقدته، فقم بإنشاء بديل وإبطال الرمز المميز القديم.

## استكشاف API {#explore-the-api}

افتح [API مرجع (Swagger UI)]({{ api_reference_url }}){target="_blank" rel="noopener noreferrer"} لتصفح نقاط النهاية وحقول الطلب والاستجابات.

لتجربة طلب تمت مصادقته، اختر **Authorize**، والصق الرمز المميز API بدون البادئة `Bearer`، وقم بالتأكيد. يضيف Swagger رأس التفويض لك. اختر نقطة نهاية، وحدد **Try it out**، واملأ الحقول المطلوبة، وحدد **Execute**. تستخدم هذه الطلبات حسابك ويمكنها إنشاء بيانات حقيقية أو تغييرها أو حذفها.

تتطلب نقاط نهاية أمان الحساب جلسة تسجيل دخول تفاعلية ولا يمكن استخدامها مع الرموز المميزة API.

## استخدم رمزًا مميزًا في التكامل {#use-a-token-in-your-integration}

أرسل الرمز المميز الخاص بك في رأس `Authorization` مع كل طلب API:

```http
Authorization: Bearer YOUR_API_TOKEN
```

استبدل `YOUR_API_TOKEN` بالقيمة التي نسختها عند إنشاء الرمز المميز. تعمل الرموز المميزة مع أذونات حسابك. لا يمنح إنشاء الرمز المميز إمكانية الوصول إلى عمل مستخدم آخر أو موارد مؤسسة أخرى؛ لا يزال التفويض ساريًا.

## إلغاء الرمز المميز {#revoke-a-token}

حدد الرمز المميز في القائمة، واختر **Revoke**، وأكد ذلك. قم بتحديث أي تكامل تم استخدامه باستخدام بيانات اعتماد بديلة. قم بإلغاء الرموز المميزة وبيانات الاعتماد غير المستخدمة التي تشك في كشفها.

رموز API هي إعدادات الحساب. لا يؤدي تبديل مساحات العمل إلى إنشاء مجموعة منفصلة من الرموز المميزة.
