# أدلة سير عمل الموافقة على المستندات {#table-of-contents}

Click2Approve هو نظام للموافقة على المستندات. أرسل المستندات إلى الأشخاص الذين يحتاجون إلى مراجعتها، واجمع القرارات والتوقيعات الإلكترونية، وتتبع النتيجة. تشرح هذه الأدلة كيفية استخدام التطبيق في خطوات بسيطة.

يحتوي **الطلب** على المستندات والتعليمات وخطوات سير العمل. يتلقى كل شخص تم تعيينه لخطوة **مهمة**. يسجل **الإيصال** النتيجة عند انتهاء الطلب.

يحتوي Click2Approve أيضًا على [إصدار مفتوح المصدر](open-source.md) لسير العمل الشخصي المستضاف ذاتيًا. راجع مقارنة الإصدارات لمعرفة الميزات المضمنة والإضافات التجارية.
