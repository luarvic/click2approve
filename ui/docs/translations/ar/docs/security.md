# MFA ومفاتيح المرور {#mfa-and-passkeys}

احمِ حسابك في Click2Approve باستخدام **المصادقة متعددة العوامل (MFA)** أو **مفتاح مرور**. مع تطبيق المصادقة، تدخل رمزًا بعد كلمة المرور. ويتيح مفتاح المرور الدخول عبر جهاز أو مفتاح أمان مدعوم باتباع مطالبة المتصفح.

تسري هذه الإعدادات على حسابك في Personal وجميع مساحات المؤسسات.

## تفعيل MFA بتطبيق مصادقة {#enable-authenticator-mfa}

1. افتح **User profile → Security**.
2. فعّل **Use multi-factor authentication**.
3. امسح رمز QR بتطبيق المصادقة أو أدخل مفتاح الإعداد يدويًا.
4. أدخل رمز تحقق من التطبيق لتأكيد الإعداد.
5. احفظ رموز الاسترداد في مكان آمن وأكّد حفظها.
6. اختر **Done — sign in again**، ثم ادخل بكلمة المرور ورمز المصادقة.

بعد الإعداد، يتطلب الدخول بكلمة المرور تحقق MFA إضافيًا. يغير بدء الإعداد جلستك؛ وسواء أكملته أو ألغيته، يلزم تسجيل الدخول مجددًا.

## رموز الاسترداد {#recovery-codes}

استخدم رمز استرداد محفوظًا إذا تعذر الوصول إلى تطبيق المصادقة.

!!! warning "احفظ رموز الاسترداد بأمان"
    كل رمز سري ويُستخدم مرة واحدة. يستبدل **Generate new recovery codes** المجموعة السابقة؛ احفظ الرموز الجديدة قبل إغلاقها.

يتطلب إنشاء رموز جديدة أو إيقاف MFA تسجيل الدخول مرة أخرى بعد الانتهاء.

لإيقاف MFA، استخدم تبويب Security وأكمل التحقق المطلوب. لا تزل وسيلة الدخول الوحيدة التي تعمل قبل تجربة بديل.

## إضافة مفتاح مرور {#add-a-passkey}

1. افتح **User profile → Passkeys** واختر إضافة مفتاح جديد.
2. أدخل اسمًا تتعرف عليه لاحقًا.
3. أكمل مطالبة الجهاز أو المتصفح باستخدام القياسات الحيوية أو PIN أو مفتاح أمان.
4. تحقق من ظهور بيانات الاعتماد في القائمة.

استخدم خيار الدخول بمفتاح المرور على جهاز ومتصفح متوافقين. تتطلب مفاتيح المرور دعمًا من كليهما. احتفظ بكلمة المرور لاسترداد الحساب.

## إزالة مفتاح مرور {#remove-a-passkey}

حدد بيانات الاعتماد في قائمة Passkeys واستخدم الإزالة، بعد مراجعة اسمها وآخر استخدام لها. تلغي الإزالة صلاحية هذا المفتاح دون إزالة المفاتيح الأخرى.

بعد الإزالة، يُخطر التطبيق برامج إدارة كلمات المرور المتوافقة لتتوقف عن عرض المفتاح. قد لا يدعم متصفحك أو مدير كلمات المرور هذا التحديث. إذا ظل المفتاح ظاهرًا، فاحذفه يدويًا من مدير كلمات المرور؛ ولم يعد بإمكانه تسجيل دخولك.

إذا فقدت تطبيق المصادقة أو تعذر استخدام الجهاز، فجرب الطريقة البديلة التي أعددتها أو رمز استرداد. إن لم يتوفر أي منها، فتواصل مع الدعم.
