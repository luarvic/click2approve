# التسجيل وتسجيل الدخول {#registration-and-sign-in}

سجّل الدخول إلى Click2Approve لإرسال المستندات للموافقة أو إتمام مهمة. يتيح حسابك الوصول إلى **Personal**، مساحة طلباتك والمهام المرسلة إلى بريدك، وإلى المؤسسات التي تتمتع فيها بوصول موظف. عند فتح رابط مهمة، استخدم البريد الذي أُرسلت إليه.

## إنشاء حساب {#register}

1. [افتح التطبيق](/app/) واختر التسجيل.
2. أدخل بريدك وكلمة مرور تستوفي متطلبات النموذج.
3. أكّد كلمة المرور. راجع [الشروط](../terms.md) و[سياسة الخصوصية](../privacy.md)، ثم حدد **I agree to the Terms and acknowledge the Privacy Policy** وأرسل النموذج.
4. إذا لزم تأكيد البريد، افتح رسالة التأكيد واتبع رابطها.
5. سجّل الدخول وأكمل [ملفك الشخصي](profile.md).

يبقى **Sign up** معطلًا حتى تحدد مربع الموافقة.

ينشئ التسجيل مساحة Personal الخاصة بك. تُدار عضوية المؤسسات بشكل منفصل عبر [الموظفين](employees.md).

## تسجيل الدخول {#sign-in}

أدخل البريد وكلمة المرور. إذا فعّلت MFA عبر تطبيق مصادقة، فأكمل التحقق الإضافي برمز التطبيق أو رمز استرداد. يمكنك أيضًا استخدام [مفتاح مرور](security.md) مسجل عندما يكون مدعومًا.

عند الوصول من رسالة مهمة أو طلب، ادخل بالحساب الذي يملك الصلاحية. لا يتجاوز الرابط صلاحيات المورد.

## تأكيد البريد الإلكتروني {#confirm-your-email}

إذا لم تجد رسالة التأكيد، فافحص البريد غير المرغوب واستخدم إعادة الإرسال. أكّد عنوان الحساب الذي تنوي استخدامه. إذا انتهت صلاحية الرابط أو رُفض، اختر **Request a new verification email** في صفحة النتيجة. وبعد نجاح التأكيد اختر **Sign in** للمتابعة.

## إعادة تعيين كلمة مرور منسية {#reset-a-forgotten-password}

اختر إعادة تعيين كلمة المرور في شاشة الدخول، وأدخل بريدك، واتبع رسالة إعادة التعيين لتحديد كلمة جديدة. تعرض صفحتا إرسال البريد ونتيجة إعادة التعيين زر **Sign in**. بعد النجاح اختر **Sign in** للمتابعة. إعادة تعيين كلمة المرور وتأكيد البريد عمليتان منفصلتان.

لمشكلات المصادقة أو مفاتيح المرور، راجع [MFA ومفاتيح المرور](security.md) و[استكشاف الأخطاء](troubleshooting.md).
