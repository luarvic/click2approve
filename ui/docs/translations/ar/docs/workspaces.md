# مساحات العمل والتنقل {#workspaces-and-navigation}

تجمع **مساحة العمل** الطلبات والمهام والإعدادات التي تستطيع الوصول إليها. يبدأ الجميع بمساحة **Personal** لطلباتهم والمهام المرسلة إلى بريدهم. إذا كنت عضوًا في مؤسسة، فاستخدم منتقي المساحة للانتقال إلى عملها المشترك. حدد المساحة المفضلة عند البدء في [ملف المستخدم](profile.md).

## Personal {#personal}

استخدم Personal للطلبات التي ترسلها باسمك والمهام المسندة إلى بريد حسابك. لا تتضمن دليل موظفين أو فرق.

قد ترسل مؤسسة مهمة إلى بريدك. تصل إلى Personal دون أن تصبح موظفًا أو تحصل على وصول لمساحة المؤسسة. تعرض قوائم المهام المؤسسة الأصلية لتمييز المرسلين.

## المؤسسات {#organizations}

يبقى عمل المؤسسة ضمن المؤسسة المحددة. تظهر مهام الموظفين والفرق في عرض Tasks لديها. ويضم عرض Requests العمل المتاح عبر هويتك كمنشئ طلب أو علاقات الفرق أو التفويض المصرح به.

يجب أن ينتمي الموظفون والمفوّضون إلى المؤسسة نفسها. لا تمنح عضوية مؤسسة الوصول إلى طلبات مؤسسة أخرى أو مهامها.

عند امتلاك وصول مفوّض، يعرض المنتقي المؤسسة مع اسم الموظف الذي تمثله. اختره للعمل نيابة عنه، واختر إدخالك للعودة إلى عملك. راجع [التفويضات](delegations.md).

يعرض الوسم الصغير عند الزاوية العليا لاسم العلامة **App** في التطبيق التجاري و **Free** في المفتوح المصدر و **Docs** في بوابة الوثائق.

## القائمة الرئيسية {#main-menu}

| القسم | الغرض |
| --- | --- |
| Tasks | مراجعة الإجراءات المسندة إليك أو المتاحة عبر دورك المؤسسي في سير العمل |
| Requests | متابعة الطلبات المتاحة؛ واستخدام New request لإرسال عمل |
| Receipts | عرض سجلات النتائج الصادرة لك ومشاركتها وحذفها في كلا نوعي المساحات |
| Templates | إعادة استخدام خطوات عمل المؤسسة |
| Employees, Teams, Delegations | إدارة العضوية والفرق والعمل المفوّض |
| Plans, Usage, Retention | مراجعة الاشتراك والحدود وإعدادات البيانات |
| Organizations | إنشاء مساحات أعمال وإدارتها |

استخدم قائمة الملف الشخصي لإعدادات الحساب وتفضيلات الإشعارات. يفتح الجرس إشعارات المساحة الحالية. ويمكن فتح لوحة التنقل بزر القائمة على الشاشات الصغيرة. يغيّر مفتاح المظهر مظهر التطبيق وDocs معًا في الموقع نفسه.

تميز التسميات الصغيرة بأحرف كبيرة مجموعات التنقل والبطاقات والأقسام والخطوات. وتستخدم العناوين وعناصر التحكم حالة الجملة. استخدم روابط المسار فوق عنوان الصفحة للعودة إلى الصفحة الأم. يفتح **Docs** الكتيبات في التبويب نفسه، وكذلك روابط الموقع و **Read documentation**. في النسخة المفتوحة المصدر، يفتح Docs دليل [النسخة المفتوحة المصدر](open-source.md) ومقارنة الميزات.

العناوين والأسماء الخضراء في الجداول روابط. يظهر تحتها خط عند المرور أو التركيز بلوحة المفاتيح، ويظهر إطار واضح للتركيز.

يتضمن التذييل روابط Home وApp وDocs وContact وTerms وPrivacy، وتفتح جميعها في التبويب نفسه.

اختر اللغة من رأس الموقع أو الأدلة لقراءة الصفحة نفسها بلغة أخرى. يحفظ الموقع اختيارك في هذا المتصفح. عند فتح رابط إنجليزي للموقع أو الأدلة من التطبيق، تُفتح الصفحة باللغة المحفوظة؛ أما بادئة اللغة المحددة صراحة في العنوان فلها الأولوية. يعرض البحث صفحات بلغة العنوان الحالي. لا يزال التطبيق بالإنجليزية، لذلك تحتفظ الأدلة بأسماء عناصره كما تظهر فيه وتشرح معناها باللغة المختارة.

تجمع القائمة الصفحات تحت **Work** و **Access** و **People** و **Subscription** و **Support**، ولا تظهر المجموعة إلا إذا توفرت ميزاتها في المساحة الحالية. اختر **Replay user guide** تحت **Support** لجولة في شريط التطبيق والتنقل؛ راجع [البدء](getting-started.md#take-a-quick-tour).

## فتح رابط مشترك {#open-a-shared-link}

سجّل الدخول بالحساب المقصود عند اتباع رابط بريد أو مورد مشترك. لا يمنح الرابط صلاحيات إضافية. إذا تعذر المورد، فراجع المساحة والحساب وصلاحية الموظف وما إذا كان السجل قد حُذف. راجع [استكشاف الأخطاء](troubleshooting.md).
