# استكشاف مشكلات الموافقة على المستندات {#troubleshooting}

إذا تعذر العثور على مهمة أو إرسال طلب أو فتح رابط نتيجة، فابدأ بالحساب والمساحة المختارة. افتح الطلب أو المهمة لمعرفة الحالة الحالية، ثم اقرأ رسالة الإجراء الذي فشل.

## لا أجد طلبًا أو مهمة {#i-cannot-find-a-request-or-task}

تظهر المهام البريدية في **Personal**، ومهام الموظفين والفرق في مؤسستها. راجع البريد وحالة الموظف وعضوية الفريق والتفويض. قد تكون المهمة ملغاة أو متخطاة أو مكتملة أو مستبدلة بمراجعة أو محذوفة.

لا يمنح رابط البريد الوصول للمؤسسة. راجع [مساحات العمل والتنقل](workspaces.md).

إذا ظهر **Page not found**، فقد تكون الصفحة نُقلت أو لا تملك الوصول إليها. اختر **Home** للعودة ثم راجع الحساب والمساحة.

## يغيب عنصر قائمة أو إجراء {#a-menu-item-or-action-is-missing}

راجع [الميزات والتوافر](features.md). تتطلب إدارة الموظفين والفرق والتفويضات والقوالب مساحة مؤسسة. قد يخفي الدور أو الخطة أو وضع الفوترة عناصر التحكم أو يعطلها. اختر المؤسسة الصحيحة واطلب من Owner أو Admin فحص وصولك.

## يعيد التطبيق التحميل بعد تحديث {#the-app-reloads-after-an-update}

يعيد التطبيق تحميل نفسه عند اكتشاف إصدار جديد ثم يفتح الصفحة الحالية. قد تفقد النصوص غير المحفوظة.

## يفشل الإرسال أو إتمام المهمة {#submission-or-task-completion-fails}

صحح الحقول المحددة وقدّم كل تعليق وتوقيع ومرفق مطلوب. انتظر اكتمال الرفع. راجع [الاستخدام](usage.md) إذا ذكرت الرسالة حصة.

حدّث المورد قبل إعادة المحاولة بعد خطأ API؛ فقد أكمله مشارك آخر أو مفوّض. افحص Requests أو Tasks لمعرفة نجاح الإجراء الأصلي قبل تكراره.

## لا أستطيع مراجعة طلب {#i-cannot-revise-a-request}

يتوفر Resubmit فقط للطلبات المؤهلة التي لم تنجح ولا تملك مراجعة أحدث. تعيد النسخة الجديدة تشغيل سير العمل؛ وتبقى القرارات في السابقة. راجع [متابعة الطلبات ومراجعتها](track-requests.md).

## لا يعمل رابط تحقق {#a-verification-link-does-not-work}

قد يكون الرابط منتهي الصلاحية أو ملغى أو يشير إلى سجل محذوف. اطلب رابطًا صالحًا من صاحب سجل النتيجة. [سجلات النتائج والتحقق](receipts.md).

## لا أستطيع الدخول أو استلام البريد {#i-cannot-sign-in-or-receive-email}

تحقق من ضرورة تأكيد البريد واطلب رسالة تأكيد أو إعادة كلمة المرور عند الحاجة. افحص البريد غير المرغوب والعنوان. جرّب رمز استرداد غير مستخدم لـMFA، أو جهازًا متوافقًا مسجلًا أو كلمة المرور لمفاتيح المرور.

راجع [التسجيل والدخول](sign-in.md) و[MFA ومفاتيح المرور](security.md) و[الإشعارات](notifications.md).

## المساحة محجوبة بسبب الدفع {#the-workspace-is-blocked-for-payment}

افتح **Plans** واتبع معالجة الدفع قبل الموعد المعروض. يجب أن يدير Owner أو Admin مدفوعات المؤسسة. راجع [الخطط والفوترة](plans-and-billing.md).

## يتعذر الحذف {#deletion-is-blocked}

اقرأ رسالة التبعية. قد يشير سجل آخر إلى الموظف أو الفريق أو عنصر العمل. راجع [الاحتفاظ والحذف](retention.md) قبل إزالة السجلات المرتبطة.

## الحصول على المساعدة أو الإبلاغ عن خلل {#get-help-or-report-a-bug}

استخدم **Report a bug** أو **Ask question**. ضمّن خطوات إعادة المشكلة، والنتيجة المتوقعة والفعلية، والوقت التقريبي، ونوع المساحة. إذا قدم خطأ API خيار **Details**، فراجع التشخيص وشارك فقط ما يناسب قناة الدعم.

لا تنشر كلمات مرور أو رموز API أو الاسترداد أو روابط التحقق أو المستندات الخاصة في البلاغات العامة. تواصل مع الدعم لمشكلات الحساب والبريد والأمان والفوترة.
