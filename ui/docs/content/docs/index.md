# Document approval workflow guides {#table-of-contents}

Click2Approve is a document approval system. Send documents to the people who need to review them, collect decisions and electronic signatures, and track the result. These guides explain how to use the app in simple steps.

A **request** contains your documents, instructions, and workflow steps. Each person assigned to a step receives a **task**. A **receipt** records the result when the request finishes.

Click2Approve also has a free [open-source edition](open-source.md) for self-hosted personal workflows. See the edition comparison for included features and commercial additions.
