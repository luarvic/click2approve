# Create a document approval request {#create-a-request}

A **request** contains documents to review, a description, and workflow steps explaining who should act and what they should do.

## Compose the request {#compose-the-request}

1. [Open the app](/app/) and choose **New request** in the main menu.
2. Enter a specific **Title** and a **Description** explaining the context.
3. Attach documents under **Files to review**. See [Files and attachments](files.md).
4. Add and configure [workflow steps](workflow-steps.md), assigning each participant by email address.

Each participant must use an account on this installation with the email address you assigned.

## Example: approval followed by signature

1. Add the proposal under **Files to review**.
2. Set the first step's **Action** to **Approve**, and add the reviewer's email.
3. Choose **Add step**, set **Action** to **Sign**, and add the signer's email.
4. Enable **Require an electronic signature** on the signing step.
5. Write clear **Instructions** for each step.

The signing task becomes available after the approval step succeeds.

## Review and submit

Check the documents, participants, step order, instructions, completion rules, visibility, and requirements. Choosing **Sign** alone does not require a drawn signature; enable **Require an electronic signature** when you need one.

Choose **Submit** and wait for confirmation. Correct highlighted fields if validation fails. Open **Requests** to [track progress](track-requests.md).

Leaving the compose screen discards edits. Request drafts are not saved.
