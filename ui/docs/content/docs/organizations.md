# Manage organizations

An organization holds its own requests, employees, teams, templates, and delegated work.

!!! info "Organization workspace"
    Create or select an organization to manage shared work. Your Personal workspace has no employees, teams, templates, or delegations.

## Create an organization

1. Open **Organizations** and start a new organization.
2. Enter its details and add a logo if needed.
3. Continue to plan selection. Use **Back** to edit the details while preserving the creation draft.
4. Choose an available plan to create the organization.
5. For a paid plan, complete Checkout. Workspace access remains restricted until payment is verified.

Business Trial is available once per owner. Selecting it again fails validation. See [Plans and billing](plans-and-billing.md) for payment and recovery behavior.

## Set up the workspace

Select the organization in the workspace picker, then:

- Add [employees](employees.md) and choose their roles.
- Create [teams](teams.md) for recurring participant groups.
- Configure [delegations](delegations.md) for employees who need someone to act on their behalf.
- Save [workflow templates](templates.md) for repeatable processes.

Employees, teams, and delegates must belong to this organization. Work in another organization remains separate.

## Update organization details

Open the organization from **Organizations** to edit details your role permits. Logo images can be up to **4 MiB** (4,194,304 bytes). Keep the business name and logo recognizable so participants can identify the organization in request context and notifications.

## Delete an organization

Only the **Owner** can schedule deletion through **Delete organization**. Read the confirmation carefully. Scheduled organizations disappear from workspace selection and become inaccessible; background processing removes their data later.

!!! warning "Preserve records before deleting"
    Scheduling deletion immediately removes access to the organization. Save any records you need before confirming; the cleanup delay is not a recovery window. See [Retention and deletion](retention.md).
