# Discuss documents in request and task Chat {#discussions}

Use **Chat** to ask questions about a document before approving or signing it. You can share supporting files in the discussion. Chat is available in both Personal and organization workspaces.

## Ask about a request

1. Open an accessible request or task.
2. Select **Chat**.
3. Read the existing messages for context.
4. Enter your message. Use the paperclip inside **Message** to attach supporting files, then choose **Send**.

Your messages appear on the right; other people's messages appear on the left. On a request, conversations are grouped by workflow step. On a task, Chat shows the current step.

Use the arrow beside a step heading to show its participants in alphabetical order. Use it again to hide the list. Messages stay visible when the participant list is hidden.

Use Chat for questions and clarification. Record the actual decision through the task's action controls so it becomes a workflow outcome.

## Audience and access

Discussion access depends on the request, task, and your permissions. A shared link or organization membership does not give everyone access to the conversation. Check the context before posting sensitive material.

Delegates participate only through the access granted within their organization. Discussion messages and notifications retain the author's attribution.

## When you cannot send

Sending may close when the workflow no longer has an actionable pending task or has completed. If the composer is unavailable, refresh the resource and check its current state and your access. The discussion can remain available to read even when new messages are no longer allowed.

## Notifications

Discussion notifications depend on your [Chat notification preferences](notifications.md) and the audience permitted to receive that message. A file sent in Chat is separate from a required [decision attachment](files.md).
