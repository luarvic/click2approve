# Files and attachments

Add documents under **Files to review** when [creating a request](create-a-request.md). Choose recognizable filenames and check that you selected the right versions.

## Upload documents

Each attachment can be up to **50 MiB** by default. Your installation may use different limits. Wait for uploads to finish before submitting the request.

The total upload request also has a size limit. If a batch is rejected, try fewer files at a time or ask the installation operator about configured limits.

## Review and download

Open a filename from a request or task to use its available preview or download action. If the browser cannot preview the format, download it and use a suitable application.

Access to an attachment follows access to its request or task. A file link does not grant another account permission to read it.

## Upload problems

Read the error and check file size and connectivity before retrying. See [Troubleshooting](troubleshooting.md). Keep your own copies of documents that you need to retain.
