# Files and attachments

Files can belong to the request, a participant's decision, or a discussion message. Check where you attach a file so it is part of the intended record.

## Request files

Add the documents participants must review when [creating a request](create-a-request.md). Use recognizable filenames and check the selected files before submitting.

Open a filename to use its available preview or download action. Preview support depends on the file format and browser. If a preview cannot display the document, download it and use a suitable application.

## Decision attachments

Attach response files in the task action area when requested. A step marked **Require an attachment** cannot be completed without its required response file.

Decision attachments appear with the recorded task action. Uploading the same file to Chat does not satisfy a task's attachment requirement.

## Discussion attachments

Attach supporting material to a [Chat message](discussions.md) when you need to clarify the request. Consider the discussion audience before sharing it.

## Revised files

A revision can add, remove, or replace request files. Review the current file list and use **Show revision changes** for context. Replaced and removed files shown there are not current review documents.

## Upload problems

Wait for uploads to finish before submitting. If an upload is rejected, read the error and check the file and workspace's [usage limits](usage.md). Avoid repeatedly submitting while a request is still processing. See [Troubleshooting](troubleshooting.md) for failed actions.
