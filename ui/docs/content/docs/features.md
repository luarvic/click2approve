# Features and availability

This installation provides personal document workflows with individual accounts.

| Feature | What you can do |
| --- | --- |
| Requests | Upload documents, add instructions, and follow recorded decisions |
| Workflow steps | Use steps in order, with several assignees in one step and all/any completion rules |
| Actions | Request approval, signature, confirmation, acknowledgement, review, verification, acceptance, or completion |
| Requirements | Require a comment or electronic signature |
| Tasks | Review documents and record your response |
| Request management | Track progress, cancel active requests, and schedule deletion |
| Account | Manage your profile, avatar, saved signature, password, MFA, and passkeys |
| Notifications | Receive in-app notifications and emails when email delivery is enabled |

Every assignee needs an account on this installation to act. Access depends on being the requester or an eligible participant; knowing a URL does not grant access.

For source code, integration, and hosting instructions, visit the [public repository](https://github.com/luarvic/click2approve). The [hosted commercial service](https://click2approve.com/) has its own features and documentation.
