# Track requests {#track-and-revise-requests}

Open **Requests** and select a request you sent. Review its current status, steps, and recorded participant actions. **Tasks** shows the work assigned to you.

## Outcomes

Steps and requests show **Succeeded** or **Failed** when their outcome is known. Participant actions retain specific labels such as **Signed** or **Rejected**. A step waits for all assignees or any one assignee according to its completion rule.

## Cancel a request

Use the cancellation action when you no longer want an active workflow to continue. Review the confirmation before proceeding. Cancellation stops pending work; it does not turn pending tasks into approvals.

## Delete a request

Use the request's deletion action and review the confirmation. Deletion is scheduled and background cleanup removes the record and associated files.

!!! warning "Keep records you need"
    Download documents you need to keep before deleting a request. Deleted records may no longer be available through old task, request, or notification links.

To send changed documents for review, create a [new request](create-a-request.md) and check its files and participants before submitting.
