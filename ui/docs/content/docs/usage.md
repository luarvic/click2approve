# Usage and limits

Limits apply to the selected workspace's plan. Personal and organization plans can offer different allowances.

## Review usage

Select the workspace and open **Usage**. Review request, task, and storage usage for the current billing period. Use the displayed allowances and plan cards to understand your current limits.

Usage belongs to the workspace where the work is recorded. Switching to another workspace changes the scope you are inspecting; it does not transfer existing work or its usage.

## When a limit blocks an action

1. Read the validation or error message to identify the relevant allowance.
2. Open Usage and confirm that you selected the correct workspace.
3. Check the current plan and any pending plan change on **Plans**.
4. Ask the Personal subscription owner or organization Owner or Admin to review available plan options.

A pending paid change does not provide the new allowance until the payment and plan activation succeed. Check [Plans and billing](plans-and-billing.md) before retrying.

## Storage and retention

Files contribute to storage use. Removing a workflow record may schedule its files for later cleanup, so storage use need not fall immediately. Plan [retention](retention.md) around how long your organization needs its records, rather than deleting active work merely to change a usage figure.
