# Workflow templates

Templates save reusable request steps and participants inside an organization. Each template belongs to the person who creates it: other members, including Owners and Admins, do not see or manage your templates.

!!! info "Organization only"
    Select an organization to create and reuse workflow templates. Templates belong to that organization and are unavailable in Personal.

## Create a template

Open **Templates** in the organization and create a template with a descriptive name and reusable steps. Configure actions, instructions, assignees, completion rules, visibility, and additional requirements, then save.

You can also use **Save template** while composing an organization request. Review what you save: a workflow template stores step configuration rather than a completed request or its recorded decisions.

## Start a request from a template

1. Choose **New request** in the same organization.
2. Select **From template**, choose the template, and continue.
3. Enter the request's title, description, and current documents.
4. Review every participant and step before choosing **Submit**.

Templates provide a starting configuration. Check that employees and teams are still appropriate for the new request. Do not assume a template supplies the files for a particular transaction.

The editor loads the template before you begin editing. Its name and description provide initial request text; change them for the current request before submitting.

## Maintain templates

Open **Templates** to update your recurring instructions and participant choices. Any active organization member can create and manage their own templates. Editing a template does not change requests that have already been submitted.

Remove unused templates with the available delete action. If deletion is blocked by a reference, follow the validation message rather than repeatedly retrying.
