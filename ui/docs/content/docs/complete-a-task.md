# Complete a task

Tasks show the work assigned to you in a request.

## Review before deciding

1. [Open Click2Approve](/app/) and select the relevant workspace, if applicable.
2. Open **Tasks** and choose a task waiting for your action.
3. Read the request description and step instructions.
4. Review the attached files and any relevant discussion.

## Record your decision

Use the action offered for the task. Depending on the workflow, you may need to leave a comment or provide an electronic signature before completing it.

Check your decision before submitting. The recorded outcome becomes part of the request's history.

## Find the context later

Return to the task or request details to review the outcome and discussion. If a task is unavailable, check that you're signed in with the intended account and workspace.
